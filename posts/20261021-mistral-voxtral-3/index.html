미스트랄 Voxtral 3 공개 — 듣고 생각하고 말하는 실시간 음성 에이전트 (캐릭터는 AI 이미지 생성)

전화 주문이 몰리는 반찬가게를 떠올려 볼게요. 받아 적는 사람, 장부를 확인하는 사람, 대답하는 사람이 따로 있으면 손님은 매번 ‘잠시만요’를 들어요. 손님이 ‘아, 잠깐만요’ 하고 말을 끊어도, 대답하던 사람은 한참 뒤에야 멈추고요.

미스트랄 AI가 10월 20일 음성 모델 묶음 Voxtral(복스트랄) 3와 음성 에이전트 SDK를 내놨어요. 듣기·생각과 도구 부르기·말하기를 한 줄로 이어 실시간으로 돌려요. 다만 이번 모델은 가중치를 공개하지 않았고, 전화 연결(SIP)은 출시 시점에 기업 고객만 쓸 수 있어요.

헤드셋을 쓴 로봇이 전화 주문을 들으며 태블릿 달력에 예약을 잡는 장면 — 듣기·생각·말하기를 한 번에 하는 음성 에이전트를 빗댄 그림 (AI 이미지 생성)

1. 무슨 일: 모델 넷과 에이전트 SDK

미스트랄은 10월 20일 받아 적기(전사) 모델 셋, 음성 합성 모델 하나, 이를 묶는 음성 에이전트 SDK를 공개했어요. 발표 글과 문서에 적힌 이름·역할·값을 표로 옮겼어요. 값은 미스트랄 API 기준이에요.

모델하는 일 · 값
Voxtral Small Transcribe 3녹음 파일 받아 적기·화자 구분, 가장 정확한 판 · 분당 0.004달러
Voxtral Mini Transcribe 3파라미터 40억 개의 작은 판 · 분당 0.0035달러
Voxtral Mini Transcribe Realtime 3말하는 동안 받아 적기·말 끝 감지 · 분당 0.008달러
Voxtral Speech 3 (TTS 3)감정·속도를 바꾸는 음성 합성 · 글자 100만 자당 13달러
음성 에이전트 API위 모델과 언어 모델을 한 줄로 · 분당 0.04달러(미스트랄 스몰 4), 다른 언어 모델은 0.08달러

네 모델 모두 미스트랄 문서에 ‘공개 프리뷰(Public Preview)’로 올라 있어요. API는 유럽·미국·글로벌 엔드포인트로 열렸고, AI 스튜디오 놀이터에서 음성 에이전트·받아 적기·음성 합성·목소리 복제를 바로 시험할 수 있어요. 음성 합성 모델은 발표 글 안에서도 ‘Voxtral Mini TTS 3’와 ‘Voxtral Speech 3’ 두 이름으로 나와요. 이 글은 값 표에 쓰인 Voxtral Speech 3로 적을게요.

미스트랄의 큰 언어 모델 라지 4는 10월 7일 글에 정리해 뒀어요.

2. 음성 에이전트 한 턴은 이렇게 돌아요

SDK가 듣기·생각·말하기를 한 줄로 흘려보내서, 한 턴을 1초 안에 끝낸다는 게 미스트랄의 설명이에요. 실시간 전사 모델이 듣다가 말이 끝났다고 판단하면, 미스트랄 스몰 4 같은 언어 모델이 답을 만들고 필요하면 도구를 불러요. 그다음 Voxtral Speech 3가 지금까지 대화의 분위기에 맞춰 말해요.

단계마다 모델이 따로라서 언어 모델·목소리·언어를 바꿔 끼울 수 있어요. 도구로는 본인 확인, 요금 조회, 예약 같은 일을 맡기고, 웹 검색·문서 라이브러리·연결한 업무 시스템을 부를 수 있어요. 실시간 오디오 전송은 LiveKit이라는 실시간 통신 도구 위에 만들었고, LiveKit을 몰라도 쓸 수 있다고 문서에 적혀 있어요.

Voxtral 3 음성 에이전트 한 턴 — 듣기(실시간 전사)·생각과 도구·말하기(음성 합성), 말 끊기와 연결 방식 (직접 제작)

콜센터 이야기에 자주 나오는 낯선 말 세 개를 먼저 풀어 볼게요.

말뜻
SIP인터넷으로 전화를 걸고 받는 표준 방식. 회사 전화망과 콜센터 시스템이 이 방식으로 통화를 넘겨요
IVR‘1번은 요금 문의’ 같은 자동 응답 메뉴. 기존 전화 상담 시스템의 한 부분이에요
말 끊기(barge-in)기계가 말하는 도중 사람이 끼어들면 바로 멈추고 듣는 기능

미스트랄은 SIP로 전화를 받고 걸며, 이미 쓰는 전화·IVR·콜센터 소프트웨어에 연결된다고 밝혔어요. 웹과 앱에서는 WebRTC(브라우저에서 음성을 실시간으로 주고받는 표준)로 붙어요. 말 끊기는 기본으로 켜져 있어요. 법적 고지처럼 끝까지 들려줘야 하는 안내는 설정으로 끌 수 있어요(미스트랄 문서).

말이 끝났는지는 침묵 길이만 보지 않고, 무슨 말을 어떻게 했는지까지 보고 판단한다고 해요. 주문 번호를 한 자리씩 불러 주다 잠깐 멈추는 사람을 끊지 않으려는 거예요.

말하던 로봇이 손을 들어 멈추고 귀를 기울이는 장면 — 사람이 끼어들면 바로 멈추고 듣는 말 끊기(barge-in)를 빗댄 그림 (AI 이미지 생성)

3. 한국어와 언어 수

미스트랄 발표 기준으로 한국어는 받아 적기와 음성 합성 모두 대상 언어에 들어 있어요. 파일 전사 평가(FLEURS 45개 언어)와 실시간 전사 평가(35개 언어) 목록에 한국어가 있고, 미리 만든 목소리(프리셋)를 주는 18개 언어에도 한국어가 있어요.

언어 수는 모델마다 달라요. 문서의 언어 표에서 파일 전사 두 모델은 50개, 실시간 전사는 45개 언어·방언, 음성 합성은 35개 언어·50개 넘는 방언이에요. 다만 표기가 엇갈려요. 발표 글은 실시간 전사를 ‘35개 넘는 언어’와 ‘40개 넘는 언어’로 다르게 적었고, 음성 합성 모델 소개 칸에는 ‘9개 언어 지원’이라고 적혀 있어요. 한국어만의 점수는 따로 밝히지 않았어요.

4. 처리 위치와 가중치 공개

Voxtral 3는 가중치를 공개하지 않았어요. 대신 ‘어디서 처리하느냐’를 고르게 해요. 미스트랄은 유럽에서 운영하는 API, 미국·글로벌 엔드포인트, 자기 인프라에 직접 까는 방식을 모두 내놨어요. 자체 구축하면 민감한 통화를 회사 안에 두고, 녹음을 남길지도 정할 수 있다고 해요.

다만 온프레미스(회사 서버)나 프라이빗 클라우드로 전체를 돌리려면 미스트랄 팀에 문의하라고 적혀 있어요. 필요한 GPU·메모리 사양은 밝히지 않았어요(마크테크포스트). 10월 21일 허깅페이스 mistralai 계정에는 Voxtral 3 모델이 없고, AA도 Small Transcribe 3를 ‘가중치 비공개’로 표시해요. 앞선 Voxtral 모델 일부(Voxtral Small 24B, Mini 4B Realtime 등)가 Apache 2.0으로 공개된 것과 달라요.

💡 핵심이번엔 가중치 공개가 아니라 ‘처리 위치 선택’으로 데이터 주권을 내세웠어요. 회사 서버에 깔려면 영업 상담을 거쳐야 해요.

5. 검증: 회사 표와 독립 평가

파일 전사는 독립 평가에서도 상위권이지만 1위는 아니에요. 벤치마크 회사 Artificial Analysis(AA)의 음성 인식 오류율 지수(AA-WER, 낮을수록 좋음)에서 Small Transcribe 3는 2.09%로 3위예요. 10월 21일 AA 페이지 데이터에서 위쪽 모델을 골라 놓으면 이래요.

모델 (회사)AA-WER · 1,000분당 값
Fun-Realtime-ASR-preview (알리바바)1.73% · 값 표시 없음
MAI-Transcribe-2 (마이크로소프트 AI)2.04% · 1.67달러
Voxtral Small Transcribe 3 (미스트랄)2.09% · 4달러
Scribe v2 (일레븐랩스)2.18% · 3.67달러
Voxtral Mini Transcribe 3 (미스트랄)2.22% · 3.5달러
Gemini 3.5 Transcribe (구글)2.60% · 5달러

미스트랄 발표 글의 45개 언어 평가(FLEURS)에서도 Small은 오류율 4.1%로 마이크로소프트 AI Transcribe 2와 같았어요. 문서의 모델 소개는 마이크로소프트 모델을 ‘앞선다’고 적었지만, 발표 글 그림과 AA 기준으로는 비기거나 조금 뒤예요. 누가 말했는지 가리는 화자 구분 오류율은 18.4%로 비교한 모델 중 가장 낮다고 미스트랄 표에 나와요. 이 표는 회사가 직접 잰 값이에요.

실시간 전사는 미스트랄 자기 그림에서도 구글보다 낮아요. 35개 언어 평가에서 지연을 480ms로 맞추면 오류율 6.4%, 240ms면 7.4%예요. 같은 그림에서 제미나이 3.5 실시간 전사는 4.2%였어요. 빨리 받아 적을수록 정확도가 떨어지는 구조라, 지연 설정을 업무에 맞게 골라야 해요. 문서에 따르면 지연은 80ms에서 2,400ms까지 정할 수 있어요.

발표 글과 문서가 다른 곳도 있어요. 발표 글은 음성 합성의 ‘프롬프트 지시 따르기’를 새 기능으로 소개했지만, 문서는 스타일 지시(style instructions)가 출시 때는 안 된다고 적었어요. 감정·속도는 글 속 태그로 정해요.

6. 고객센터에 넣기 전 점검

전화 상담에 바로 붙이기 전에, 문서에 적힌 전화 연결의 한계부터 보세요. 전화(SIP) 연결은 출시 때 기업 고객만 쓸 수 있고, 스스로 켤 수 없어 계정팀을 거쳐야 해요. 전화번호와 통화를 실어 나르는 시스템은 회사가 직접 마련해요.

문서는 전화 에이전트가 통화를 사람 상담원에게 넘길 수 없다고 적었어요. 처리 못 할 요청에는 ‘담당자가 다시 연락드린다’처럼 말하게 하라고 안내해요. 전화 중에는 우리 앱 코드가 돌지 않아서 앱 쪽 도구는 실패하고, 서버 쪽 도구만 써야 해요. 또 한 실시간 세션에서 말 끝 감지와 화자 구분을 함께 켜면 오류가 나요.

값은 음성 에이전트 API가 분당 0.04달러(미스트랄 스몰 4)라, 10분 통화 한 건이면 0.4달러예요(우리 계산). Voxtral 3를 검토한다면 볼 곳은 세 가지예요.
① 채널 — 웹·앱으로 먼저 시험하고, 전화 연결은 계정팀과 일정을 잡으세요
② 한국어 — 우리 상담 녹음 몇 건으로 받아 적기 정확도와 목소리를 먼저 들어 보세요
③ 사람 연결 — 상담원 이관이 안 되니, 처리 못 할 요청의 다음 단계를 먼저 정하세요

⚠️ 주의실제 고객 통화를 넣기 전에 녹음 보관·개인정보 처리 조건을 담당자와 확인하세요. 목소리 복제는 당사자 동의를 받은 뒤에 쓰세요.

② 듣기·생각·말하기를 한 줄로, 한 턴 1초 안(회사 발표)
③ 파일 전사는 AA 3위, 실시간 전사는 구글보다 낮아요
④ 한국어는 대상 언어에 있지만 따로 밝힌 점수는 없어요
⑤ 가중치 비공개, 전화(SIP)는 출시 땐 기업 고객만

오늘의 큰 흐름: 오픈 가중치와 추론 비용 경쟁이에요. 미스트랄은 이번엔 가중치 대신 분당 값과 처리 위치 선택으로 겨뤘어요.

자주 묻는 질문

Q. Voxtral 3로 한국어 상담 봇을 만들 수 있나요?

미스트랄 발표 기준으로 한국어는 받아 적기와 음성 합성 대상 언어에 들어 있어요. 다만 한국어 점수는 따로 밝히지 않았고, 전화 연결은 출시 때 기업 고객만 계정팀을 거쳐 쓸 수 있어요. 웹·앱에서 우리 상담 녹음으로 먼저 시험해 보세요.

Q. 모델을 내려받아 무료로 쓸 수 있나요?

아니요. 10월 21일 기준 Voxtral 3는 가중치를 공개하지 않았어요. API로 쓰거나, 회사 서버에 까는 방식은 미스트랄 팀과 상의해야 해요. 앞선 Voxtral 모델 일부는 Apache 2.0으로 허깅페이스에 있어요.

Q. 값은 얼마인가요?

받아 적기는 분당 0.0035달러에서 0.008달러, 음성 합성은 글자 100만 자당 13달러예요. 음성 에이전트 API는 미스트랄 스몰 4를 쓰면 분당 0.04달러, 다른 언어 모델이면 0.08달러예요(10월 20일 발표).

Q. 기존 전화 상담 시스템(IVR)에 붙일 수 있나요?

미스트랄은 SIP로 기존 전화·IVR·콜센터 소프트웨어에 연결된다고 밝혔어요. 출시 때는 기업 고객이 계정팀을 통해 켜고, 번호와 전화 시스템은 회사가 마련해요. 문서상 사람 상담원에게 통화를 넘기는 기능은 없어요.
