오픈클로·헤르메스·그록봇·메타 뮤즈 비교, AI 에이전트 차이

AI 에이전트 네 갈래 비교 — 오픈클로·헤르메스·그록봇·메타 뮤즈 (캐릭터는 GPT 이미지 생성)

일을 대신 해 주는 AI 에이전트가 1년도 안 돼 쏟아졌어요. 이름을 보다 보면 이런 생각이 들죠. “다 비슷해 보이는데, 뭐가 다르지?” 저는 이 중 오픈클로를 맥미니에 올려 24시간 돌리고 있어서, 마지막에 나온 메타 뮤즈가 무엇을 다르게 들고 나왔는지 특히 궁금했어요.

비서를 두는 방법을 떠올려 보세요. 직접 뽑아 우리 집에 들일 수도 있고, 일하면서 요령을 스스로 늘리는 비서를 들일 수도 있어요. 파견 회사가 사무실과 컴퓨터까지 딸려 보내는 비서 팀을 쓸 수도 있고, 대기업 컨시어지 서비스에 가입할 수도 있죠. 오픈클로, 헤르메스 에이전트, 그록봇, 메타 뮤즈가 정확히 이 네 갈래예요.
네 에이전트의 차이는 똑똑함보다 ‘어디서 돌고, 누가 관리하고, 누구를 믿어야 하나’에 있어요.

가재 로봇, 날개 투구 로봇, 구름 위 노트북 로봇, 컨시어지 로봇 — 비서를 두는 네 가지 방법 (GPT 이미지 생성)

1. 히스토리: 10개월 사이 네 갈래

2025년 11월부터 2026년 9월까지, 네 에이전트가 차례로 나왔어요. 날짜별로 정리했어요.

날짜무슨 일
2025년 11월 24일오스트리아 개발자 피터 슈타인베르거가 Warelay라는 이름으로 첫 공개
2026년 1월Clawdbot → 앤트로픽 상표 문제로 Moltbot → 사흘 만에 OpenClaw(1월 30일)
2026년 2월 14일만든 사람이 OpenAI 합류를 발표, 프로젝트는 오픈클로 재단이 맡기로
2026년 2월 25일Nous Research가 헤르메스 에이전트 공개
2026년 3월오픈클로 GitHub 별 24만 7천 개(3월 2일). 중국이 국가기관 사용을 제한
2026년 5월OpenRouter 일간 사용량에서 헤르메스가 오픈클로를 앞섬(MarkTechPost 보도)
2026년 8월xAI 그록봇 베타 공개(11일), SuperGrok·Cursor 구독으로 확대(26일)
2026년 9월메타 뮤즈 공개(8일), Connect에서 AI 안경·전용 이메일 발표(23일)
2026년 9월 29일메타 발표 기준 뮤즈 제공 지역은 미국·캐나다
2026년 10월 7일GitHub 별(직접 확인): 오픈클로 약 39만, 헤르메스 약 25만

흐름을 한 줄로 하면, 개인이 만든 오픈소스가 불을 붙였고(오픈클로) 오픈소스 안에서 ‘스스로 배우는’ 쪽으로 진화했어요(헤르메스). 그다음 대형 회사들이 ‘설치 없이 빌려 쓰는’ 서비스로 가져갔어요(그록봇·뮤즈).

개인 AI 에이전트 네 갈래 — 나온 순서와, 어디서 도나 × 누구를 향하나 지도 (직접 제작)

2. 한눈에 비교

먼저 ‘어디서 돌고, 무엇으로 생각하고, 값을 어떻게 내나’ 세 가지로 보면 쉬워요.

에이전트어디서 · 머리 · 값
오픈클로내 컴퓨터 · 아무 모델(내 API 키) · 무료(MIT) + 모델 비용
헤르메스 에이전트내 컴퓨터·서버 등 7가지 실행 환경 · 아무 모델 · 무료(MIT) + 모델 비용
그록봇봇마다 xAI 클라우드 컴퓨터 · 발표문에 모델명 없음 · 구독에 포함
메타 뮤즈메타의 보안 가상컴퓨터 · 자체 모델 Muse Spark · 대부분 무료 + 유료 구독

오픈소스 둘은 통제권이 내게 있고, 회사 서비스 둘은 설치와 관리가 필요 없어요. 통제권을 가질지, 편하게 빌려 쓸지가 첫 갈림길이에요.

3. 기술 차이 여섯 가지

같은 ‘에이전트’라도 여섯 가지 축에서 갈라져요.

어디서 도나 오픈클로·헤르메스는 내 컴퓨터(헤르메스는 Docker·SSH 등 7가지 실행 환경), 그록봇은 봇마다 늘 켜진 xAI 클라우드 컴퓨터, 뮤즈는 메타의 보안 가상컴퓨터(Muse Secure VM)예요.

머리(모델) 오픈클로·헤르메스는 아무 모델이나 내 키로 붙이고, 그록봇은 발표문에 모델명이 없고, 뮤즈는 메타 자체 모델 Muse Spark예요.

어디로 말 거나 오픈클로·헤르메스는 텔레그램·디스코드·왓츠앱 같은 메신저, 그록봇은 전용 앱과 봇끼리 그룹챗(보도), 뮤즈는 앱·웹·왓츠앱이에요.

어떻게 배우나 오픈클로는 사람이 쓴 설명서(SKILL.md)를 스킬로 써요. 헤르메스는 일을 끝내면 스스로 스킬을 만들고, 쓰면서 고쳐요. 그록봇은 한 번 보여 주면 루틴으로 저장하고(보도), 뮤즈는 중요한 걸 기억하고 “잊어줘”로 지워요.

안전장치 오픈클로는 사용자가 정해요. 제3자 스킬이 사용자 모르게 데이터를 빼낸 사례(Cisco 연구)가 있었어요. 헤르메스는 격리된 실행 환경을 고를 수 있고, 그록봇은 판단이 필요한 일만 사람에게 올려요. 뮤즈는 민감한 일 전 확인, 전 과정 기록, 인터넷 접속 감시를 기본으로 둬요.

값 오픈클로·헤르메스는 무료(MIT)에 모델 비용이 들어요. 그록봇은 구독에 포함되고 사용량은 따로 계산돼요. 뮤즈는 대부분 무료에 유료 구독이 있어요.

뒷마당에서 집을 직접 짓는 로봇과 서비스 아파트로 들어가는 로봇 — 직접 돌리기와 빌려 쓰기 (GPT 이미지 생성)

오픈클로와 헤르메스는 같은 칸(내 컴퓨터, 오픈소스)에 있지만 설계가 달라요. MarkTechPost 정리로는 오픈클로가 메신저를 넓게 잇는 중앙 게이트웨이 쪽이고, 헤르메스는 ‘하고, 배우고, 고치는’ 반복 고리로 스킬 파일을 쌓는 쪽이에요.

4. 메타 뮤즈는 무엇이 다른가

앞의 셋과 비교하면 뮤즈는 다섯 가지가 새로워요.

① 설치가 없는 일반인용이에요. 앱을 받거나 왓츠앱에서 말을 걸면 끝이에요. 메타 발표문 제목부터 ‘모두를 위한 개인 AI 에이전트’예요.

② 머리부터 몸까지 메타가 다 가졌어요. 모델은 Muse Spark, 일하는 컴퓨터는 Muse Secure VM, 창구는 메타 앱과 왓츠앱이에요.

③ 안전장치를 제품 앞에 세웠어요. 인터넷에 나갈 때마다 별도 감시 에이전트(Sentinel)가 승인하고, 비밀번호와 결제수단은 뮤즈가 볼 수 없어요. 메일 발송·구매 전에는 묻고, 한 일은 전부 기록으로 보여 줘요.

④ 돈 버는 방식이 달라요. 저커버그는 많은 토큰을 무료로 주고 거래에서 작은 수수료로 이익을 내겠다고 했어요(TechCrunch 보도). 그래서 Shopify·Walmart·Best Buy 같은 쇼핑 연결을 함께 발표했어요.

⑤ 기기로 나가요. AI 안경에서 이름을 부르면 보고 있는 것을 두고 일하고, 뮤즈 전용 이메일 주소도 생겨요(9월 Connect 발표).

작업실과 인터넷 사이 유리문에서 종이비행기를 검사하는 경비 로봇 — 뮤즈의 감시 에이전트 (GPT 이미지 생성)

숙제도 있어요. TechCrunch는 메타의 개인정보 이력(FTC 합의, 케임브리지 애널리티카)을 짚으며 ‘소비자가 믿을까’를 물었어요. 메일·결제까지 잇는 에이전트라, 안전장치가 약속대로 작동하는지는 지켜봐야 해요. 그리고 2026년 9월 29일 메타 발표 기준으로 미국·캐나다에서만 써요.

5. 누구에게 무엇이 맞나

고르는 기준은 성능보다 ‘무엇을 맡기고, 누구를 믿을지’예요.

이런 분맞는 쪽
내 기계에서 내 규칙대로, 데이터를 밖에 안 내보내고 싶다오픈클로 — 보안 설정도 내 몫
같은 일을 반복시키고, 쓸수록 나아지길 원한다헤르메스 — 스스로 스킬을 쌓는 구조
팀 일을 여러 봇에 나눠 맡기고, 서버 관리는 싫다그록봇 — 구독 필요
설치 없이 메일·예약·쇼핑을 맡기고 싶다메타 뮤즈 — 미국·캐나다만, 메타에 데이터를 맡김
💡 핵심보내기·결제처럼 권한이 큰 일을 맡길수록, 승인 장치가 기본으로 들어 있는 쪽부터 고르세요.

6. 넷 모두에 해당하는 주의

에이전트에 준 권한이 곧 위험의 크기예요. 메일을 보낼 수 있게 하면 잘못 보낼 수도 있어요.

처음엔 ‘확인받고 하기’로 돌리고, 손에 익으면 규칙을 정해 맡기세요. 저도 블로그 발행을 처음엔 매번 직접 승인했고, 지금은 ‘하루 1편 큐’와 ‘발행 전 검사’ 규칙을 정해 맡기고 있어요.

‘완료’라는 말은 결과물로 확인하세요. 에이전트가 했다고 말하는 것과 실제로 된 것은 달라요.

⚠️ 주의결제·메일 발송·계정 설정 권한은 처음부터 ‘묻지 않고 하기’로 두지 마세요.

자주 묻는 질문

Q. 한국에서 메타 뮤즈를 쓸 수 있나요?

2026년 9월 29일 메타 발표 기준 제공 지역은 미국과 캐나다예요. 한국 출시 일정은 메타 발표에서 찾지 못했어요.

Q. 오픈클로와 헤르메스는 무료인가요?

둘 다 MIT 라이선스 오픈소스라 프로그램은 무료예요. 대신 붙여 쓰는 모델의 API 비용과, 늘 켜 둘 컴퓨터가 필요해요.

Q. 그록봇은 따로 돈을 내나요?

xAI 발표(2026년 8월 26일)로는 SuperGrok 요금제와 Cursor 유료 요금제(Pro·Pro+·Ultra·Teams)에 들어 있어요. 사용량은 기존 요금제와 따로 계산돼요.

Q. 메타 뮤즈 유료 요금은 얼마인가요?

메타는 ‘대부분 무료, 더 쓰려면 구독’이라고만 밝혔어요. TechCrunch는 출시 때 Power 월 20달러, Maximum 월 100달러라고 보도했어요(2026년 9월 8일).

오픈클로를 24시간 돌리려고 맥미니 M4를 자동화 전용으로 둔 이야기는 이 글에 있어요.
