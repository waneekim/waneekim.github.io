메타 뮤즈 스파크 오픈 정리, 미국 오픈웨이트 1위의 라이선스와 장비

메타 뮤즈 스파크 오픈 공개 — 미국 오픈웨이트 1위의 조건 (캐릭터는 AI 이미지 생성)

메타(Meta)가 10월 15일 오픈웨이트 모델 뮤즈 스파크 오픈(Muse Spark Open)의 가중치를 허깅페이스에 올렸어요. 4월부터 메타 AI 앱과 API로만 쓰던 뮤즈 스파크(Muse Spark)를 내려받아 돌릴 수 있게 한 판이에요. 식당에 빗대면, 가게 안에서만 팔던 간판 메뉴를 밀키트로 포장해 집에 가져가게 한 셈이에요. 다만 포장에 조건 스티커가 붙어 있고, 데우려면 업소용 오븐이 필요해요.

벤치마크 회사 Artificial Analysis(AA)는 이 모델에 지능 지수 39점을 매겼고, 미국 오픈웨이트 모델 가운데 가장 높아요. 그래도 중국 상위 오픈 모델보다는 낮고, 라이선스는 흔히 말하는 오픈소스와 달라요. 같은 주 미국 2위로 나온 리플렉션 빔은 10월 19일 글에 정리해 뒀어요.

1. 무슨 일: 10월 15일 가중치 공개

메타는 10월 15일 뮤즈 스파크 오픈의 가중치를 허깅페이스 meta-models 계정에 Muse Model License로 공개했어요. 메타 연구 블로그는 이 모델을 ‘지금까지 가장 뛰어난 미국 오픈웨이트 모델’이라고 소개했어요. 모델 카드와 개발자 문서에 나온 내용을 표로 옮겼어요.

항목공개 내용
크기파라미터 8,160억 개 중 420억 개만 한 번에 사용(MoE)
문맥 길이1,048,576토큰(약 100만)
입력과 출력글·이미지·영상·음성을 읽고 글로 답함
가중치 형식메타 제공 BF16·NVFP4 두 가지
라이선스Muse Model License (메타 자체 라이선스)
내려받는 곳허깅페이스(승인제), 아마존 SageMaker AI, 구글 클라우드 Model Garden, 마이크로소프트 Foundry
API로 쓰는 곳베이스텐, 파이어웍스, 그록(Groq), 모달, 네비우스, 오픈라우터, 투게더 AI

MoE(전문가 혼합)는 모델 안의 여러 ‘전문가’ 가운데 일부만 골라 계산하는 구조예요. 계산은 420억 개 몫만 하지만, 돌리려면 8,160억 개 전체를 메모리에 올려야 해요(메타 개발자 문서). AMD·인텔·Unsloth는 자기 하드웨어와 개인 장비용으로 줄인 판을 따로 냈어요. 메타는 코딩과 에이전트 작업에 맞춰 만든 모델이라고 설명했어요.

2. 서비스용 뮤즈 스파크와 무엇이 다른가

뮤즈 스파크 오픈은 8월에 낸 뮤즈 스파크를 바탕으로 안전 학습을 더한 공개판이에요. 메타 개발자 페이지의 설명이에요. 시스템 안전장치 없이 모델만 따로 돌려도 악용에 버티도록 학습을 더 했다고 해요. 파이토치 블로그는 서비스용 뮤즈 스파크 1.3과 같은 기반 모델을 쓴다고 적었어요.

메타 뮤즈 모델이 나온 순서를 정리하면 이래요(날짜는 메타 발표와 AA 기록 기준).

날짜무슨 일
4월 8일뮤즈 스파크 첫 공개 — 메타 AI 앱·비공개 API, 가중치 비공개
7월 9일뮤즈 스파크 1.1
8월 5일뮤즈 스파크 1.2와 코딩 에이전트 Muse Code
8월 10일작은 모델 뮤즈 글리머(Muse Glimmer), Apache 2.0 오픈웨이트
9월 2일뮤즈 스파크 1.3
10월 12일서비스용 상위 모델 뮤즈 원더(Muse Wonder)
10월 15일뮤즈 스파크 오픈 가중치 공개

같은 AA 지수로 보면 공개판은 서비스용 최신판보다 낮아요. 10월 20일 AA 표에서 같은 xhigh 추론 설정으로 뮤즈 스파크 1.3은 45점, 1.2는 40점, 오픈은 39점이에요. 찾은 자료에서 메타는 이 차이의 까닭을 따로 설명하지 않았어요.

4월의 뮤즈 스파크는 라마(Llama) 시절과 달리 메타가 처음으로 가중치를 공개하지 않은 모델이었어요(The Decoder). 1.1부터 1.3까지도 API로만 나왔고, 뮤즈 스파크 계열에서 가중치가 풀린 건 이번이 처음이에요. 메타 AI 앱의 개인 에이전트 뮤즈가 서비스용 뮤즈 스파크로 움직인다는 건 9월 27일 글에, 뮤즈 스파크 1.3이 나온 주의 이야기는 9월 8일 사이버보안 모델 글에 있어요.

3. 라이선스: 오픈소스가 아닌 오픈웨이트

가중치는 무료로 받아 고치고 팔 수도 있지만, 조건이 붙은 메타 자체 라이선스예요. 라이선스 원문은 사용·복제·수정·미세조정·증류·병합·재배포·판매를 허용한다고 적은 뒤, 아래 조건을 달았어요.

조건원문 내용
사용 정책라이선스에 붙은 사용 정책을 지키고, 다시 나눌 때 라이선스·정책 사본을 함께 넣기
이름 표시쓰는 제품의 화면이나 문서·웹사이트·설정 메뉴에 ‘Built with Muse Spark Open’ 표시
파생 모델이 모델이나 그 출력으로 만들거나 학습·미세조정·증류한 모델에도 같은 조건
API 판매모델을 API로 남에게 파는 회사가 계열사 포함 12개월 총매출 2,000만 달러를 넘으면, 먼저 메타에 알리고 따로 서면 계약
판매 조건 예외회사 안 사용, 연구, API 판매가 아닌 사업, 내 제품 속 기능
금지 분야군사·핵·무기·불법 약물, 중요 기반시설 운영, 자격 없는 금융·법률·의료 행위, 악성코드 만들기 등
나이18세 미만을 위한 모델이 아님

뮤즈 스파크 오픈 라이선스 한 장 정리 — 누구나 지킬 것, API로 팔 때의 매출 2,000만 달러 기준, 허깅페이스 승인제 (직접 제작)

그래서 ‘오픈소스’보다 ‘오픈웨이트’가 맞는 이름이에요. Apache 2.0이나 MIT 같은 오픈소스 라이선스에는 매출 기준, 화면 표시 의무, 사용 분야 제한이 없어요. 메타의 작은 모델 뮤즈 글리머와 리플렉션 빔은 Apache 2.0이에요.

AA도 이 모델을 ‘상업 이용에 조건이 있는 오픈웨이트’로 분류했어요. 가중치·학습 방법·데이터 공개 정도를 매기는 AA 개방성 지수는 100점 만점에 28점이고, 학습 데이터 항목은 0점이에요.

밀키트 비유로 말하면, 완성된 재료는 받았지만 레시피 원본은 받지 못한 셈이에요. 메타는 학습 데이터를 공개 자료, 인터넷 수집, 제3자 구매, 메타 제품에서 나온 자료, 합성 데이터라고 종류만 밝혔어요. 허깅페이스에서 내려받을 때도 이름·생년월일·국가·소속을 적어 승인을 받아야 해요.

조건 자체는 메타에게도 새롭지 않아요. 라마 4 라이선스는 ‘월 사용자 7억 명을 넘으면 따로 허가’와 ‘Built with Llama’ 표시를 요구했는데, 이번엔 기준이 사용자 수에서 ‘API 판매와 회사 매출’로 바뀌었어요. The New Stack은 이 라이선스가 문샷 AI의 Kimi K3 라이선스와 비슷하다고 짚었고, AA 분류에서도 GLM-5.3·Kimi K3 같은 중국 상위 모델 일부가 같은 ‘조건부’ 칸에 있어요.

💡 핵심가중치는 열렸지만 쓰는 조건은 메타가 정해요. 회사 안 사용과 내 제품 기능은 넓게 열려 있고, API 재판매는 큰 회사일수록 계약이 필요해요.

4. 내려받기 전에: 크기와 장비

메타가 낸 가장 작은 공식 형식(NVFP4)도 파일이 약 533GB라서, 개인 PC가 아니라 GPU 서버나 고사양 Mac 여러 대가 필요해요. 허깅페이스 파일 크기 합계(우리 계산)와 메타 개발자 문서의 권장 구성을 표로 옮겼어요.

형식파일 크기 · 권장 장비
BF16 (16비트 원본)약 1.64TB · 엔비디아 B300 같은 GPU 8장, GPU 메모리 약 2TB
NVFP4 (전문가 부분만 4비트)약 533GB · 블랙웰 GPU 4장 서버 한 대, 또는 H200 8장
AMD용 FP8·MXFP4AMD 인스팅트 MI355X·MI350X 8장
인텔용 INT4인텔 제온 6 CPU 서버
Mac용 NVFP4M5 Ultra Mac Studio 2대(각 512GB) 또는 4대(각 256GB)
Unsloth 2비트 GGUF시스템 메모리와 GPU 메모리를 합쳐 약 300GB

모델 카드는 NVFP4로 돌릴 때 GPU 메모리를 최소 700GB, BF16은 2TB로 잡으라고 적었어요. 파일보다 큰 까닭은 답을 만들 때 쓰는 캐시와 실행 공간이 더 들기 때문이에요(메타 개발자 문서). 양자화(가중치를 적은 비트로 줄이기)를 한 판은 드문 경우 원본과 품질이 조금 다를 수 있다고 모델 카드에 적혀 있어요.

작은 토스터와 큰 업소용 오븐 사이에서 커다란 밀키트 상자를 든 로봇 — 8,160억 파라미터를 올릴 큰 장비가 필요한 뮤즈 스파크 오픈을 빗댄 그림 (AI 이미지 생성)

메타가 가장 앞세운 구성은 Mac Studio 두 대예요. 썬더볼트 5로 두 대를 바로 이어 1TB 통합 메모리처럼 쓰고, 이 구성에서 오픈소스 앱 고치기와 영상 편집 자동화를 시험했다고 했어요. 메타는 이 급의 모델이 데스크톱에서 도는 첫 사례라고 설명해요. 다만 512GB 메모리 Mac Studio는 10월 15일 기준 아직 일반 판매 전이라고 The New Stack이 전했어요. 메타 문서에는 256GB 모델 4대를 잇는 구성도 함께 적혀 있어요.

5. 성적표: 독립 평가와 회사 표

AA 지수 39점은 미국 오픈웨이트 1위지만, 오픈웨이트 전체로 보면 중국 모델 여러 개가 위에 있어요. AA는 10월 16일 빔 평가 글에서 빔(30점)이 뮤즈 스파크 오픈(39점) 다음인 미국 2위라고 적었어요. 10월 20일 AA 표에서 회사마다 가장 높은 오픈웨이트 모델을 골라, 뮤즈 스파크 오픈보다 높은 곳과 미국 2위를 함께 놓으면 이래요.

모델 (회사·나라)AA 지수
MiMo-V2.6-Pro (샤오미·중국)46점

딥시크 V4.1 Flash 1017은 10월 17일에 나온 판이라, 10월 16일 기사의 순위와 조금 달라요. 유럽의 미스트랄 라지 4는 38점이지만 10월 20일 현재 가중치 공개 전이라 AA가 오픈웨이트로 분류하지 않았어요. AA가 직접 잰 세부 점수도 있어요. 지식 평가 AA-Omniscience에서 39%를 맞혔고, 모를 때 ‘모른다’ 대신 틀린 답을 낸 비율(환각률)은 24%로 빔(47%)·GLM-5.3(30%)·Kimi K3(53%)보다 낮았어요. 반면 명령줄 작업 평가 Terminal-Bench 4.0은 8.1%로, GLM-5.3(42%)·MiMo-V2.6-Pro(35%)보다 크게 낮아요.

메타 모델 카드의 비교 표에서는 도구·에이전트 과제가 강하고, 코딩은 중국 상위 모델보다 낮아요. MCP 서버 도구를 쓰는 과제 MCP-Atlas는 89.2, 직무 과제 JobBench는 61.8로 비교한 모델 중 가장 높아요.

반면 터미널 작업 Terminal-Bench 2.1은 76.4로 Kimi K3(85.0)·GLM 5.3(83.9)보다 낮고, 긴 코딩 과제 DeepSWE 1.1도 60으로 Kimi K3(68)보다 낮아요. 정리하면 도구·에이전트 과제는 강하고 코딩·터미널은 중국 상위 모델 아래예요.

다만 회사 표는 출처가 섞여 있어서 칸끼리 그대로 비교하기 어려워요. 메타 평가 방법 문서를 보면 AA에서 가져온 값, 공식 순위표 값, 메타가 직접 돌린 값, 각 회사가 스스로 밝힌 값이 한 표에 들어 있어요.

DeepSWE는 모델마다 쓴 실행 도구도 달라요. 뮤즈는 Muse Code, GLM은 mini-swe-agent, 큐웬은 Claude Code, Kimi는 Kimi Code예요. 메타는 다른 회사 모델을 돌릴 때 설정을 그 모델에 맞추지 않아 최고 성능이 안 나왔을 수 있다고 직접 적었어요.

표의 AA 지수는 공개 8일 전인 10월 7일 AA에서 받아 온 값이라고 문서에 적혀 있어요. AA가 공개 전에 미리 잰 점수라는 뜻이라, 다른 기관 평가가 더 쌓여야 판단이 단단해져요. 안전 점수 가운데 StrongREJECT v2는 메타 내부 벤치마크이고, 전체 평가 보고서는 ‘곧’ 내겠다고 했어요.

6. API 값과 도입 전 점검

API로 쓰면 100만 토큰당 입력 1.25달러, 출력 4.25달러예요. 10월 20일 오픈라우터에 올라온 업체 다섯 곳(모달·투게더·네비우스·파이어웍스·베이스텐)이 모두 같은 값이었어요. 8월 메타 API의 뮤즈 스파크 1.2 표준 요금과도 같은 숫자예요.

AA는 이 값이 비슷한 크기 오픈웨이트 모델의 중간값(입력 0.43달러, 출력 1.68달러)보다 비싸다고 평가했어요. 대신 초당 142토큰으로 빠르고, 지수 평가에 쓴 출력 토큰이 1억 1,000만 개로 적은 편이에요.

자주 묻는 질문

Q. 뮤즈 스파크 오픈은 무료인가요?

가중치는 라이선스상 무료로 받을 수 있어요(허깅페이스 승인 필요). API로 쓰면 업체 요금이 들고, 10월 20일 오픈라우터 업체들은 100만 토큰당 입력 1.25달러, 출력 4.25달러였어요. API로 남에게 파는 큰 회사는 메타와 따로 계약해야 해요.

Q. 오픈소스라고 불러도 되나요?

가중치는 공개됐지만 학습 데이터는 종류만 밝혔고, 라이선스에 매출 기준·이름 표시·사용 분야 제한이 있어요. 그래서 ‘오픈웨이트’가 정확한 이름이에요. AA도 ‘상업 이용에 조건이 있는 오픈웨이트’로 분류했어요.

Q. 개인 PC에서 돌릴 수 있나요?

어려워요. 메타 공식 4비트판도 약 533GB이고, 가장 작게 줄인 Unsloth 2비트판도 메모리를 약 300GB 써요. 메타가 내세운 구성도 512GB 메모리 Mac Studio 2대예요.

Q. 한국어도 잘하나요?

모델 카드는 100개 넘는 언어 데이터로 학습했다고 적었지만, 한국어 성능을 따로 밝힌 자료는 찾지 못했어요. 모델 카드도 학습 데이터의 모든 언어를 평가하지는 않았다고 적었어요. 우리 업무 예시로 직접 시험해 보는 게 안전해요.
