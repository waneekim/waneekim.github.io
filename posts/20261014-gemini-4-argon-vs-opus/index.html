제미나이 4 아르곤 출시, 오퍼스 5.5와 같은 지시로 직접 비교

아르곤 vs 오퍼스 5.5 — 같은 지시로 직접 비교 (캐릭터는 AI 이미지 생성)

제미나이 4 아르곤이 모두에게 열리자, 두 모델에게 같은 3D 젤리곰 화면을 만들게 한 비교 영상이 돌았어요. 처음 봤을 때는 “오퍼스 5.5 쪽이 훨씬 낫네” 싶었어요. 그런데 영상 한 편으로 정해도 될까요?

같은 레시피를 두 요리사에게 주고 맛을 보면, 한 접시만으로는 실력보다 그날 컨디션이 더 크게 보일 때가 있어요. 그래서 저희도 같은 지시문을 두 모델에 직접 보내 보고, 걸린 시간과 비용까지 쟀어요.
한 번 해 본 결과로는 ‘훨씬 낫다’고 할 차이는 없었어요. 둘 다 처음엔 곰이 안 보였고, 오류를 알려 주자 한 번에 고쳤어요. 값은 11월 30일까지 아르곤이 절반이에요.

같은 레시피 카드를 들고 젤리곰 쟁반 두 개를 돋보기로 비교하는 로봇 — 같은 지시로 두 모델 비교 (AI 이미지 생성)

1. 무슨 일: 아르곤 일반 공개

구글이 2026년 10월 14일(한국 시간) 제미나이 4 아르곤(Gemini 4 Argon)을 개발자·기업·구독자에게 열었어요. 9월 30일 처음 발표했을 때는 페어윈드 프로그램에 든 일부 사이버 방어자와 구글 내부 팀만 썼어요. 이번에 Gemini API와 구독 서비스로 넓어진 거예요.

구글 한국어 블로그는 이렇게 적었어요. “아르곤은 오늘부터 전 세계에 순차 출시됩니다.” 순차 출시라서 같은 요금제여도 내 계정에는 며칠 늦게 보일 수 있어요. 같은 날 페어윈드 프로그램 파트너도 수백 곳 더 늘린다고 밝혔어요.

2. 어디서, 어떤 요금제로 쓰나

제미나이 앱과 검색의 AI 모드는 AI Pro부터, 안티그래비티와 AI 스튜디오 구독 혜택은 AI Ultra만 써요. 발표문 각주와 본문을 표로 옮겼어요. 무료·AI Plus 요금제는 발표에 나오지 않아요.

사용하는 곳쓸 수 있는 요금제
제미나이 앱 · 검색의 AI 모드AI Pro · AI Ultra

기업비즈니스용 제미나이 · Gemini API · 안티그래비티

API 요금은 출시 기념가로 시작해요. Gemini API 가격 페이지(10월 13일 갱신) 기준 100만 토큰당 값이에요.

구분11월 30일까지 (기념가) → 12월 1일부터
입력2달러 → 4달러
출력 (생각 토큰 포함)10달러 → 20달러
캐시된 입력0.10달러 → 0.20달러

한 번에 다루는 양은 입력과 출력을 합쳐 100만 토큰이에요. 구글은 “1백만 통합 입출력 토큰 한도”라고 불러요. 클로드 오퍼스 5.5의 API 값은 입력 4달러·출력 20달러라서, 12월부터는 두 모델의 API 값이 같아져요.

과학자를 위한 프로그램도 있어요. 선정된 과학자 1만 명에게 안티그래비티 최상위 사용량 등급을 6개월 무료로 주고, 신청을 받아 차례로 승인해요.

3. 구글이 내세운 사례

구글은 코딩·과학·업무 문서 사례를 앞세웠고, 3D 시각화를 따로 한 꼭지로 꼽았어요.
① 크롬: 4,000만 줄짜리 크로미움 코드 중 약 600만 줄 규모의 옛 기능 폴더에서 핵심 코드를 떼어 냈어요. 수개월 걸릴 일을 몇 주 만에 끝냈다고 해요.
② 젬마: 오픈 모델 젬마 4 E2B를 A100에서 vLLM으로 돌리는 속도를 2.85배 높였어요.
③ 고고학: 약 50GB의 항공 라이다(LiDAR) 스캔 데이터와 도면·기록을 모아 미국 차코 캐니언의 3D 모델을 다시 만들었어요.
④ 신약: 아이소모픽 랩스는 복잡한 PDF와 특허를 읽는 일을 몇 주에서 몇 시간으로 줄였다고 해요.

벤치마크로는 금융·코딩·법률·세무를 보는 Vals Index 1위, 공간 추론을 보는 ERQA 87%를 내세웠어요. 이번 실험과 가장 가까운 건 ‘복잡한 3D 시각화’ 꼭지예요. 구글은 직원들이 브라우저에서 바로 도는 3D 시각화·게임·인터랙티브 애니메이션 시제품을 아르곤으로 만든다고 소개했어요.
위 숫자는 모두 구글이 공개한 값이에요. 그래서 3D 화면 만들기만큼은 직접 시험해 봤어요.

4. 같은 지시로 젤리곰 화면을 만들어 봤어요

두 모델에게 같은 영어 지시문으로 3D 젤리곰 웹페이지를 만들게 했어요. 둘 다 처음엔 곰이 안 보였고, 오류를 한 번 알려 주자 고쳤어요.

  • 지시는 이랬어요. 반투명하고 윤기 나는 젤리곰을 6색 이상, 떨어지고 서로 튕기고 마우스로 잡아 던질 수 있게, 색 고르기·탄성 슬라이더·‘곰 더 붓기’ 버튼을 넣은 HTML 파일 하나.
  • 오퍼스 5.5는 저희 LLM 중계기(클로드 구독)로, 아르곤은 Gemini API로 바로 보냈어요.

같은 지시로 오퍼스 5.5와 제미나이 4 아르곤이 만든 3D 젤리곰 웹페이지 — 처음 오류, 고치기 1번, 시간·토큰·비용 비교 (직접 제작)

처음 받은 두 페이지는 엣지 브라우저로 열자 곰 없이 빈 화면만 나왔어요. 둘 다 곰 모양을 만드는 부분에서 오류가 났어요. 그래서 브라우저 콘솔에 뜬 오류 문장을 그대로 붙여 “고쳐서 전체 HTML을 다시 줘”라고 한 번 보냈어요. 둘 다 이 한 번으로 고쳐졌어요.

고친 페이지를 같은 동작으로 녹화 — 위 오퍼스 5.5, 아래 제미나이 4 아르곤 (직접 제작)

녹화는 같은 순서로 했어요. 곰 하나를 잡아 던지고, ‘곰 더 붓기’를 두 번 누르고, 탄성 슬라이더를 끝까지 올렸어요.

녹화 8초 지점의 같은 순간 — 오퍼스 5.5는 밝은 배경에 흩어진 곰, 아르곤은 분홍빛 배경에 쌓인 곰 (직접 캡처)

모양은 꽤 달랐어요. 오퍼스 5.5는 밝은 배경에 윤기 나는 곰이 서 있는 자세로 흩어지고, 물리 계산을 외부 라이브러리 없이 직접 짰어요. 아르곤은 분홍빛 배경에 색이 진한 곰이 바닥에 누워 쌓이고, 물리 라이브러리와 화면 돌리기 기능을 가져다 썼어요. 색 칩에 무작위 색 버튼도 하나 더 넣었어요. 어느 쪽이 더 예쁜지는 취향 차이 정도였어요. 지시한 기능은 둘 다 다 들어갔어요.

비용은 아르곤만 실제 API로 냈어요. 오퍼스 5.5는 클로드 구독으로 돌려 따로 돈이 나가지 않았고, 위 값은 API 가격으로 바꿔 계산한 거예요.

5. 무슨 뜻인가: 영상 한 편은 약해요

같은 지시도 돌릴 때마다 결과가 달라서, 영상 한 편으로 ‘훨씬 낫다’를 가르기는 어려워요.

  • 몇 번 돌려 잘 나온 걸 골랐는지, 안티그래비티나 클로드 코드 같은 에이전트로 여러 번 고쳤는지에 따라 같은 모델도 결과가 크게 달라져요.
  • 이번에 더 눈에 띈 건 두 모델 모두 처음 답이 바로 돌지 않았다는 점이에요. 어느 모델을 쓰든 브라우저로 열어 보고 오류를 알려 주는 확인 한 번이 필요해요.

지금 고른다면 이렇게 보면 돼요.
API로 긴 작업을 많이 돌리는 분은 아르곤을 11월 30일 기념가 동안 시험해 볼 만해요. 같은 일을 절반 값에 돌려 볼 수 있어요.
이미 클로드 구독과 클로드 코드로 일하는 분은 오퍼스 5.5를 그대로 써도 돼요. 이번 결과만으로 옮길 이유는 크지 않았어요.
