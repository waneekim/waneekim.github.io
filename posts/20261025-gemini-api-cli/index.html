구글 제미나이 API CLI 공개, AI 일꾼의 주문 창구는 뭐가 편할까

제미나이 API CLI — AI 일꾼의 주문 창구, 뭐가 편해질까? (캐릭터는 AI 이미지 생성)

학교 축제 준비를 맡은 반장을 떠올려 볼게요. 포스터는 미술실, 안내 방송은 방송실, 배경 음악은 음악실에 가서 부탁해야 하는데, 교실마다 신청서 모양이 달라요. 그런데 교무실에 주문 창구 하나가 생겨서, 짧은 쪽지만 내면 결과물을 사물함에 넣고 사물함 번호를 알려 준다면 어떨까요?

구글이 AI 일꾼(에이전트)이 명령 한 줄로 제미나이의 그림·영상·음악·목소리 만들기와 문서 읽기를 부를 수 있는 ‘제미나이 API CLI’를 실험 단계로 공개했어요. 누구나 코드를 볼 수 있는 오픈소스로 나왔어요.

AI 일꾼의 주문 창구 — 짧은 명령 한 줄을 내면, 제미나이가 만든 결과를 파일로 저장하고 위치만 알려 줘요 (구글 공식 설명서를 보고 직접 제작)

③ 아직 실험 단계(프리뷰)이고, 제미나이 API 키가 있어야 써요
2026년 10월 25일 기준 · 구글 공식 깃허브 확인

1. 제미나이 API CLI가 뭐예요?

궁금이CLI가 뭐예요? 이름이 너무 어려워요.
AI 로봇마우스 대신 글자로 컴퓨터에 일을 시키는 도구예요. 이번 건 제미나이에게 일을 맡기는 주문 창구라고 보면 돼요.

CLI는 터미널, 그러니까 검은 화면에 글자로 명령을 쓰는 창에서 쓰는 프로그램이에요. 이름은 gemini-api예요. 구글 설명서에 나온 예시는 이렇게 생겼어요.

gemini-api image "개발 도구용 친근한 로봇 마스코트" --out ./assets/

이 한 줄이면 그림이 만들어져 폴더에 저장되고, AI 일꾼은 그 파일 위치를 받아 다음 일을 이어 가요. 맥·리눅스·윈도우에서 프로그램 하나만 깔면 돼요.

2. 무엇을 시킬 수 있어요?

이런 주문하는 일
만들기그림·영상·음악·목소리(읽어 주기)
읽기PDF·사진·소리 파일 내용 살피기, 받아쓰기
맡기기오래 걸리는 조사를 뒤에서 돌리고 나중에 결과 받기

AI타임스 보도에 따르면 받아쓰기 결과는 시간이 적힌 자막 파일(SRT)로도 받을 수 있어요. 오래 걸리는 일은 ‘번호표’(작업 번호)를 받아 두었다가 나중에 결과를 찾아가는 방식이에요.

3. 누가, 왜 쓰는 거예요?

궁금이그럼 제미나이 앱이랑 뭐가 달라요?
AI 로봇앱은 사람이 쓰는 창구고, 이건 AI 일꾼이 쓰는 창구예요. 다른 회사 AI 일꾼도 쓸 수 있어요.

구글은 설명서에서 코덱스, 클로드 코드, 안티그래비티, 오픈클로, 헤르메스처럼 명령을 직접 실행할 수 있는 AI 일꾼이라면 무엇이든 쓸 수 있다고 밝혔어요. 예를 들어 클로드 코드에게 홈페이지를 만들게 하면서 “마스코트 그림과 환영 음성은 제미나이로 만들어”라고 시키는 식이에요.

왜 만들었을까요? AI타임스 보도에 따르면 지금까지 AI 일꾼은 모델 이름을 일일이 찾고, 한 번 쓰고 버릴 코드를 짜거나 긴 명령을 반복해야 했어요. 신청서 모양이 교실마다 달랐던 거죠. 이 도구는 모든 주문을 같은 모양으로 맞추고, 쓸 수 있는 명령과 주문서 양식을 도구 안에서 바로 찾아보게 했어요.

💡 한 줄로AI 일꾼끼리 일을 나눠 맡는 시대에, 구글이 "우리 기능은 이 창구로 부르세요" 하고 문을 하나 낸 셈이에요.

4. 바로 믿고 써도 돼요?

궁금이그럼 아무 AI한테나 맡겨도 돼요?
AI 로봇아직 시험판이에요. 열쇠(API 키) 관리도 꼭 챙겨야 해요.
⚠️ 알아 둘 점① 구글 스스로 '실험적인' 도구라고 적었고, 10월 23일 기준 0.4.4 버전이에요. 명령 모양이 바뀔 수 있어요.
② 도구의 코드는 오픈소스지만, 실제로 쓰려면 구글 AI 스튜디오에서 만든 제미나이 API 키가 필요해요. 요금은 제미나이 API 요금 안내를 따로 확인해야 해요.
③ AI 일꾼에게 열쇠를 맡기는 거라, 일꾼이 엉뚱하게 많이 부르면 그만큼 쓰게 돼요.

다행히 안전장치도 있어요. --dry-run을 붙이면 실제로 보내지 않고 “이렇게 보낼 거예요”만 보여 줘요. 이때 열쇠 값은 가려서 보여 준다고 구글은 설명했어요. 열쇠는 컴퓨터의 비밀번호 보관함(키체인)에 넣어 둘 수도 있어요. AI에게 비밀번호를 직접 주지 않는 방법은 지난 글 1Password 에이전트 로그인에서도 다뤘어요.

5. 나는 뭘 하면 돼요?

  1. 개발자가 아니라면 지금은 알아 두기만당장 앱이 바뀌는 소식은 아니에요. AI 일꾼끼리 도구를 빌려 쓰는 흐름이라는 것만 기억해요.
  2. 클로드 코드·코덱스를 쓴다면 작게 시험하기먼저 --dry-run 으로 무엇을 보낼지 보고, 그림 한 장처럼 작은 일부터 맡겨요.
  3. 열쇠와 사용량 챙기기API 키는 글이나 코드에 그대로 적지 말고, 사용량 화면을 가끔 확인해요.
💡 우리 이야기이 블로그도 AI 일꾼(클로드 코드)이 그림 만드는 명령을 직접 불러 삽화를 만들어요. 다만 이번 도구는 아직 써 보지 않았어요. 써 보면 따로 후기를 남길게요.
✅ 한눈에 정리· 제미나이 API CLI는 AI 일꾼이 제미나이 기능을 명령 한 줄로 부르는 주문 창구예요
· 그림·영상·음악·목소리 만들기, 문서·소리 읽기, 오래 걸리는 조사 맡기기를 할 수 있어요
· 클로드 코드·코덱스처럼 다른 회사 AI 일꾼도 쓸 수 있어요
· 아직 실험 단계이고, API 키와 요금은 따로 챙겨야 해요

오늘의 큰 흐름: AI 회사들이 ‘내 앱으로 오세요’에서 ‘어느 AI 일꾼이든 우리 기능을 불러 쓰세요’로 문을 넓히고 있어요.
