RTX Spark 정리, 로컬 AI 성능과 제품별 출하 일정

RTX Spark — 로컬 AI와 실행 경계를 함께 봐요 (캐릭터는 GPT 이미지 생성)

“큰 AI 모델을 내 노트북에서 돌리면, 클라우드 비용과 자료 전송 부담을 줄일 수 있을까요?” 마이크로소프트와 엔비디아가 10월 7일 공개한 RTX Spark PC 소식은 이런 기대를 겨냥해요. 다만 최대 메모리, 실행할 수 있는 모델, 제품별 출하 날짜를 나눠 읽어야 해요.

책상 옆에 작업실을 마련하는 것과 비슷해요. 넓은 작업대가 있으면 큰 일을 펼칠 수 있지만, 어떤 서랍을 열 수 있는지도 정해야 해요.
이번 발표는 로컬 AI용 하드웨어와 에이전트의 실행 경계를 함께 다뤄요. 직접 장비를 시험한 후기가 아니라 두 회사의 발표를 대조한 정리예요.

1. RTX Spark는 어떤 제품인가요?

RTX Spark는 여러 제조사의 Windows PC에 들어가는 엔비디아 플랫폼이에요. 엔비디아의 10월 7일 발표는 Blackwell RTX GPU와 Grace CPU, 최대 128GB 통합 메모리를 설명해요. Surface Laptop Ultra를 비롯한 노트북과 소형 데스크톱이 이 플랫폼을 사용해요.

따라서 ‘RTX Spark 한 대’라는 표현만으로 사양이 같다고 보면 안 돼요. 실제 구매를 검토할 때는 PC 모델명과 메모리 옵션까지 맞춰 봐야 해요. 아래 표의 숫자도 모든 제품의 기본 사양을 뜻하지 않아요.

발표 항목읽을 때 구분할 점
통합 메모리 최대 128GB구매할 제품의 옵션을 별도로 확인
Surface에서 120B 초과 모델 실행회사 설명이며 모든 모델의 속도 보장 아님
노트북과 소형 데스크톱출하 일정이 서로 다름

2. 128GB와 120B는 무엇이 다른가요?

128GB는 메모리 용량이고, 120B는 모델 파라미터 1,200억 개를 뜻해요. 마이크로소프트의 Surface 발표는 최대 128GB 통합 메모리로 120B를 넘는 모델을 로컬에서 실행할 수 있다고 설명해요. 이는 회사가 제시한 실행 가능 범위이며, 이 글에서 측정한 결과가 아니에요.

메모리에 들어가는 것과 기다릴 만한 속도로 끝나는 것은 다른 질문이에요. 예를 들어 문서 한 장을 요약하는 요청과 긴 자료를 읽고 코드를 여러 번 고치는 요청을 같은 조건으로 볼 수는 없어요. 큰 숫자 하나보다 자신이 돌릴 모델과 작업 조건을 먼저 적어 두는 편이 비교에 도움이 돼요.

💡 핵심모델을 실행할 수 있는지와 쓸 만한 속도인지는 따로 봐요.

3. 모두 10월 16일에 나오나요?

10월 16일은 발표된 RTX Spark 노트북의 출하 시작 일정이에요. 엔비디아는 노트북 예약과 10월 16일 판매, 소형 데스크톱의 11월 판매를 구분했어요. 마이크로소프트도 Surface Laptop Ultra는 10월 16일, Surface RTX Spark Dev Box는 미국에서 11월 출하로 안내했어요.

9월 IFA 안내에는 소형 PC까지 ‘10월’로 묶인 표현이 있었지만, 이 글에서는 더 최근인 10월 7일 제품별 안내를 기준으로 삼았어요. 한국 판매일·원화 가격·구성별 재고는 이번에 확인한 자료로 확정하지 않았어요.

4. MXC는 무엇을 막아 주나요?

MXC는 에이전트가 접근할 파일과 네트워크의 범위를 실행 환경에서 제한하는 계층이에요. Microsoft Execution Containers의 약자예요. 마이크로소프트는 10월 7일 정식 제공을 발표했어요. 개발자나 조직이 정책을 정하면 에이전트의 판단과 별개로 실행 시점에 그 경계를 적용하는 구조예요.

개발자 문서는 프로세스·세션 등 격리 방식마다 특성이 다르다고 설명해요. 특히 Permissive 모드는 정책에서 허용하지 않은 접근을 기록하면서도 통과시키므로, 기록이 남는다는 이유만으로 차단 중이라고 생각하면 안 돼요. Entra·Agent 365의 일부 관리 연동은 같은 문서에서 ‘예정’으로 구분해요.

로컬 AI PC 검토 때 하드웨어 사양, 실제 작업 성능, 에이전트 실행 권한을 나눠 확인하는 기준 (직접 제작)

5. 로컬 실행과 안전은 같은 말일까요?

내 PC에서 실행한다는 사실만으로 자료 접근과 외부 연결이 통제되지는 않아요. Windows 발표는 로컬과 클라우드를 함께 사용하는 방향을 설명해요. 따라서 ‘로컬 AI PC’라는 이름이 모든 요청의 오프라인 처리를 보장한다는 뜻은 아니에요.

이 글의 검토 제안은 세 가지예요. 실제 사용할 앱이 어느 작업에서 외부 서비스를 부르는지 확인하고, 읽을 폴더와 수정할 폴더를 나누고, 중단 후 남은 결과물을 찾는 방법을 마련해요. 예를 들어 초안 폴더 수정은 허용하되 원본 보관 폴더는 읽기만 허용하는 식으로 업무 범위를 적어 볼 수 있어요. 이는 설정을 검토하는 예시이며 직접 실행해 검증한 설정값은 아니에요.

6. 구매 전에 어떤 측정을 기다릴까요?

실제 사용할 모델과 장시간 작업의 측정값이 필요해요. Microsoft 발표의 첫 토큰 속도 비교는 회사가 의뢰한 사전 생산 장비 시험이에요. 사용 모델과 입력 길이가 정해진 조건이며, 모든 요청의 속도나 전체 작업 완료 시간을 뜻하지 않아요. 회사 발표를 독립 리뷰처럼 읽지 않는 것이 출발점이에요.

구매 검토표에는 모델 이름, 메모리 구성, 첫 응답 시간, 완료 시간, 발열·소음, 전원 연결 여부를 함께 적어 보세요. 이 항목들은 이 글이 제안하는 비교 기준이에요. 매일 하는 일 하나를 클라우드 방식과 비교하면 장비 가격뿐 아니라 운영 부담도 보이게 돼요.

지금 확실하게 말할 수 있는 변화는 로컬 모델을 실행할 하드웨어와 에이전트 통제를 같은 발표에서 다룬다는 점이에요. 얼마나 빠르고 경제적인지는 출시 제품의 동일 조건 측정으로 판단할 부분이에요.

오늘의 큰 흐름: 에이전트 보안이 운영체제의 실행 경계로 내려오고 있어요. 하드웨어 성능과 권한 통제를 함께 평가할 시점이에요.

자주 묻는 질문

Q. RTX Spark PC는 전부 128GB인가요?

아니에요. 공식 발표는 ‘최대’라고 설명해요. 같은 플랫폼이라도 제품과 옵션을 확인해야 해요.

Q. 10월 16일에 한국에서도 살 수 있나요?

확인한 발표만으로 한국 판매일을 확정할 수는 없어요. 국내 판매 페이지의 일정과 구성, 보증 조건을 따로 확인하세요.

Q. MXC가 있으면 어떤 에이전트든 자동으로 안전해지나요?

그렇게 보장하는 기능은 아니에요. 에이전트의 연동 여부와 격리 방식, 실행 정책을 확인해야 해요. 허용 모드에서는 기록과 차단의 동작도 달라요.

로컬 모델을 이해할 때 전체 파라미터와 활성 파라미터를 구분하는 방법은 미스트랄 라지 글에서 이어 볼 수 있어요.
