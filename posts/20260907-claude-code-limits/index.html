Claude Code 요금과 한도 — 실사용자가 정리한 구조와 한도 안 걸리는 사용법

Claude Code를 쓰기 시작하면 두 가지 질문이 생깁니다. “얼마 내야 하나”와 “얼마나 쓸 수 있나”. 요금은 간단한데 한도 구조는 처음엔 헷갈립니다. 블로그 운영 시스템을 이걸로 매일 굴리는 입장에서, 구조와 실전 요령을 정리합니다.

⚠️ 요금·한도는 자주 바뀝니다. 이 글은 2026-09-07 기준이고, 결제 전 공식 요금 페이지와 공식 도움말 확인은 필수입니다.

💰 1. 요금 — 구독에 포함, 별도 과금 없음

Claude Code는 Claude 유료 구독(Pro 이상)에 포함됩니다. 따로 API 키를 사거나 사용량 과금을 걱정할 필요가 없어요.

플랜월 요금대상
Pro$20 (연간 결제 시 월 $17)개인 — 저는 이걸로 시작했습니다
Max$100 / $200 (5x / 20x)헤비 유저 — Pro 대비 5배/20배 사용량

무료 플랜에서는 Claude Code를 쓸 수 없습니다. 구독 선택이 고민이라면: ChatGPT Plus vs Claude Pro

⏳ 2. 한도 구조 — 두 개의 창이 겹쳐 있습니다

① 5시간 롤링 윈도우 — 첫 메시지를 보낸 시점부터 5시간짜리 창이 열리고, 그 안에서 쓸 수 있는 양이 정해져 있습니다. 창이 지나면 다시 채워져요. Pro 기준 통상 수십 회 메시지 수준으로 알려져 있는데(집계 기준 5시간당 약 45회), 작업의 무게에 따라 체감은 크게 달라집니다.

② 주간 상한 — 5시간 창과 별개로 주 단위 총량 상한이 있습니다. 매일 장시간 돌리는 헤비 유저가 아니면 잘 안 닿지만, 존재는 알아둬야 합니다.

③ 공용 풀 — 중요한 포인트. Claude Code와 클로드 챗(웹·앱)이 같은 사용량 풀을 씁니다. 챗에서 쓴 만큼 코드에서 쓸 양이 줄어요.

🧭 3. 실전 요령 — 한도에 덜 걸리는 사용법 (실사용 경험)

① 큰 작업은 창 시작에 맞춰서. 5시간 창이 새로 열릴 때 무거운 작업(대규모 리팩터링, 여러 글 발행)을 몰아서 시키면 창 하나로 마무리됩니다.

② 맥락을 아껴 쓰면 한도도 아껴집니다. 대화가 길어질수록 요청당 소모가 커집니다. 새 작업은 /clear로 시작하고, 긴 세션은 /compact로 압축하세요 — 한도 관리이자 품질 관리입니다.

③ 반복 설명을 없애세요. CLAUDE.md에 규칙을 적어두면 같은 지시를 매번 반복하는 소모가 사라집니다. (사용법 정리)

④ Pro로 시작해 부족하면 Max로. 제 경험상 학습·취미 수준은 Pro로 충분하고, 매일 몇 시간씩 굴리는 운영 단계가 되면 그때 Max를 검토해도 늦지 않습니다.

  • 요금은 구독 포함이라 예측 가능 — 이게 API 과금 대비 큰 장점입니다
  • 한도는 “5시간 창 + 주간 상한 + 챗과 공용”이라는 구조만 이해하면 스트레스가 줄어듭니다
