클로드 코드 요금과 한도, 구조와 아껴 쓰는 법 (2026년 10월)

클로드 코드 요금과 한도 — 구조와 아껴 쓰는 법, 2026년 10월 기준 (캐릭터는 GPT 이미지 생성)

클로드 코드를 쓰기 시작하면 두 가지가 궁금해져요. “얼마 내야 하지?” 그리고 “얼마나 쓸 수 있지?” 요금은 단순한데, 한도는 처음엔 헷갈려요. 블로그 운영을 클로드 코드에 매일 맡기는 입장에서 정리했어요.

클로드 코드 한도는 휴대폰 데이터와 비슷해요. 요금제를 고르면 쓸 수 있는 양이 정해지고, 다 쓰면 다시 채워질 때까지 기다리거나 추가로 사야 해요. 다른 점은 다시 채워지는 주기가 한 달이 아니라 5시간과 1주일, 두 개라는 거예요.
그래서 요금표보다 한도가 언제 다시 채워지는지를 먼저 알아 두는 게 좋아요.

모래시계와 연료 게이지를 보는 장면 — 시간이 지나면 다시 채워지는 한도를 빗댄 그림 (GPT 이미지 생성)

1. 요금은 구독에 들어 있어요

클로드 코드는 Pro 이상 유료 구독에 들어 있어요. 무료 플랜에서는 쓸 수 없어요. 구독으로 쓰면 한도 안에서는 쓴 만큼 따로 돈이 나가지 않아요. 플랜별 요금을 2026년 10월 7일 공식 요금표 기준으로 정리했어요.

플랜월 요금 · 클로드 코드
무료 플랜 (Free)$0 · 클로드 코드 없음
Pro 플랜$20 (연간 결제면 월 $17) · 포함
Max 5x 플랜$100 · Pro의 5배 사용량
Max 20x 플랜$200 · Pro의 20배 사용량

가격은 세금 별도예요. 저는 제 돈으로 Pro를 구독해서 시작했어요. 구독 없이 API 키(Claude Console)로 로그인해서 쓰면 방식이 달라요. 한도 대신 쓴 만큼 토큰 요금이 나가요.

2. 세션 한도: 5시간마다 다시 차요

한도의 첫 단위는 세션이에요. 세션 한도는 5시간마다 다시 채워져요. 5시간 안에 쓸 수 있는 양이 정해져 있고, 다 쓰면 클로드 코드가 You've hit your session limit 메시지와 다시 채워지는 시각을 띄우고 다음 요청을 막아요.

쓸 수 있는 양은 메시지 개수로 정해져 있지 않아요. 공식 도움말은 메시지 길이, 첨부 파일 크기, 대화 길이, 모델, 여러 단계로 도는 작업이 사용량을 좌우한다고 적어요. Max 5x는 Pro 세션 한도의 5배, Max 20x는 20배예요.

클로드 코드 한도의 구조 — 5시간 세션 한도, 주간 한도, 채팅과 함께 쓰는 한 통 (직접 제작)

3. 주간 한도, 그리고 한 통

세션 한도와 따로, 일주일 단위 한도가 하나 더 있어요. 주간 한도는 계정마다 정해진 시각에 매주 다시 채워져요.

쓴 양은 세션 한도와 주간 한도에 동시에 쌓여요. 그래서 짧게 몰아 쓰면 세션이 다시 차기 전에 주간 한도부터 닿을 수 있어요. 두 한도는 모든 모델이 함께 써요. 모델을 바꿔도 다시 열리지 않아요.

그리고 이 한도는 클로드 채팅과 클로드 코드가 같이 써요. 공식 도움말은 claude.ai, 클로드 데스크톱, 클로드 코드 사용량이 모두 같은 한도에 들어간다고 적어요. 채팅을 많이 쓴 날은 코드에서 쓸 양이 그만큼 줄어요.

로봇과 말풍선이 주스 한 통을 나눠 마시는 장면 — 채팅과 클로드 코드가 같은 한도를 쓴다는 뜻 (GPT 이미지 생성)

💡 핵심채팅과 클로드 코드는 한 통을 나눠 써요. 큰 작업이 있는 날은 채팅을 아껴 두세요.

4. 남은 양 확인하기

남은 한도는 클로드 코드 안에서 /usage로 볼 수 있어요.

  1. 클로드 코드 입력 칸에 /usage를 입력하세요.→ 구독 사용량 막대와 다시 채워지는 시각이 보여요.
  2. 웹에서는 claude.ai의 Settings > Usage를 여세요(영어 화면 기준).→ 지금 세션에서 쓴 양과 남은 시간, 주간 한도가 다시 차는 때가 보여요.

/usage에는 무엇이 한도를 많이 썼는지도 나와요. 스킬·서브에이전트·MCP 서버별 비율과, 긴 맥락처럼 사용량의 10% 이상을 차지한 습관을 짚어 줘요. 다만 이 내역은 이 컴퓨터의 기록으로 계산해서, 다른 기기나 claude.ai에서 쓴 양은 빠져 있어요.

5. 한도를 아끼는 요령 4가지

첫째, 다른 일로 넘어갈 때는 /clear로 새로 시작하세요. 클로드 코드는 요청할 때마다 지금까지의 대화를 함께 보내요. 하루 종일 연 세션에서는 한 줄 질문도 대화 전체만큼 한도를 써요.

공식 문서도 /clear는 비용이 들지 않는다고 적어요. 다른 일로 넘어갈 때는 /clear부터라고 기억하세요.

하던 일을 이어 가야 하면 /compact로 대화를 요약해 줄이세요. 다만 요약하는 일 자체가 큰 요청이라, 새로 시작해도 되는 일이면 /clear가 더 싸요. 남길 내용을 정해 주면 요약이 덜 흐트러져요.

📋 그대로 복사해 쓰세요

/compact 바꾼 파일 목록과 남은 할 일 위주로 요약해줘

둘째, 같은 설명은 CLAUDE.md에 한 번만 적으세요. 매번 같은 규칙을 다시 말하는 소모가 사라져요. 다만 CLAUDE.md는 세션마다 통째로 읽히니, 공식 문서 권고처럼 200줄 아래로 짧게 두세요.

셋째, 무거운 작업은 세션이 막 다시 찼을 때 몰아서 시키세요. /usage에서 다시 채워지는 시각을 보고, 여러 글 발행 같은 무거운 작업을 새 세션 시작에 맞추면 세션 하나 안에서 끝내기 쉬워요.

넷째, 한 시간 넘게 쉬었다 오면 새로 시작하세요. 구독에서는 대화 캐시가 한 시간 유지돼요. 그보다 오래 쉬었다가 긴 대화에 말을 걸면, 첫 요청에서 대화 전체를 다시 읽느라 한도를 크게 써요.

6. Pro로 시작하고, 모자라면 Max

처음엔 Pro로 시작하고, 한도에 자주 닿을 때 Max를 보세요.
이런 분은 Pro — 배우는 중이거나 취미로 가끔 맡기는 분. 제 경험상 이 단계는 Pro로 충분했어요.
이런 분은 Max — 매일 몇 시간씩 맡기는 운영 단계라 한도에 자주 닿는 분.

업그레이드 말고 방법이 하나 더 있어요. Pro·Max에서 사용 크레딧(usage credits)을 켜면, 한도를 넘긴 만큼 따로 돈을 내고 이어서 쓸 수 있어요. 클로드 코드에서 /usage-credits를 입력하면 claude.ai의 사용량 설정 화면이 열려요.

⚠️ 주의사용 크레딧은 켜 두면 한도를 넘긴 만큼 돈이 나가요. 켤 때는 월 사용 한도를 같이 정해 두세요.

막힐 때

You’ve hit your session limit 메시지가 떠요
원인: 5시간 세션 한도를 다 썼어요. 주간 한도를 다 쓰면 weekly limit 메시지가 떠요.
해결: 메시지에 나온 시각까지 기다리세요. 2.1.234부터는 열어 둔 세션에서 한도가 다시 찬 뒤 하던 일을 이어서 하게 할 수 있어요.

모델을 바꿨는데도 계속 막혀요
원인: 세션 한도와 주간 한도는 모든 모델이 같이 써요.
해결: 기다리거나, 사용 크레딧이나 상위 플랜을 고르세요. 메시지에 Opus limit처럼 모델 이름이 있으면 /model로 다른 계열 모델로 바꿔 이어서 쓸 수 있어요.

한도가 생각보다 빨리 닳아요
원인: 대화가 아주 길거나, 오래 쉬었다 이어 쓰거나, 서브에이전트를 여러 개 돌렸을 때예요.
해결: /usage 내역에서 무엇이 많이 썼는지 보고, 새 작업은 /clear로 시작하세요.

자주 묻는 질문

Q. 무료 플랜으로 클로드 코드를 쓸 수 있나요?

아니요. 공식 요금표에서 무료 플랜의 클로드 코드 칸은 '없음(No)'이에요. Pro부터 들어 있어요.

Q. 5시간에 메시지 몇 개까지 되나요?

정해진 개수로 공개돼 있지 않아요. 메시지 길이, 대화 길이, 첨부, 모델, 작업 단계 수에 따라 달라져요. 지금 얼마나 남았는지는 /usage로 보는 게 정확해요.

Q. Max 5x와 20x는 뭐가 다른가요?

세션 한도가 Pro의 5배와 20배예요. 요금은 월 $100과 $200이에요(2026년 10월 7일 기준, 세금 별도).

Q. 서브에이전트를 쓰면 한도를 더 쓰나요?

네. 서브에이전트도 따로 요청을 보내고, 메인 대화와 같은 한도에서 빠져요.
