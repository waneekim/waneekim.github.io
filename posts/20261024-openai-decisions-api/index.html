오픈AI 개발자 문서(10월 22일 정식 출시 기록)와 테크크런치·AI타임스 보도를 대조해 정리한 글이에요. 제휴 링크는 없어요. 4컷 만화의 장면 그림과 캐릭터는 AI 이미지 생성이고, 말풍선 글자와 도식은 직접 만들었어요.

오픈AI 디시전스 API 정식 출시, 고르기만 하는 AI는 왜 빠를까

디시전스 API — 고르기만 하는 AI, 왜 빠를까? (캐릭터는 AI 이미지 생성)

시험에 서술형 문제가 나오면 답을 길게 써야 해서 시간이 오래 걸려요. 그런데 O/X 문제나 객관식은 하나만 고르면 끝이죠. 같은 사람이 풀어도 고르는 문제가 훨씬 빨라요.

오픈AI가 10월 22일(미국 시각), AI가 긴 글 대신 ‘정해 둔 답 고르기’로만 빠르게 판단해 주는 디시전스 API(Decisions API)를 모든 고객에게 정식으로 열었어요. API는 다른 프로그램이 AI를 불러 쓰는 연결 창구예요. 개발자용 기능이지만, 우리가 쓰는 앱의 반응 속도를 바꿀 수 있는 소식이에요.

4컷 만화 — 서술형처럼 길게 답하던 AI가, 객관식처럼 고르기만 하자 훨씬 빨라졌어요 (장면 그림 AI 이미지 생성, 말풍선 글자 직접 넣음)

2026년 10월 24일 기준 · 오픈AI 개발자 문서 확인

1. 디시전스 API가 뭐예요?

궁금이AI가 고르기만 한다고요? 그럼 대답은 안 해요?
AI 로봇문장으로 길게는 안 해요. 대신 "맞을 확률 0.9", "2번", "다섯 단계 중 4단계"처럼 딱 정해진 모양으로 답해요.

개발자가 질문과 고를 수 있는 답을 미리 정해 두면, AI는 그 안에서만 골라요. 글·사진·정리된 데이터(JSON)를 함께 보낼 수 있어요.

이런 질문이면AI의 답
이 사진에 찌그러짐이 있나요?그럴 확률(0에서 1 사이)
이 문의는 어느 부서로 보낼까요?정해 둔 보기 중 하나
이 문제는 얼마나 급한가요?단계에 맞춘 점수

오픈AI 문서에 나온 예시도 이런 일이에요. 앱이 하루에도 수없이 되풀이하는 작은 판단이죠. 답을 받은 뒤 실제로 무엇을 할지는 앱이 정해요.

2. 왜 이렇게 빨라요?

궁금이똑같은 AI인데 왜 고르기만 하면 빨라져요?
AI 로봇글은 한 조각씩 이어 써야 해서 오래 걸려요. 고르기는 다 쓸 필요 없이 바로 끝나요!

오픈AI 개발자 계정은 출시 글에서 “전체 답을 만들지 않고도” 분류하고 다음 할 일을 정한다고 소개했어요. 오픈AI API 제품 책임자 니쿤지 한다는 테크크런치 인터뷰에서 1~3초 걸리던 일을 100에서 180밀리초, 그러니까 0.1초대로 줄였다고 말했어요. 4컷 만화 2번 칸의 기다림이 거의 사라진 셈이에요.

기다리는 시간 비교 — 오픈AI 설명과 스픽 시험 모두 0.1초대로 줄었어요 (회사·고객사가 밝힌 숫자로 직접 제작)

새 모델을 따로 만든 것도 아니에요. 한다는 원래 있던 GPT-6 루나를 판단 일에 맞게 빠르고 싸게 돌리도록 고쳤다고 설명했어요. 값은 입력 100만 토큰(글자 조각)당 0.10달러이고, AI가 내놓는 답에는 요금을 받지 않아요.

3. 누가, 어디에 써요?

누가어디에
스픽(언어 학습 앱)음성 대화에서 다음 행동까지 1.4초 → 0.13초
박스·데이터독·램프정식 출시 전에 먼저 시험
오픈AI 자신비서 서비스 닷츠(dots)의 반응 속도 높이기

실시간 음성 AI인 GPT-라이브와도 바로 이어 붙였어요. 사용자가 말하는 도중에도 상담 AI가 “더 물어볼까, 담당자에게 넘길까”를 고르는 식이에요. 요청 한 번에 질문을 400개까지 보낼 수 있어요(베타 때 200개). 4컷 만화 4번 칸처럼요.

이런 ‘고르는 AI’는 오픈AI가 처음 만든 게 아니에요. 스타트업 타입세이프의 제브(Jev)가 먼저 이 분야를 열었고, 테크크런치는 타입세이프의 기업가치를 76억 달러로 전했어요. 제브가 어떤 AI인지는 지난 글에 쉽게 정리해 두었어요.

→ System One 모델 Jev란, 글을 쓰지 않고 고르는 AI

4. 그럼 오픈AI 것이 제일 좋아요?

궁금이그럼 이제 오픈AI 것만 쓰면 돼요?
AI 로봇아직 몰라요! 어떤 일이냐에 따라 잘하는 모델이 달라요.
⚠️ 알아 둘 점① '약 10배 빠르다'는 오픈AI가 자기 기존 방식(리스폰스 API)과 비교한 숫자예요. 다른 회사 모델과 견준 게 아니에요.
② 테크크런치에 따르면 공개 순위표 두 곳에서 오픈AI 모델은 8위와 14위, 제브는 7위와 3위였어요.
③ 디시전스 API는 고르기만 해요. 설명 글이 필요한 일은 기존 방식을 쓰라고 오픈AI 문서도 안내해요.
④ 지금은 GPT-6 루나 모델 하나만 쓸 수 있어요.

5. 나는 뭘 하면 돼요?

  1. 개발자가 아니라면 '앱이 빨라지는 이유'로 알아 두기상담 챗봇이나 음성 비서가 눈에 띄게 빨라졌다면, 뒤에서 이런 고르는 AI가 일하고 있을 수 있어요.
  2. 개발자라면 반복되는 작은 판단부터 바꿔 보기분류나 담당자 배정처럼 답이 정해진 일이 맞아요. 오픈AI는 코드를 쓰기 전에 시험해 보는 플레이그라운드도 열어 두었어요.
  3. 중요한 결정은 사람이 다시 보기확률은 '아마 맞다'는 뜻이지 '반드시 맞다'가 아니에요. 돈이나 안전이 걸린 판단은 사람이 확인해요.
✅ 한눈에 정리· 디시전스 API는 글 대신 확률·보기·점수로만 답하는 '고르는 AI'예요
· 오픈AI는 기존 방식보다 약 10배 빠르다고 밝혔고, 0.1초대 사례가 나왔어요
· 10월 22일 모든 고객에게 정식 출시됐고, 입력 100만 토큰당 0.10달러예요
· 속도는 회사 발표 숫자이고, 공개 순위표에선 경쟁 모델이 앞선 곳도 있어요

오늘의 큰 흐름: AI가 ‘말 잘하는 비서’를 넘어, 앱 속에서 0.1초 만에 판정하는 ‘보이지 않는 심판’으로도 쓰이기 시작했어요.
