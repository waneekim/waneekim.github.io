HTML 파일 하나로 앱 만들기, 코딩 몰라도 되는 45줄 템플릿

HTML 하나로 앱 만들기 — 코딩 몰라도 되는 45줄 템플릿 (캐릭터는 GPT 이미지 생성)

‘앱을 만든다’고 하면 앱스토어 등록, 서버, 개발자부터 떠오르죠. “코딩도 모르는데 내가 쓸 앱을 가질 수 있을까?” 그런데 저는 지금 실제로 쓰는 앱이 셋 있고, 전부 HTML 파일 하나예요. 셋 다 설치도 서버도 없이 더블클릭이면 열려요.

HTML 파일은 악보 한 장과 비슷해요. 악보만 있으면 피아노가 있는 곳 어디서나 같은 곡을 칠 수 있죠. HTML 파일이 악보, 브라우저가 피아노예요. 그리고 그 피아노는 이미 모든 폰과 PC에 있어요.
브라우저가 곧 실행기라서, 파일 하나에 화면·모양·동작을 담으면 그게 앱이에요.

종이 한 장 같은 HTML 파일이 브라우저에서 앱이 되는 장면 (GPT 이미지 생성)

1. 파일 하나로 앱이 되는 이유

HTML 파일 안에 화면·모양·동작 세 가지를 다 넣으면, 브라우저가 그대로 실행해요. 폰 앱은 iOS·안드로이드가, PC 프로그램은 윈도우가 실행해 주죠. HTML 파일은 브라우저가 실행해요.

HTML 파일에 들어가는 세 가지예요.
HTML (뼈대) — 화면에 뭐가 있는지. 제목, 목록, 버튼
CSS (옷) — 어떻게 보이는지. 색, 크기, 배치
자바스크립트 (근육) — 누르면 뭐가 일어나는지. 계산, 저장

보통은 이 셋을 파일 여러 개로 나누지만, 한 파일에 다 넣어도 브라우저는 똑같이 읽어요. 그래서 설치도 서버도 없이 파일이 곧 앱이에요.

2. 실제로 쓰는 앱 3개의 크기

제가 만든 HTML 앱의 크기를 정한 건 코드가 아니라 그림과 데이터였어요. 이 저장소의 실제 파일을 2026년 10월 7일에 다시 재서 정리했어요.

앱크기와 안에 든 것
여행 앱 첫 버전약 19KB — 3일 일정, 맛집 5곳 전화·지도, 준비물 체크리스트
여행 앱 최종판약 22MB — 보물지도 그림 6장을 파일 안에
OpenAI 비용 계산기약 5.8KB — 입력 4개, 계산, 결과 표
블로그 관제판약 63KB — 표·배지·탭, 접힘 상태 기억

표에서 세 가지가 보여요.

동작 코드는 생각보다 적어요. 관제판의 자바스크립트는 571자뿐이고, 모양을 정하는 CSS가 9,711자예요.

크기는 그림과 데이터가 정해요. 여행 앱은 그림 6장을 넣자 1,000배 넘게 커졌어요. 관제판은 9월 8일 약 30KB에서 담긴 기록이 늘어 63KB가 됐지만, 코드는 한 글자도 그대로예요.

실패는 기능이 아니라 읽히는지에서 와요. 여행 앱 첫 버전은 기능은 다 됐는데, 아무도 안 읽어서 버렸어요.

3. 되는 것과 안 되는 것

혼자 쓰는 앱이면 대부분 되고, 여러 사람이 데이터를 같이 쓰는 순간부터 안 돼요.

되는 것안 되는 것
화면·버튼·탭·목록여러 사람이 같은 데이터 공유
계산기·변환기·체크리스트푸시 알림
내 기기에 저장비밀 보관 (코드가 다 보임)
전화·지도·카톡 공유 링크앱스토어 등록
그림 넣기, 인터넷 없이 실행기기끼리 자동 동기화

핵심은 ‘내 기기에 저장’이에요. 브라우저에는 로컬스토리지(localStorage)라는 작은 저장 공간이 있어서, 체크한 항목이나 입력값을 기억해 둘 수 있어요. 여행 앱의 준비물 체크리스트도, 관제판의 접힘 상태도 이걸로 기억해요.

반대로 5가족이 같은 체크리스트를 같이 체크하는 건 안 돼요. 각자 자기 폰의 저장 공간에만 기록되니까요.

같은 체크리스트 앱인데 엄마 폰과 아이 폰의 체크가 다른 장면 — 저장은 기기마다 따로 (GPT 이미지 생성)

💡 핵심혼자 쓰는 앱은 파일 하나로 충분해요. 여럿이 같은 데이터를 써야 할 때가 서버가 필요한 때예요.

4. 45줄 템플릿으로 첫 앱 만들기

여행 준비물 체크리스트 템플릿이에요. 체크하면 줄이 그어지고, 항목을 추가할 수 있고, 닫았다 열어도 그대로 남아요. 2026년 10월 7일 엣지에서 다시 열어 체크·추가·새로고침까지 확인했어요.

템플릿을 실제로 연 화면 — 체크·추가 뒤 새로고침해도 그대로 (직접 캡처)

  1. 사이트판 맨 아래 템플릿 전체 코드를 복사 버튼으로 복사하세요.→ 45줄짜리 HTML 코드가 복사돼요.
  2. 메모장에 붙여 넣고 파일 > 다른 이름으로 저장을 고르세요.→ 저장 창이 떠요.
  3. 파일 형식은 모든 파일, 인코딩은 UTF-8로 두고 이름을 checklist.html로 저장하세요.→ 확장자가 .html인 파일이 생겨요.
  4. 저장한 파일을 더블클릭하세요.→ 브라우저에 체크리스트가 열려요. 이게 앱이에요.

코드 안의 ‘구명조끼’, ‘우비·방수팩’, ‘상비약’을 바꾸면 내 목록이 되고, ‘여행 준비물’을 바꾸면 제목이 바뀌어요. 이 두 군데만 고쳐도 이미 내 앱이에요.

오래 쓸 앱이나 폰에서 쓸 앱은 주소로 여는 게 확실해요. MDN 문서는 더블클릭으로 연 파일(file: 주소)의 로컬스토리지 동작은 정해져 있지 않고, 브라우저마다 다를 수 있다고 적어요. 제가 확인한 건 엣지예요.

깃허브 페이지(GitHub Pages) 같은 무료 호스팅에 올리면 폰 브라우저에서도 주소로 열 수 있어요. 공개 저장소라면 깃허브 무료 계정으로도 돼요. 제 비용 계산기도 이렇게 배포한 이 사이트의 주소로 열어요.

5. AI에게 앱 만들기 시키기

직접 고치기 번거로우면 AI에게 시키세요. 여행 앱 두 개를 코덱스로 만들며 배운 조건을 프롬프트 하나로 줄였어요. 대괄호 안만 바꿔 쓰면 돼요.

📋 그대로 복사해 쓰세요

HTML 파일 하나로 [우리 가족 주간 식단표] 앱을 만들어줘. 외부 라이브러리 없이, 폰 세로 화면에 큼직하게. 입력한 내용은 localStorage에 저장해줘. 쓸 사람은 [초등학생 아이], 화면은 [요일별 카드 7장]으로. 완성 파일 전체를 코드블록 하나로 줘.

‘쓸 사람’과 ‘화면 모양’ 두 조건이 핵심이에요. 여행 앱 첫 버전이 버려진 건 기능 때문이 아니라, 누가 볼 물건인지를 안 적어서였어요.

6. 파일 하나라서 생기는 함정

편하지만, 파일 하나라서 생기는 함정이 세 가지 있어요.

⚠️ 주의API 키·비밀번호·개인정보는 HTML 파일에 넣지 마세요. 파일을 연 사람은 누구나 코드를 볼 수 있어요.

제 비용 계산기도 API 키 없이 요금표만 넣었어요.

그림을 넣으면 급격히 커져요. 여행 앱은 그림 6장에 19KB가 22MB가 됐어요. 카톡으로 보내기 부담스러운 크기였어요. 사진이 많으면 링크로 대신하거나 호스팅에 올리세요.

브라우저 데이터를 지우면 저장한 것도 사라져요. 로컬스토리지는 브라우저 안에 있어서, 브라우저 설정에서 사이트 데이터를 지우면 같이 지워져요. 오래 둘 데이터는 내보내기 버튼을 달거나 따로 백업하세요.

자주 묻는 질문

Q. 코딩을 전혀 몰라도 되나요?

템플릿은 복사해서 저장만 하면 돼요. 고치는 건 5번의 프롬프트로 AI에게 시키면 되고요. 제 여행 앱 두 개도 코덱스와 대화로 만들었어요.

Q. 폰에서도 쓸 수 있나요?

네. 깃허브 페이지 같은 무료 호스팅에 올려 주소로 열면 폰 브라우저에서 쓸 수 있어요. 템플릿도 폰 세로 화면에 맞춰 두었어요.

Q. 저장한 내용은 어디에 남나요?

그 브라우저의 로컬스토리지에 남아요. 다른 기기나 다른 브라우저에서는 보이지 않고, 브라우저 설정에서 사이트 데이터를 지우면 함께 지워져요.

Q. 앱스토어에 올릴 수 있나요?

HTML 파일 하나로는 안 돼요. 대신 주소만 있으면 설치 없이 바로 열 수 있어요.

여행 앱을 코덱스로 만들고 첫 버전을 버린 과정은 이 글에 자세히 적었어요.

템플릿 전체 코드

메모장에 붙여 넣고 checklist.html로 저장하세요. 오른쪽 위 복사 버튼으로 가져갈 수 있어요.

<!doctype html>
<html lang="ko">
<head>
<meta charset="utf-8">
<meta name="viewport" content="width=device-width, initial-scale=1">
<title>여행 준비물</title>
<style>
  body{font-family:sans-serif;max-width:480px;margin:24px auto;padding:0 16px}
  h1{font-size:22px}
  label{display:flex;gap:10px;align-items:center;padding:10px 0;border-bottom:1px solid #eee;font-size:17px}
  input[type=checkbox]{width:22px;height:22px}
  .done{color:#999;text-decoration:line-through}
  #add{display:flex;gap:8px;margin-top:16px}
  #add input{flex:1;font-size:16px;padding:8px}
  button{font-size:16px;padding:8px 14px}
</style>
</head>
<body>
<h1>🧳 여행 준비물</h1>
<div id="list"></div>
<form id="add"><input placeholder="항목 추가" required><button>추가</button></form>
<script>
const KEY = 'trip-checklist';
let items = JSON.parse(localStorage.getItem(KEY) || 'null') || [
  {t:'구명조끼', d:false}, {t:'우비·방수팩', d:false}, {t:'상비약', d:false}];
const list = document.getElementById('list');
function save(){ localStorage.setItem(KEY, JSON.stringify(items)); }
function render(){
  list.innerHTML = '';
  items.forEach(it => {
    const l = document.createElement('label');
    l.className = it.d ? 'done' : '';
    const c = document.createElement('input'); c.type = 'checkbox'; c.checked = it.d;
    c.onchange = () => { it.d = c.checked; save(); render(); };
    l.append(c, it.t); list.append(l);
  });
}
document.getElementById('add').onsubmit = e => {
  e.preventDefault(); const inp = e.target.querySelector('input');
  items.push({t: inp.value.trim(), d:false}); inp.value = ''; save(); render();
};
render();
</script>
</body>
</html>
