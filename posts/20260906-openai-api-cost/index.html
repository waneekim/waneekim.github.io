OpenAI API 비용, 직접 계산해보면 감이 옵니다 — 한국어 계산기 포함

“API 쓰면 한 달에 얼마 나와요?” — 이 질문에 단가표 링크로 답하는 글이 너무 많습니다. 단가표는 “100만 토큰당 $4” 같은 식이라, 처음 보는 사람에게는 아무 감도 주지 않죠. 저는 이 블로그의 삽화를 전부 OpenAI API로 생성하는 실사용자입니다. 그 경험으로 비용 구조를 해설하고, 직접 계산해볼 수 있는 도구를 만들었습니다.

🧮 먼저 계산기부터

→ OpenAI API 비용 계산기 (한국어)

모델 단가, 요청당 토큰, 하루 요청 수, 환율을 넣으면 월 비용이 원화로 나옵니다. 핵심 설계는 하나입니다 — 단가를 직접 수정할 수 있게 했습니다. API 요금은 자주 바뀌어서, 고정 단가 계산기는 몇 달이면 낡습니다. 이 계산기는 공식 요금 페이지를 보고 숫자만 바꿔 넣으면 계속 쓸 수 있습니다.

💡 비용 구조, 딱 3가지만 이해하면 됩니다

① 입력과 출력의 단가가 다릅니다 — 출력이 5~6배 비쌉니다. 대부분 모델에서 출력(AI가 생성하는 텍스트) 단가가 입력의 5~6배입니다. 그래서 “장문의 답변을 뽑는 작업”이 “장문의 자료를 읽히는 작업”보다 비쌉니다. 요약 작업이 생각보다 싸고, 초안 작성이 생각보다 비싼 이유입니다.

② 모델 등급 차이가 수십 배입니다. 2026년 9월 집계 기준으로 최상위 모델과 경량 모델의 단가 차이는 40~50배에 달합니다. 모든 요청에 최상위 모델을 쓰는 건, 동네 마트에 갈 때마다 비행기를 타는 것과 같습니다. 분류·추출 같은 단순 작업은 경량 모델로 내리는 것이 비용 최적화의 90%입니다.

③ 감 잡는 환산: 한글 1자 ≈ 1~2토큰. A4 한 장(한글 약 1,800자)이 입력 2,000~3,500토큰입니다. “회의록 10장 요약을 하루 20번” 같은 실제 업무를 토큰으로 바꿔 계산기에 넣어보면, 막연했던 비용이 구체적인 숫자가 됩니다.

🧾 실사용 예: 이 블로그의 이미지 생성 비용

이 블로그 글마다 들어가는 캐릭터 삽화는 전부 이미지 생성 API(gpt-image-1)로 만듭니다. 품질 medium 기준으로 한 장에 수십 원 수준이라, 글 한 편의 삽화 비용은 커피 한 잔이 안 됩니다. 텍스트든 이미지든 결론은 같습니다 — 개인·소규모 자동화 수준에서 API 비용은 생각보다 부담이 없고, 진짜 비용 폭탄은 “최상위 모델로 대량 반복”에서만 나옵니다.

⚠️ 계산할 때 흔한 실수 2가지

· 대화 맥락 누적을 빼먹는 것 — 챗봇처럼 대화가 이어지는 서비스는 매 요청에 이전 대화가 입력 토큰으로 다시 들어갑니다. 대화가 길어질수록 요청당 입력 토큰이 커지는 구조라, 평균이 아니라 후반부 기준으로 잡아야 안전합니다 · 배치 할인을 모르는 것 — 실시간 응답이 필요 없는 작업(야간 일괄 처리 등)은 Batch API로 단가가 50% 할인됩니다. 계산기에 체크박스로 넣어뒀습니다
