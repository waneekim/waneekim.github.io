OpenAI API 비용, 한 달 요금 계산법 (2026년 10월)

OpenAI API 비용 — 한 달 요금 직접 계산하는 법 (캐릭터는 GPT 이미지 생성)

“API 쓰면 한 달에 얼마 나와요?” 이 질문에 단가표 링크만 보여 주는 글이 많아요. 그런데 단가표는 ‘100만 토큰당 몇 달러’라서, 처음 보면 내 일에 얼마가 드는지 감이 오지 않아요.

API 요금은 교통비와 비슷해요. 간 거리만큼 내고, 무엇을 타느냐에 따라 같은 거리도 값이 크게 달라요. 동네 마트에 갈 때마다 비행기를 타지 않듯, 쉬운 일에 가장 비싼 모델을 쓸 필요는 없어요.
API 비용은 ‘토큰 수 × 모델 단가’로 정해지고, 금액을 가장 크게 바꾸는 건 모델 고르기예요.

가까운 가게에 가려고 자전거·자동차·비행기 중 자전거를 고르는 장면 — 일에 맞는 모델 고르기를 빗댄 그림 (GPT 이미지 생성)

🎯 이 글에서 얻는 것대상: OpenAI API 월 비용이 궁금한 분
① 비용을 정하는 3가지: 토큰·입출력·모델
② 공식 단가로 계산한 한 달 예시
③ 계산기 쓰는 법과 흔한 실수
준비물: 맡길 일 하나 · 하루 요청 수 짐작
2026년 10월 7일 · OpenAI 공식 요금표 기준

1. 비용은 토큰 수 × 단가

API는 글자 수가 아니라 토큰(token) 수로 요금을 매겨요. 토큰은 AI가 글을 잘게 잘라 읽는 단위예요. 내가 보낸 글(입력)과 AI가 써 준 글(출력)을 따로 세고, 각각 모델 단가를 곱해서 더해요.

한글 원고로 직접 재 봤어요. 이 블로그 글에서 A4 한 장 분량인 1,800자를 GPT-5 계열이 쓰는 토크나이저(o200k_base)로 세니 1,032토큰이 나왔어요. 글자 수의 0.6배쯤이에요. 토크나이저는 모델마다 다를 수 있어서, 실제 토큰 수는 API 응답에 함께 오는 사용량(usage) 항목으로 확인해요.

2. 출력이 입력보다 5배 비싸요

AI가 써 주는 출력의 단가가 내가 보내는 입력의 단가보다 비싸요. 2026년 10월 7일 공식 요금표에서 대표 모델 세 개는 모두 출력이 입력의 5배예요. 그래서 긴 자료를 읽히고 짧게 받는 요약은 생각보다 싸고, 짧게 주고 길게 받는 초안 쓰기는 생각보다 비싸요.

출력이 비싸니 답의 길이를 정해 주는 것만으로도 비용이 줄어요.

❌ 이렇게 말고

이 회의록 요약해줘

답의 길이가 정해져 있지 않아서, 인사말과 설명까지 길게 붙여 출력 토큰이 늘어나기 쉬워요.

⭕ 이렇게

이 회의록을 5줄 이내로 요약해줘. 인사말이나 설명 없이 요약만 써줘

3. 모델에 따라 100배 차이

같은 일이라도 어떤 모델에 맡기느냐에 따라 단가가 100배까지 벌어져요. OpenAI 공식 요금표 맨 위의 대표 모델 세 개를 옮겼어요.

모델입력 / 출력 (100만 토큰당)
gpt-6-astra$10 / $50
gpt-6.1-sol$2 / $10
gpt-6-luna$0.10 / $0.50

가장 비싼 astra와 가장 싼 luna는 입력·출력 모두 100배 차이예요. 위 단가는 짧은 맥락 기준이고, 요금표에는 더 비싼 긴 맥락(long context) 단가가 따로 있어요.

분류·추출처럼 단순한 일은 싼 모델로 내리세요. 모든 요청에 가장 비싼 모델을 쓰는 건 동네 마트에 갈 때마다 비행기를 타는 것과 같아요.

💡 핵심싼 모델로 먼저 해 보고, 결과가 모자랄 때만 한 단계씩 올리세요.

4. 한 달 비용 계산 예시

A4 한 장 원고를 요약하는 일을 하루 20번 한다고 잡고 계산해 볼게요. 입력은 1,000토큰, 출력은 250토큰(400자 남짓한 요약)으로 잡았어요. 한 달 30일이면 600번이에요.

OpenAI API 한 달 비용 계산식과 모델별 예시 — 같은 요약 일도 모델에 따라 100배 차이 (직접 제작)

계산식은 그림과 같아요. 모델별로 넣으면 이렇게 나와요.

모델한 달 비용 (600번)
gpt-6-astra$13.50
gpt-6.1-sol$2.70
gpt-6-luna$0.135

gpt-6-astra라면 입력 60만 토큰 × $10 ÷ 100만 = $6, 출력 15만 토큰 × $50 ÷ 100만 = $7.50이에요. 더하면 $13.50이에요. 같은 일을 gpt-6-luna에 맡기면 $0.135로, 100분의 1이에요.

5. 계산기로 내 비용 계산하기

내 일에 맞춰 숫자를 바꿔 보려면 사이트에 만들어 둔 한국어 계산기를 쓰세요. 단가를 직접 고쳐 넣을 수 있게 만들어서, 요금이 바뀌어도 계속 쓸 수 있어요.

  1. 아래 링크로 계산기를 여세요.→ 모델 단가 표와 사용량 칸이 보여요.
  2. 단가 표의 직접 입력 줄을 고르고, 공식 요금표의 입력·출력 단가를 넣으세요.→ 표에 미리 들어 있는 숫자는 2026년 9월 예시값이라, 바꿔 넣는 게 정확해요.
  3. 요청 1건당 입력·출력 토큰, 하루 요청 수, 환율을 넣으세요.→ 요청 1건·하루·한 달 비용과 원화 환산이 바로 바뀌어요.
  4. 선택: 실시간 답이 필요 없는 일이면 Batch API 사용에 체크하세요.→ 단가가 절반으로 계산돼요.

6. 이 블로그의 삽화 비용

이 블로그의 캐릭터 삽화는 전부 OpenAI 이미지 생성 API로 만들어요. 지금은 gpt-image-2 모델, 품질 medium, 1024×1024 크기로 만들어요. 공식 가이드에 따르면 이 설정의 이미지 출력 비용은 한 장에 $0.053이에요. 글 한 편에 3장이면 약 16센트이고, 프롬프트 입력 비용이 조금 더 붙어요.

제 경험으로는 개인·소규모 자동화에서 API 비용은 생각보다 부담이 작았어요. 비용이 크게 나오는 건 대개 가장 비싼 모델로 같은 일을 대량으로 되풀이할 때예요.

막힐 때

계산보다 청구 금액이 훨씬 커요
원인: 챗봇처럼 대화가 이어지는 서비스는 요청마다 앞의 대화가 입력 토큰으로 다시 들어가요. 대화가 길어질수록 요청 1건의 입력이 커져요.
해결: 입력 토큰은 평균이 아니라 대화 후반 기준으로 잡으세요.

갈수록 앞의 대화를 짐처럼 더 싣고 가는 장면 — 대화가 길어지면 입력 토큰이 늘어나는 것을 빗댄 그림 (GPT 이미지 생성)

실시간이 아닌 일인데 제값을 다 냈어요
원인: 밤새 몰아서 처리해도 되는 일을 일반 요청으로 보냈을 때예요.
해결: Batch API로 보내세요. 공식 문서 기준 비용이 50% 낮고, 결과는 24시간 안에 돌아와요.

내 일이 몇 토큰인지 모르겠어요
원인: 토큰 수는 언어와 모델에 따라 달라서 글자 수로는 정확히 알 수 없어요.
해결: 실제 요청을 몇 번 보내 보고, API 응답의 사용량(usage) 항목에 찍힌 토큰 수를 계산기에 넣으세요.

자주 묻는 질문

Q. 토큰은 글자 수와 같은가요?

아니요. 제 한글 원고 1,800자는 1,032토큰이었어요(o200k_base 기준). 언어와 모델에 따라 달라지니, 정확한 수는 API 응답의 사용량 항목으로 확인하세요.

Q. 대화가 길면 단가가 달라지나요?

네. 공식 요금표에는 짧은 맥락과 긴 맥락(long context) 단가가 따로 있어요. gpt-6-astra의 긴 맥락 단가는 입력 $20, 출력 $75예요.

Q. 이미지 생성도 토큰으로 계산하나요?

네. 이미지도 출력 토큰으로 매겨요. 공식 가이드에 모델·품질·크기별 한 장 비용이 나와 있고, gpt-image-2 medium 1024×1024는 $0.053이에요.
