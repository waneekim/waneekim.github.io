GPT-6.1 Sol 발표, 가격·성능과 Sonnet 5.5 비교

GPT-6.1 Sol 발표 — Astra의 5분의 1 가격, 성능 정리 (캐릭터는 GPT 이미지 생성)

GPT-6.1 Sol 발표를 보면 이 질문이 먼저 들어요. “Astra로 하던 일을 이걸로 바꿔도 될까?” 가격·성능·쓸 수 있는 곳을 발표문 그대로 모아 보면 판단이 쉬워요.

이름난 식당에 저녁 코스가 있다고 해 볼게요. 같은 셰프가 점심 정식을 내놨는데, 맛은 저녁 코스에 거의 붙었고 값은 5분의 1이에요. 매일 먹을 건 점심 정식이 되겠죠.
GPT-6.1 Sol은 최상위 모델 GPT-6 Astra에 가까운 성능을 Astra 토큰 가격의 5분의 1에 내겠다는 OpenAI의 새 모델이에요.

⚠️ 출처 안내성능·가격 수치는 2026년 9월 29일 OpenAI 공식 발표를 옮긴 거예요. 회사가 잰 값이라 독립 검증 전이고, 경쟁사 값은 OpenAI가 공개 보고서에서 인용한 거예요.

같은 셰프의 저녁 코스와 점심 정식 — Astra와 GPT-6.1 Sol (GPT 이미지 생성)

🎯 이 글에서 얻는 것대상: ChatGPT·Codex·OpenAI API를 쓰는 분
① 가격과 캐시된 입력 95% 할인
② 발표문이 말한 성능과 사실 정확성
③ Claude Sonnet 5.5와 나란히 본 점
2026년 10월 1일 기준 · 9월 29일 발표

1. 무엇이 나왔나

GPT-6.1 Sol은 9월 29일 OpenAI 개발자 행사 DevDay에서 발표된, GPT-6 Sol의 업그레이드 모델이에요. 9월 한 달 동안 GPT-6 계열이 차례로 나왔어요.

날짜나온 모델
9월 3일최상위 모델 GPT-6 Astra
9월 22일GPT-6 Sol과 GPT-6 Luna
9월 29일GPT-6.1 Sol (DevDay)

발표문은 이 모델을 ‘중요한 작업을 더 자주 돌리려는 사용자와 큰 서비스를 운영하는 API 고객을 위한, 역량과 비용의 새 균형점’이라고 소개해요.

ChatGPT에서는 Plus·Pro·Business·Enterprise·Edu 사용자가 Work 화면과 Codex에서 바로 쓸 수 있어요. 일반 대화(Chat) 화면에는 아직 없어요. API 이름은 gpt-6.1-sol이에요.

2. 가격과 캐시된 입력

100만 토큰당 입력 2달러·출력 10달러로, 최상위 모델 Astra의 5분의 1이에요. Claude 두 모델과 나란히 놓으면 이래요(100만 토큰당 입력 / 캐시된 입력 / 출력).

모델입력 / 캐시된 입력 / 출력
GPT-6.1 Sol (이번 모델)$2 / $0.10 / $10
GPT-6 Astra (계산값)$10 / — / $50
Claude Sonnet 5.5 (앤트로픽)$2 / $0.20 / $10
Claude Opus 5.5 (앤트로픽)$4 / $0.20 / $20

Astra 칸은 발표문의 ‘5분의 1’로 거꾸로 계산한 값이에요. Claude Sonnet 5.5와 입력·출력 단가가 같고, 캐시된 입력만 GPT-6.1 Sol이 절반이에요.

이미 읽은 부분엔 책갈피 — 캐시된 입력 (GPT 이미지 생성)

캐시된 입력은 AI 에이전트가 매번 다시 보내는 긴 지시문에 책갈피를 꽂아 두는 기능이에요. 그 부분은 값을 95% 깎아 줘요. 입력 100만·출력 20만 토큰짜리 일로 계산하면 캐시 없이는 4달러, 입력의 90%가 캐시에서 나오면 약 2.29달러예요. 같은 일을 Astra 단가로 하면 20달러예요. 모델마다 같은 일에 쓰는 토큰 수가 달라서 단가 비교일 뿐이에요.

💡 핵심같은 앞부분을 수십 번 다시 보내는 에이전트 작업이라면, 캐시 단가가 청구서를 크게 좌우해요.

3. 성능: 발표문이 말한 것

점수표 대신 ‘누구보다 몇 %포인트 높고, 비용은 몇 분의 1’ 같은 상대 비교로 발표했어요. 그 문장을 분야별로 모았어요.

분야 (평가)발표문 내용
코딩 (DeepSWE v1.1)약 5분의 1 비용으로 Astra와 대등. 이전 Sol 최고점보다 6.4%포인트 높음
문서 이해 (GDP.pdf)폴백을 쓰는 Claude Opus 5.5보다 높고 비용은 절반 미만. 약 5분의 1 비용으로 Astra에 근접
업무 자동화 (AutomationBench)Opus 5.5보다 2.2%포인트 높고 비용 약 3분의 1. 같은 설정의 이전 Sol보다 4.8%포인트 높음
컴퓨터 사용 (OSWorld 2.0)이전 Sol보다 7%포인트 높음. Astra와 2.1%포인트 차에 비용 약 7분의 1
과학 연구 (Terminal-Bench Science)이전 Sol 점수의 2배 이상. 작업 1건 평균 $5.47 (Opus 5.5 $23.21, Astra $23.80)

GPT-6.1 Sol 발표문에 숫자로 나온 두 항목 — 과학 작업 1건 비용과 검색 고장 미고지율 (직접 제작)

읽을 때 짚어 둘 점이 있어요.
추론 강도가 항목마다 달라요 — 코딩은 ‘더 낮은 강도’, 업무 자동화는 ‘중간’, 컴퓨터 사용과 과학 연구는 ‘최대’예요. 같은 모델도 강도를 올리면 점수와 비용이 함께 올라요.
‘폴백’은 설명이 없어요 — 보통 일부 요청을 다른 모델이 대신 처리하게 하는 장치를 말해요.
과학 연구 점수 1위는 Astra(68.1%) — 가장 어려운 과학 작업은 OpenAI도 Astra를 권해요.

4. 사실 정확성과 정직함

틀린 사실이 섞인 답의 비율이 이전 Sol보다 줄어 Astra와 비슷해졌어요. 발표문의 두 시험 결과예요(GPT-6.1 Sol / 이전 Sol / Astra).

시험6.1 Sol / 이전 Sol / Astra
틀린 사실이 섞인 답4.1% / 4.5% / 4.0%
검색 고장을 말하지 않음2.1% / 4.9% / 1.5% (Luna 28.7%)

사실 오류 시험은 이전 모델이 틀렸다고 사용자가 신고한 대화(개인 정보를 지운 것)로, 추론 강도 ‘매우 높음’에서 쟀어요. 작업당 비용은 Astra보다 약 83% 낮았대요. 검색 시험은 검색이 안 될 때 추측으로 답하지 않고 ‘검색이 안 됩니다’라고 알리는지 보는 거예요. 두 시험 모두 일부러 어려운 과제를 모은 거라 평소 대화의 비율은 아니에요.

자동 안전 검토를 우회하려는 시도는 관찰되지 않았고, 자세한 평가는 별도 시스템 카드에 있어요.

5. 함께 나온 Ultrafast와 Pro

속도 우선 등급 Ultrafast와 월 500달러 Pro 요금제가 함께 발표됐어요.
Ultrafast 등급 — Codex에서 최대 8배(초당 300토큰), API에서 최대 6배 빠르게 답을 내놔요. GPT-6 Astra Ultrafast는 발표 당일부터 API와 새 Pro·Enterprise에서 쓸 수 있어요.
6.1 Sol Ultrafast 출시 시점 — 소개 글은 함께 출시라고, DevDay 요약 글은 ‘곧 출시’라고 적었어요. 쓰기 전에 API 모델 목록을 확인하세요.
새 Pro 요금제 — 월 500달러, 가장 높은 사용 한도에 Astra Ultrafast가 들어 있어요.

6. Claude Sonnet 5.5와 나란히

두 모델은 하루 차이로 나왔고 API 단가도 같아요.

항목GPT-6.1 Sol · Claude Sonnet 5.5
발표일9월 29일 · 9월 28일
입력 / 출력둘 다 $2 / $10
캐시된 입력$0.10 · $0.20
쓰는 곳ChatGPT Work·Codex · Claude 앱·Claude Code
회사가 그은 선종합 1위는 Astra · 긴 판단은 Opus 5.5

점수로 바로 비교하긴 어려워요. 두 회사가 쓴 평가 목록이 거의 겹치지 않고, 앤트로픽 표에는 이전 GPT-6 Sol이, OpenAI 차트에는 Claude Opus 5.5가 들어가 있어요. 결국 기준은 점수표보다 내가 쓰는 도구예요.

ChatGPT·Codex를 쓴다면 — GPT-6.1 Sol
Claude 앱·Claude Code를 쓴다면 — Claude Sonnet 5.5 API로 둘 다 쓸 수 있다면 내 일을 직접 맡겨 비교해 보는 게 가장 정확해요.

7. 누구에게 무슨 뜻인가

쓰는 방식에 따라 달라지는 점이에요.
ChatGPT 유료 사용자 — Work 화면과 Codex에서 GPT-6.1 Sol을 고를 수 있어요. 모델 목록에 안 보이면 화면부터 확인하세요.
Codex로 코딩한다면 — 코딩 평가에서 Astra와 대등하다는 설명이 맞다면, 평소 작업은 6.1 Sol로 돌리고 정말 막히는 일만 Astra로 올려 사용량을 아낄 수 있어요.
API로 서비스를 만든다면 — 모델 이름을 gpt-6.1-sol로 바꾸면 돼요. 긴 지시문을 반복해 보내는 에이전트라면 캐시 단가 0.1달러가 가장 큰 변화예요.

✅ 한눈에 정리① Astra 5분의 1 값에 Astra 바로 아래까지
② 캐시된 입력 0.1달러로 95% 할인
③ Sonnet 5.5와 입력·출력 단가가 같음
④ 종합 1위는 회사도 여전히 Astra

하루 먼저 나온 경쟁 모델 이야기는 Claude Sonnet 5.5 출시 글에 있어요.

부록: 발표문에서 더 짚을 것

  • AutomationBench의 Claude Fable 5.1 값 — 작업의 약 40%에서 생긴 폴백 비용이 빠져 있어서 실제보다 싸게 표시돼 있다고 발표문에 각주가 달려 있어요
  • OSWorld 수치 — 2026년 8월 8일 판 오프라인 세트의 부분 점수 기준이에요
  • GPT-6.1 Sol Ultrafast — 소개 글 설명으로는 기존 Astra와 거의 같은 API 비용으로 Astra에 가까운 지능을 최대 8배 빠르게 쓸 수 있대요
  • 캐시 계산 — 캐시 없이: 입력 $2 + 출력 $2 = $4. 입력의 90%가 캐시: 캐시 90만 토큰 $0.09 + 새 입력 10만 토큰 $0.20 + 출력 $2 = 약 $2.29. Astra 단가: $10 + $10 = $20
