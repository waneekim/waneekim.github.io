오픈AI COOKED 첫 화, Codex 28일 약속 칸에 들어간 영상

오픈AI COOKED 첫 화 — Codex 28일 약속 속 영상 (캐릭터는 AI 이미지 생성)

12월이 되면 하루에 한 칸씩 여는 선물 달력이 있어요. 칸마다 작은 선물이 들어 있다고 믿고 열어 보는 달력이에요. Codex 사용자에게도 이런 달력이 생겼어요. OpenAI의 Tibo(X 계정 @thsottiaux)가 10월 4일(미국 시각) 28일 동안 매일 개선 하나, 아니면 사용량 리셋을 내놓겠다고 약속했거든요.

10월 20일 새벽(한국 시각) 그 열다섯 번째 칸에 들어간 것은 기능도 리셋도 아닌, OpenAI 개발자 계정의 새 영상 시리즈 ‘COOKED’ 첫 화였어요. 영상은 9월 29일 DevDay에서 나온 제품을 요리 방송 형식으로 다시 보여 줬어요. 무엇이 나왔는지, 약속의 15일이 어떻게 채워졌는지, 답글 반응까지 정리했어요.

작은 문이 가득한 선물 달력에서 라면 영상이 나오는 TV 칸이 열리고, 옆에는 선물 상자와 배터리 바구니가 놓인 그림 — 개선이나 리셋 대신 영상이 들어간 날을 빗댄 그림 (AI 이미지 생성)

1. COOKED 첫 화가 보여 준 것

OpenAI 개발자 계정(@OpenAIDevs)은 10월 20일 새벽 3시(한국 시각) ‘COOKED: Ep. 1’을 올렸어요. 13분 20초짜리 영상으로, 진행자 두 명이 라면을 끓이며 DevDay에서 나온 제품을 써 보는 요리 방송 형식이에요. 영상도 첫머리에서 ‘DevDay에서 나온 것들을 직접 해 보고 싶었다’고 소개해요.

요리사 모자를 쓴 로봇이 카메라 앞에서 라면을 끓이고, 조리대에는 삶은 달걀과 작은 휴대용 게임기가 놓인 그림 — 요리 방송 형식의 COOKED 첫 화를 빗댄 그림 (AI 이미지 생성)

영상에 나온 순서대로 표로 옮겼어요. 모두 영상 속 시연이고, 우리가 직접 써 본 결과는 아니에요.

제품영상에서 보여 준 것
ChatGPT 닷츠(dots)재료 사진을 받은 dot이 레시피를 정리, 손님 응대·메일도 맡음
ChatGPT 스페이스(Space)dot이 생각을 적고 사람과 함께 보는 곳, 조리 단계를 정리
GPT-Live-1‘보조 셰프’ 목소리로 라면 조리를 실시간 안내
Codex 클라우드직접 꾸민 클라우드 작업 환경, 노트북을 닫아도 작업이 이어짐
새 Codex CLI중간 ‘광고’ 코너 — 말로 대화, 에이전트 상태 보기, 대화 갈라 내기
Ultrafast휴대용 게임기에서 돌아가는 라면 게임을 즉석에서 만듦

닷츠와 스페이스는 레시피 준비를 맡았어요. 진행자가 재료 사진을 찍어 보내자, 늘 켜져 있는 에이전트 dot이 레시피를 정리했다고 소개해요. 그동안 뒤에서 손님 체크인과 메일 보내기도 맡았대요. 스페이스는 dot이 생각을 적고 사람과 함께 작업하는 곳이에요. 진행자들은 스페이스에 정리된 단계를 보며 조리했어요.

OpenAI DevDay 요약 글은 ChatGPT Space를 팀원·ChatGPT·dot이 지식을 함께 쌓는 공간으로 소개했고, Pro·Business·Enterprise 요금제의 데스크톱 앱과 웹에 열었다고 적었어요. dots가 무엇인지는 10월 4일 글 ‘OpenAI dots(닷츠) 발표, 24시간 일하는 에이전트 정리’에 있어요.

→ OpenAI dots(닷츠) 발표, 24시간 일하는 에이전트 정리

조리 안내는 GPT-Live-1이 맡았어요. 진행자는 이 모델을 OpenAI의 음성용 최첨단(frontier) 모델이자 풀 듀플렉스(듣기와 말하기를 동시에 하는) 모델이라고 소개했어요. 말끝을 흐리거나 ‘음’ 하고 멈춰도 끼어들지 않는다는 걸 보여 줬어요. OpenAI API 문서도 GPT-Live 1을 듣고 말하기를 동시에 하는 실시간 대화용 음성 모델로 설명해요.

Codex 클라우드는 ‘노트북을 닫아도 되는’ 작업 환경으로 나왔어요. 영상은 Codex 클라우드를 DevDay의 또 다른 큰 출시로 꼽고, 나와 팀이 직접 설정한 클라우드 환경에서 일하니 노트북을 닫아도 된다고 설명했어요. DevDay 요약 글은 다시 쓸 수 있는 개발 환경 덕에 작업이 빨리 시작되고, 팀이 승인된 설정을 함께 쓴다고 적었어요.

새 Codex CLI는 영상 중간에 ‘스폰서 광고’처럼 들어갔어요. 전체 화면 모양, 여러 에이전트 상태 보기, 대화를 별도 작업 트리(Git worktree)로 갈라 내기, 터미널과 말로 대화하기 네 가지를 짧게 보여 줬어요. DevDay 요약 글의 ‘새로 다듬은 Codex CLI’(음성으로 작업 시작, /agents 화면, worktree)와 같은 내용이에요.

Ultrafast로는 라면 게임을 만들었어요. 게스트 두 명이 주방 재료로 만든 생강 샷을 한 번에 마신 뒤, Ultrafast로 Mod Retro 휴대용 게임기에서 돌아가는 라면 시뮬레이터를 만드는 도전이었어요. dot 캐릭터를 고르고 냉장고에서 재료를 모아 라면 한 그릇을 완성하는 픽셀 그래픽 게임이에요. 에뮬레이터에서 먼저 돌려 본 뒤, 영상 후반에 실제 게임기에서 실행했어요.

Ultrafast는 같은 DevDay에서 발표된 속도 우선 등급이에요(Codex에서 최대 8배, 초당 300토큰). DevDay 모델 소식은 10월 1일 글 GPT-6.1 Sol 발표, 가격·성능과 Sonnet 5.5 비교, 요금 계산은 10월 9일 글 GPT 솔 울트라패스트, 여섯 배 요금이 붙는 이유에 정리했어요.

커뮤니티 작품 코너도 있었어요. OpenAI 개발자 커뮤니티 담당자가 SNS에 올라온 작품을 골라 와, 잘 익었는지(cooked) 덜 익었는지(undercooked) 팻말로 평가했어요.
① GPT-6.1 Sol로 만든 레트로 우주 슈팅 게임
② GPT-6 Astra로 이삼백 년 동안 풀리지 않았다는 나폴레옹의 편지를 해독한 작품 — 영상 속 설명으로 조회 500만 회 가까이, ‘오늘의 캐치’로 뽑힘
③ 직접 그린 말 모양에 따라 빠르기가 달라지는 말 경주 게임

작품의 원 게시물은 따로 확인하지 못해, 영상에서 소개한 범위로만 적었어요. OpenAI 개발자 계정이 이어 올린 글타래에는 온라인 영화제, iOS 게임, 집 배선 3D 시각화 같은 작품이 더 소개됐어요.

2. 28일 약속, 15일 동안 온 것

이 영상은 Tibo의 ‘28일 약속’ 15일째 자리에 올라왔어요. Tibo는 10월 4일(미국 시각) X에 이렇게 적었어요. “앞으로 28일 동안 매일, 대부분의 Codex·Work 사용자에게 의미 있는 분명한 개선 하나를 내놓거나 사용량 전체를 리셋하겠습니다.”

리셋은 Codex 사용 한도를 처음으로 되돌려 주는 거예요. 한도에 걸려 기다리던 사람에게는 바로 쓸 수 있는 선물이에요. Tibo는 다음 날부터 ‘Day 1/’처럼 번호를 붙여 결과를 올렸어요. 15일까지 올라온 것을 종류별로 나누면 개선 9번, 리셋 5번, 영상 1번이에요.

Tibo의 Codex 28일 약속, 15일까지 개선 9번·리셋 5번·영상 1번 — 날짜 번호별로 칸을 나눈 달력 (직접 제작)

개선 아홉 번의 내용을 표로 옮겼어요. 모두 Tibo 글의 설명이고, 우리가 따로 잰 값은 아니에요.

날개선 내용
Day 1구독으로 쓰는 GPT-6 Astra·GPT-6.1 Sol 기본 속도 약 50% 빠르게
Day 2자동 검토(Approve for me)를 사용량에서 빼는 등 묶음 개선
Day 4방향 수정(steering) 즉시 반영, GPT-6.1 Sol Ultrafast 출시
Day 5데스크톱 앱 다음 메시지 제안(베타, Pro 요금제)
Day 7GPT-6.1 Sol 기본 문맥 272k → 500k 토큰(Codex·Work)
Day 9데스크톱 앱 디스크 저장량 약 60% 줄임
Day 11‘선택한 모델 용량 초과’ 오류 크게 줄임
Day 12서브에이전트 문맥 재사용 등으로 실제 쓸 수 있는 양 늘림
Day 14데스크톱 앱에서 이전 메시지 편집

리셋은 3·6·8·10·13일째, 다섯 번이었어요. 3일째는 Codex와 ChatGPT Work 활성 사용자 4천만 명 돌파를 기념해 유료 계정에 ‘쌓아 둔 리셋’을 넣어 줬어요. 같은 글은 그날 챗GPT 채팅에 GPT-6가 들어간 소식을 ‘가장 큰 것’으로 꼽았어요(10월 8일 글 ‘챗GPT 인텔리전트 UI 정리’). 10일째에는 ‘리셋 버튼을 잃어버렸다는 소문은 크게 과장됐다’는 농담과 함께 리셋했어요.

15일째 글은 “We’re cooked” 한 줄과 함께 COOKED 영상 글을 인용했어요. 한국 시각 10월 20일 새벽 4시 45분에 올라와, 9시간쯤 지나 조회 110만 회를 넘겼어요. cooked는 ‘요리가 다 됐다’는 뜻이면서, 미국 인터넷 말로는 ‘망했다’는 뜻으로도 쓰여요. 영상 제목을 살린 말장난으로 보여요.

3. 답글 반응: 개선도 리셋도 아니다

15일째 글의 답글에는 실망하는 목소리가 많았어요. 눈에 띈 답글을 우리말로 옮기면 이래요.
① “이건 기능도, 개선도, 리셋도 아니잖아요”
② “매일 실제 업무를 낫게 하는 개선이나 리셋 중 하나를 준다고 하지 않았나요?”
③ “‘We’re cooked’라니, Tibo도 상황이 안 좋다는 걸 인정하네요”

세 번째 답글처럼 cooked를 ‘망했다’로 읽은 사람도 있었어요. 답글은 일부를 골라 옮긴 것이고, 전체 여론을 잰 숫자는 아니에요. 영상 자체는 10월 20일 오후 1시(한국 시각) 조회 45만 회를 넘겼어요. 영상을 본 사람과 약속을 기다린 사람의 기대가 달랐던 셈이에요.

4. 우리 시각: 그 칸엔 리셋이 어울렸다

우리 생각은 짧아요. 그날 내놓을 개선이 없었다면, 리셋이 약속에 더 맞았어요. 약속의 문장은 ‘대부분의 사용자에게 분명한 개선’ 아니면 ‘사용량 전체 리셋’이었어요. 사용자 쪽에서 매일 칸을 연다는 건, 그날 바로 쓸 수 있는 무언가를 받는다는 뜻이었어요.

COOKED는 DevDay 제품을 친근하게 다시 보여 주는 영상으로는 볼 만했어요. 다만 영상 속 제품은 DevDay 요약 글에 있거나 이미 OpenAI 문서에 올라 있는 것들이라, 그날 새로 쓸 수 있게 된 것은 찾지 못했어요(10월 20일 확인). 약속은 회사가 스스로 내건 이벤트이고, 15일 가운데 14일은 속도·문맥·오류처럼 매일 쓰는 데 닿는 개선이나 리셋으로 채워졌어요. 그래서 한 칸의 아쉬움이 더 눈에 띄었다고 봐요.

5. 남은 13번에서 볼 것

15일째를 한 번으로 세면, 약속은 13번 남았어요(Day 16부터 Day 28까지). 남은 칸에서 지켜볼 것은 세 가지예요.
