n8n vs Zapier 비교 — 소포마다 돈을 내느냐, 트럭 한 번에 내느냐

택배 회사가 둘 있습니다. 한 곳은 소포 하나를 옮길 때마다 돈을 받아요. 트럭에 소포가 네 개 실렸으면 네 번 계산합니다. 다른 곳은 트럭이 한 번 왕복하면 한 번 계산해요. 소포가 네 개든 열네 개든 같은 값입니다. 어느 쪽이 싼지는 요금표만 봐서는 모릅니다. 내 소포가 하루에 몇 개인지를 먼저 세어야 하죠.

Zapier와 n8n의 차이가 정확히 이겁니다. 둘 다 “A에서 일이 생기면 B, C, D를 자동으로 한다”를 만드는 도구인데, 세는 단위가 다릅니다. 이 글은 요금표를 옮겨 적는 대신 셈법부터 설명하고, 제 블로그 자동화를 두 도구로 옮기면 얼마가 되는지 실제로 계산해 봅니다.

결론 요약

  • Zapier는 태스크, n8n은 실행을 셉니다. 태스크 = 성공한 액션 단계 하나. 실행 = 워크플로 한 바퀴, 단계 수 무관
  • 단계가 많은 자동화일수록 n8n이 유리하고, 단계가 한두 개인 단순 연결은 Zapier 무료(월 100 태스크)로도 됩니다
  • n8n은 직접 설치하면 무료(Community Edition)입니다. 대신 서버와 유지보수가 내 몫이고, 회사 밖에 서비스로 팔 수는 없습니다
  • 제 자동화(하루 1번, 4단계)를 옮기면 Zapier는 월 120 태스크로 무료 한도를 넘고, n8n은 월 30 실행으로 가장 싼 요금제의 1.2%입니다

🧩 1. 둘 다 뭐 하는 물건인가 — 30초 설명

둘 다 구조는 같습니다. 트리거(폼이 제출됐다, 메일이 왔다, 이슈가 올라왔다) 하나에 액션(시트에 적어라, 슬랙에 보내라, 글을 발행해라)을 줄줄이 붙입니다. 코드 없이 화면에서 상자를 잇는 방식이에요. AI 업무 자동화 시작법에서 “반복되는 일의 순서를 적어두는 게 시작”이라고 했는데, 그 순서를 실제로 돌리는 도구가 이 둘입니다.

차이는 세 가지로 요약됩니다.

📦 2. 셈법 — 이게 요금표보다 먼저입니다

Zapier의 태스크. 공식 도움말 기준으로, 성공한 액션 단계 하나가 태스크 하나입니다. 트리거는 세지 않고, 필터·경로(Paths)·포매터·지연·루프 같은 보조 단계도 세지 않아요. 오류로 멈춘 액션도 세지 않습니다. 도움말의 예시가 명확합니다 — 액션이 두 개인 자동화가 열 번 돌면 20 태스크.

n8n의 실행. 요금 페이지 FAQ의 문장 그대로입니다. “실행은 워크플로 전체가 한 번 도는 것이다. 단계가 몇 개든, 데이터를 얼마나 처리하든 상관없이 실행 하나다.”

그림의 예가 제 블로그 공장입니다. 이슈가 올라오면 글을 만들고 사이트·네이버·인스타에 내보내는 흐름 — 트리거 하나에 액션 넷. 하루 한 번, 한 달 30번 돌면 Zapier는 120 태스크, n8n은 30 실행이에요. 여기에 “썸네일 만들기”, “대시보드 갱신” 같은 단계를 하나 더 붙일 때마다 Zapier는 한 달 30 태스크가 늘고, n8n은 그대로입니다.

🔢 4. 내 자동화를 옮기면 얼마인가 — 세 가지 경우

제가 실제로 셈해 본 순서입니다. 여러분 것도 같은 순서로 하면 됩니다.

경우 1 — 지금 제 공장 그대로 (하루 1번, 액션 4개)

  • Zapier: 월 120 태스크. 무료 100을 넘고, 4단계라 무료 플랜(2단계 제한)은 애초에 안 됩니다 → Professional $19.99/월
  • n8n 클라우드: 월 30 실행 → Starter €20/월의 1.2%. 사실상 최저 요금제에서 놀 만큼 남습니다
  • n8n 직접 설치: 0원 + 서버

경우 2 — 단계가 12개로 늘면 (썸네일, 카드뉴스, 릴스, 대시보드…)

  • Zapier: 월 360 태스크 → 여전히 Professional 750 안. 하지만 단계를 더 붙일수록 빠르게 750에 닿습니다
  • n8n: 월 30 실행, 변화 없음

경우 3 — 실행이 하루 100번으로 늘면 (댓글마다, 주문마다 도는 흐름)

  • Zapier: 4단계 × 3,000번 = 월 12,000 태스크 → 태스크 계단을 여러 단 올라가야 합니다
  • n8n 클라우드: 월 3,000 실행 → Starter 2,500을 넘어 Pro €50/월
  • n8n 직접 설치: 여전히 0원. 서버가 버티는지만 문제

정리하면 “단계 수 × 횟수”가 큰 사람일수록 n8n, “횟수는 적고 연결만 몇 개”인 사람일수록 Zapier가 편합니다. OpenAI API 비용 글에서도 결론이 같았어요. 비용 폭탄은 요금표가 아니라 곱셈에서 나옵니다.

🏠 5. 직접 설치 — “무료”의 조건

n8n 문서는 셀프호스팅 Community Edition을 무료라고 명시하고, “거의 전체 기능”이 들어 있다고 합니다. 대신 세 가지가 붙어요.

  • 서버는 내가 마련하고, 설치·업데이트·보안도 내 책임입니다. 문서 표현 그대로 “npm, Docker 또는 서버 설정이 필요”하고 “유지보수는 당신의 책임”입니다
  • 유료 전용 기능이 있습니다. SSO(SAML·LDAP), 프로젝트, 환경 분리, 외부 비밀 저장소, 로그 스트리밍, Git 버전 관리, 워크플로·자격증명 공유 등은 클라우드 유료 플랜이나 기업용에 있습니다. 혼자 쓰면 대부분 필요 없는 것들이에요
  • 라이선스는 “Sustainable Use License”입니다. 오픈소스가 아니라 소스 공개형 라이선스예요. 회사 내부 업무, 개인 용도, 비영리 용도로는 자유롭게 쓰고 고칠 수 있지만, 다른 사람에게 돈을 받고 제공하는 것(예: n8n을 호스팅해서 파는 서비스)은 안 됩니다

서버 비용은 사람마다 다릅니다. 저는 24시간 도는 맥미니가 이미 있어서, 그 글에서 계산한 대기 전력(4W × 24시간 × 30일 ≈ 2.9kWh) 위에 얹히는 셈이에요. 서버가 없는 분은 작은 클라우드 서버 한 대 값이 붙고, 그 값과 n8n Starter €20을 비교하시면 됩니다.

💬 7. 제 답 — 저는 둘 다 안 씁니다, 그리고 그 이유

솔직히 적겠습니다. 제 블로그 공장은 n8n도 Zapier도 아니고 파이썬 스크립트와 윈도우 작업 스케줄러로 돌아갑니다. 이유는 하나예요. 제 자동화의 핵심 단계인 “네이버 에디터에 글을 타이핑해서 발행”은 브라우저를 직접 조작하는 일이라, 두 도구의 기본 노드로는 안 되고 결국 코드를 써야 했습니다. 코드를 써야 한다면 도구를 하나 더 얹을 이유가 없었어요. (그 코드는 전부 AI에게 시켰고, 그 한계는 바이브 코딩의 한계 글에 적었습니다.)

만약 코드 없이 시작해야 했다면 — 이미 켜둔 기계가 있으니 n8n 직접 설치를 골랐을 겁니다. 단계가 매주 늘어나는 자동화라서요. 반대로 “폼 제출되면 시트에 적고 슬랙에 알려라” 정도라면 Zapier 무료로 오늘 끝냈을 거고요.

🎯 시작 코스 — 결정까지 10분

  1. 자동화할 흐름을 한 줄로 적습니다. “○○가 생기면 → A, B, C를 한다”
  2. 한 달에 몇 번 도는지 셉니다 (하루 1번이면 30)
  3. 화살표 뒤의 액션 수를 셉니다 (필터·지연은 빼고)
  4. 횟수 × 액션 수 = Zapier 태스크, 횟수 = n8n 실행. 위 요금표의 한도와 비교합니다
  5. 100 태스크 안이면 Zapier 무료로 시작, 넘으면 n8n 체험(카드 불필요)으로 같은 흐름을 만들어 봅니다. 서버가 있으면 공식 문서의 설치 안내대로 Community Edition을 올려 봅니다

요금표는 다음 달에 바뀔 수 있지만 셈법은 잘 안 바뀝니다. 소포마다 세느냐, 트럭마다 세느냐 — 이것만 기억하면 요금표가 바뀌어도 다시 계산할 수 있어요.

기준: 2026-09-21. 요금·한도는 Zapier 요금 페이지와 n8n 요금 페이지, 태스크 셈법은 Zapier 도움말 “How tasks are counted”, 실행 정의는 n8n 요금 페이지 FAQ, 셀프호스팅 조건과 유료 전용 기능은 n8n 문서 “Choose how to use n8n”, 라이선스는 n8n 저장소의 LICENSE.md를 이날 직접 확인했습니다. 두 도구를 유료로 운영한 경험은 없으며, 4절의 계산은 제 파이프라인의 실행 횟수와 단계 수를 대입한 것입니다. 삽화는 GPT 이미지 생성, 도식은 직접 제작했습니다.
