🥇 1. Claude Code — 실사용, 운영·자동화의 답

터미널(과 VS Code)에서 도는 에이전트입니다. 제 블로그 운영 시스템 전체 — 글 발행, 사이트 배포, 브라우저 자동화 — 를 이걸로 굴립니다. 핵심은 내 컴퓨터에서 직접 실행하고 검증까지 한다는 것. 코드를 한 줄도 안 보는 사용자가 성립합니다. Claude 유료 플랜(Pro 이상)에 포함됩니다.

→ 설치 5분 가이드 · 사용법

🥈 2. Codex — 실사용, 대화로 만드는 첫 결과물

ChatGPT 안에서 대화하듯 시작하는 코딩 에이전트. 5가족 여행 앱을 이걸로 만들었습니다. 기획 대화와 제작이 한 흐름으로 이어지는 게 강점이고, ChatGPT 구독에 포함됩니다. 1회성 결과물엔 이쪽이 매끄러웠어요.

→ Claude Code vs Codex 실사용 비교

🔍 3~5. 조사 기반 — Cursor, Copilot, Gemini CLI

Cursor — AI가 깊게 통합된 코드 에디터(VS Code 기반). 코드를 눈으로 보며 통제하고 싶은 현직 개발자의 도구입니다. 에디터형과 에이전트형의 구조 차이는 별도 글에 정리했습니다.

GitHub Copilot — 기존 에디터에 붙는 보조형의 원조. 자동완성부터 에이전트 기능까지 확장 중이고, GitHub 생태계(PR 리뷰 등)와의 결합이 강점입니다.

Gemini CLI — 구글의 터미널 에이전트. 무료 티어가 넉넉한 편이라 “에이전트형을 일단 맛보고 싶다”에 맞습니다.

셋 다 실사용 평가가 아니므로, 후보를 좁힌 뒤 실제 사용자의 후기를 찾아보시길 권합니다.
