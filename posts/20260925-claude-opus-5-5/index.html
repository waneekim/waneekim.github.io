Claude Opus 5.5 벤치마크·가격, Fable 5.1과 비교

Claude Opus 5.5 — Fable 5.1과 벤치마크 비교 (캐릭터는 GPT 이미지 생성)

휴대폰을 살 때 이런 일이 있어요. 올해 나온 일반 모델이 작년 최고급 모델만큼 빠른데, 값은 훨씬 싸요. 그러면 고민이 시작되죠. “비싼 거 살 이유가 남았나?”

2026년 9월 22일 앤트로픽이 내놓은 Claude Opus 5.5가 딱 그 모양이에요. 회사의 한 줄 설명은 “대부분의 작업에서 Claude Fable 5.1 수준으로 작동하고, 운영 비용은 Opus 5보다 40% 적다”예요.
아래 등급 이름을 단 Opus 5.5가 공식 성능표에서 윗급 Fable 5.1을 앞섰다는 게 이번 발표의 핵심이에요.

두 휴대폰을 든 로봇 — 비싼 모델과 새 모델의 칩이 똑같이 빛난다 (GPT 이미지 생성)

1. 무슨 일이 있었나

앤트로픽이 9월 22일 새 5.5 세대의 첫 모델 Claude Opus 5.5를 내놓았어요. API 이름은 claude-opus-5-5이고, AWS·구글 클라우드·마이크로소프트 애저를 포함한 모든 플랫폼에서 바로 쓸 수 있어요. 비교 대상인 Fable 5.1은 3주 전인 9월 1일에 나온, 일반 사용자가 쓸 수 있는 앤트로픽 최상위 모델이에요.

⚠️ 출처 안내성능·가격 수치는 2026년 9월 25일 기준 앤트로픽 공식 발표를 옮겼어요. 회사가 직접 잰 값이라 독립 검증 전이고, 모델마다 측정 설정이 다른 항목이 있어요.

발표를 세 줄로 줄이면 이래요.
→ Opus 5 대비: 공식 표의 벤치마크 9개가 모두 오르고, 토큰 단가는 20% 내리고, 출력 속도는 30% 이상 빨라졌어요.
→ Fable 5.1 대비: 9개 항목 모두 앞서고, 토큰 단가는 60% 싸요.
→ GPT-6 Astra 대비: 수치가 나란히 있는 6개 중 4개에서 앞서고, 업무 자동화와 과학 연구 작업 2개는 Astra가 높아요.

2. 성능 지표, 공식 표 읽는 법

공식 발표의 벤치마크 표는 9개 항목, 모델 5개예요. 네 모델이 모두 점수를 가진 다섯 항목을 먼저 그림으로 보면 이래요. 9개 항목 전체 수치는 4번 표에 있어요.

Claude Opus 5.5 벤치마크 — Opus 5.5·Fable 5.1·Opus 5·GPT-6 Astra가 모두 점수를 가진 5개 항목 (직접 제작)

표를 읽을 때 알아 둘 각주가 세 가지 있어요.

① 설정이 같지 않아요. Opus 5.5는 따로 적지 않으면 ‘적응형 사고 최대 노력’ 설정이고, Terminal-Bench 4.0은 Opus 5.5가 xhigh, GPT-6 Astra가 high 설정으로 잰 값이에요.
② AutomationBench는 측정 경로가 달라요. Opus 5.5는 Zapier가 얼리 액세스 기간에 직접 잰 값이고, 나머지 모델은 Zapier 공개 리더보드 값이에요. 대체 모델 없이 돌려서, 안전장치가 끼어든 경우는 실패로 셌다고 해요.
③ 오차가 있어요. Terminal-Bench 4.0 표준오차는 Opus 5.5 ±2.6점, 다른 Claude 모델 ±1.6~2점이고, Terminal-Bench-Science는 모델마다 ±3.5점에서 ±5점 사이예요.

1~2점 차이는 사실상 같은 수준으로 보는 게 맞아요.

3. 이전 버전 Opus 5와 달라진 것

값은 20% 내리고, 점수는 9개 항목 모두 올랐어요. 100만 토큰당 공식 단가를 비교하면 이래요.

항목 (100만 토큰당)Opus 5 → Opus 5.5
입력 토큰$5 → $4 (20% ↓)
출력 토큰$25 → $20 (20% ↓)
캐시 읽기$0.50 → $0.20 (60% ↓)
캐시 쓰기$6.25 → $5 (20% ↓)

출력 속도는 Opus 5보다 30% 이상 빨라졌고, 일반적인 작업 비용은 약 40% 줄어든다는 게 앤트로픽 추산이에요.

점수는 과학 연구 작업이 가장 크게 뛰었어요. Terminal-Bench-Science 점수가 29.0%에서 58.7%로 두 배가 됐어요. 에이전트 코딩(Terminal-Bench 4.0)은 14.1점, 업무 자동화(AutomationBench)는 13.1점, Cursor 안 작업(CursorBench)은 11.2점 올랐어요.

반면 차트 읽기(+5.6점)나 고난도 지식 문제(+4.1점)는 오름폭이 작아요. 코딩과 ‘일을 끝까지 해내는’ 에이전트 작업 쪽이 크게 좋아진 세대라고 읽을 수 있어요.

빠른 응답이 필요할 때 쓰는 Fast 모드도 있어요. Claude Code와 Claude Platform에서 최대 2.5배 속도로 쓸 수 있고, 값은 입력 $8·출력 $40으로 두 배예요.

4. Fable 5.1과 비교, 윗급을 넘었나

공식 표에서 Opus 5.5는 윗급 Fable 5.1을 9개 항목 모두 앞서고, 값은 60% 싸요. Fable 5.1은 앤트로픽이 ‘미토스(Mythos)급 모델’이라 부르는, 일반에 공개된 최상위 모델이에요. AI 사이버보안 모델 글에서 다뤘듯 Fable 5.1과 Mythos 5.1은 같은 모델에 안전장치만 다르게 건 거예요.

9개 항목을 차이가 큰 순서로 정리했어요.

항목Fable 5.1 → Opus 5.5
단가 (입력 / 출력, 100만 토큰당)$10 / $50 → $4 / $20 (60% 쌈)
Terminal-Bench 4.0 · 에이전트 코딩55.8% → 66.4% (+10.6)
GDPval-AA v2.1 · 44개 직업 실무 (Elo)1735 → 1846 (+111)
AutomationBench · 업무 자동화31.4% → 40.0% (+8.6)
Terminal-Bench-Science 0.1 · 과학 연구52.6% → 58.7% (+6.1)
CursorBench 4.0 · Cursor 안 작업51.8% → 57.8% (+6.0)
FrontierCode v1.1 · 어려운 코딩50.3% → 54.4% (+4.1)
Humanity’s Last Exam · 고난도 지식65.6% → 67.7% (+2.1)
OSWorld 2.1 · 컴퓨터 조작80.7% → 81.8% (+1.1)
Chartography · 차트 읽기88.4% → 89.0% (+0.6)

아래 세 줄은 1~2점 차이라, 오차를 생각하면 사실상 비슷해요. 차이가 뚜렷한 건 에이전트 코딩, 실무 과제(GDPval), 업무 자동화, 과학 연구 쪽이에요.

입력 100만 토큰에 출력 20만 토큰을 쓰는 작업이라면, 공식 단가로 계산한 값은 이래요.
→ Fable 5.1: $10 + 0.2 × $50 = $20
→ Opus 5: $5 + 0.2 × $25 = $10
→ Opus 5.5: $4 + 0.2 × $20 = $8

5. 경쟁 모델, 어디서 이기고 지나

발표 표에 나란히 실린 경쟁 모델은 OpenAI의 GPT-6 Astra와 GPT-5.6 Sol 둘이에요. Astra는 GPT-6 아스트라 글에서 다룬 그 모델이에요.

Opus 5.5가 앞서는 곳: 에이전트 코딩(66.4 vs 57.9), 어려운 코딩(54.4 vs 53.3), 실무 과제 GDPval(1846 vs 1542), 고난도 지식 문제(67.7 vs 57.2)
GPT-6 Astra가 앞서는 곳: 과학 연구 작업(64.6 vs 58.7), 업무 자동화(41.4 vs 40.0)
비교할 수 없는 곳: Cursor 안 작업·컴퓨터 조작·차트 읽기는 Astra 값이 표에 없어요

막대 점수판 옆에서 어깨를 으쓱하는 로봇 — 대부분 이겼지만 두 칸은 옆 로봇이 높다 (GPT 이미지 생성)

두 가지는 조심해서 보세요. 어려운 코딩(+1.1)과 업무 자동화(−1.4)는 차이가 작아 오차 범위 안이에요. 그리고 업무 자동화는 앞에서 말했듯 두 모델의 측정 경로가 달라요. GPT-5.6 Sol은 값이 있는 모든 항목에서 Opus 5.5보다 낮아요.

6. 안전성, 발표문이 밝힌 것

능력이 올라간 만큼 안전장치도 Fable 5.1 수준으로 걸었다는 게 회사 설명이에요. 앤트로픽은 출시 전 외부 기관(Frontier Design, METR)의 평가를 받았다고 밝혔어요. 자사의 가장 포괄적인 정렬 테스트인 자동 행동 감사에서는 ‘지금까지 시험한 모델 중 가장 좋은 성적’이었고, 경계를 넘으려는 시도는 Opus 5나 Claude Mythos 5.1보다 약 85% 적었다고 해요.

유리 시험실 안의 로봇을 돋보기로 살피는 검사 로봇 — 출시 전 안전성 평가 (GPT 이미지 생성)

발표문은 ‘Opus 5.5는 생물학과 사이버보안에서 Claude Mythos 5.1과 비슷한 수준이라, Fable 5.1과 비슷한 안전장치를 걸고 배포한다’고 적었어요. 동시에 ‘배포 전에 모든 실패를 확실히 잡아내는 평가를 만드는 건 아직 풀리지 않은 문제’라고도 밝혔어요.

7. 누구에게 무슨 뜻인가

API로 Fable 5.1을 쓰던 팀이라면 같은 일을 Opus 5.5로 돌려 결과를 비교해 볼 이유가 생겼어요. 공식 단가로 60% 싸요. 다만 점수 차이가 작은 영역(차트 읽기, 컴퓨터 조작)은 직접 비교가 필요해요.

Opus 5를 쓰던 팀이라면 모델 이름만 바꿔도 단가가 20% 내려가요. 캐시를 많이 쓰는 작업이면 캐시 읽기가 60% 싸져서 차이가 더 커요.

과학 연구·업무 자동화가 주력인 팀이라면 이 두 영역은 GPT-6 Astra가 표에서 앞서요. 한쪽으로 정하기 전에 자기 작업으로 둘 다 돌려 보세요.

💡 핵심앤트로픽도 '이 수준에서는 벤치마크 차이가 실제 차이를 덜 알려 준다'고 적었어요. 내 일로 직접 돌려 보는 게 가장 정확한 벤치마크예요.

다음 소식으로, 앤트로픽은 Sonnet 5.5와 Haiku 5.5가 몇 주 안에 같은 개선을 담아 나온다고 예고했어요.

✅ 한눈에 정리① 9월 22일 출시 · 입력 $4 · 출력 $20
② Opus 5보다 9개 항목 모두 오르고 20% 싸요
③ Fable 5.1보다 9개 모두 앞서고 60% 싸요
④ 과학 연구·업무 자동화는 GPT-6 Astra 우위

Fable 5.1과 Mythos 5.1이 왜 같은 모델에 안전장치만 다르게 걸었는지는 이전 글에서 다뤘어요. AI 회사들이 해킹 능력 모델의 문을 잠근 이야기예요.
