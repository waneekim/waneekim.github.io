⚙️ 1. 설치 — 방법 4가지 중 하나만

30초 안에 고르자. 고민되면 A다.

방법 A. PowerShell 한 줄 (공식 권장)

PowerShell을 열고:

irm https://claude.ai/install.ps1 | iex

자동 백그라운드 업데이트까지 해줘서 이후 신경 쓸 게 없다. irm is not recognized 오류가 나면 CMD에서 실행한 것이다 — PowerShell에서 다시 하자.

방법 B. winget (내가 쓰는 방법)

winget install Anthropic.ClaudeCode

이 머신이 이 방법으로 설치돼 있다. 단점 하나: 업데이트가 자동이 아니라서 가끔 winget upgrade Anthropic.ClaudeCode를 직접 돌려야 한다.

방법 C. CMD 파

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

방법 D. npm (Node.js 22+ 있는 개발자)

npm install -g @anthropic-ai/claude-code

뭘 고를까? 고민되면 A. 이미 winget으로 프로그램을 관리하고 있다면 B.

🔑 2. 설치 확인과 첫 로그인

새 터미널을 열고(중요 — 기존 터미널은 PATH를 모른다):

claude --version

버전이 찍히면 성공이다. 이 머신에서는 2.1.229 (Claude Code)가 나온다. 이제 작업할 폴더로 이동해서:

cd 내-프로젝트-폴더
claude

🚑 4. 안 될 때 — Windows에서 흔한 문제 3가지

① 'claude' is not recognized — 십중팔구 PATH 문제거나 터미널을 재시작 안 한 것.

# 사용자 PATH에 설치 경로 추가
$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

추가 후 터미널을 완전히 닫고 새로 열자.

② irm is not recognized / && is not valid — PowerShell 명령을 CMD에서(또는 그 반대로) 실행한 것. 방법 A는 PowerShell, 방법 C는 CMD 전용이다.

③ TLS/SSL 연결 오류 — 오래된 환경에서 TLS 1.2가 꺼져 있는 경우:

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
