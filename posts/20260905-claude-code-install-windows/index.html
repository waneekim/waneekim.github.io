클로드 코드 설치 방법, 윈도우에서 파워셸 한 줄로 끝내기

클로드 코드 설치 방법 — 윈도우에서 파워셸 한 줄로 (캐릭터는 GPT 이미지 생성)

클로드 코드를 써 보려고 공식 문서를 열면 설치 명령이 네 가지나 나와요. “이 중에 뭘 쳐야 하지?” 터미널이 낯설면 여기서 창을 닫게 되죠.

전동 드릴을 선물 받았는데 배터리가 따로 든 상자를 열어 본 적 있으세요? 물건은 이미 좋은데, 끼우기 전까지는 아무 일도 일어나지 않아요. 클로드 코드도 같아요. 설치와 로그인, 이 두 단계가 배터리를 끼우는 일이에요.
윈도우에서는 파워셸에 명령 한 줄을 붙여 넣고, 브라우저로 로그인하면 준비가 끝나요.

드릴은 있는데 배터리가 따로 든 상자 — 설치 전의 클로드 코드 (GPT 이미지 생성)

🎯 이 글에서 얻는 것대상: 윈도우에 클로드 코드를 처음 까는 분
① 설치 방법 네 가지와 고르는 기준
② 설치 확인과 첫 로그인
③ 막힐 때 흔한 오류 세 가지
준비물: 클로드 유료 플랜 · 파워셸
2026년 10월 기준 · Windows 11 · 2.1.268

1. 시작 전에 확인할 것

계정부터 확인하세요. 클로드 코드는 무료 플랜으로는 쓸 수 없어요. 공식 문서 기준으로 Pro·Max·Team·Enterprise 또는 Console 계정이 있어야 해요. 컴퓨터 조건은 아래와 같아요.

항목조건
운영체제Windows 10 1809 이상 (이 글은 Windows 11)
메모리4GB 이상, x64 또는 ARM64
계정Pro·Max·Team·Enterprise 또는 Console
노드(Node.js)필요 없음 — npm으로 설치할 때만 22 이상
깃(Git for Windows)선택 — 있으면 Bash 도구를 써요
관리자 권한필요 없음

여기서 걸리는 건 대부분 계정이에요. 무료 계정으로 설치까지는 되지만, 쓰려고 하면 막혀요. Git for Windows가 없으면 클로드 코드는 셸 명령을 파워셸로 실행해요.

2. 설치 방법 고르기

고민되면 방법 A, 파워셸 한 줄이에요. 공식 문서가 권장하고, 자동 업데이트까지 돼요. 어떤 방법으로 깔아도 결과는 같은 클로드 코드예요. 업데이트 방식만 달라요.

클로드 코드 설치 방법 고르기 — 파워셸 한 줄, winget, npm, CMD 중 하나 (직접 제작)

정리하면 이래요.
방법 A. 파워셸 한 줄 — 공식 권장, 백그라운드 자동 업데이트
방법 B. winget — 윈도우 패키지 관리자, 업데이트는 직접
방법 C. 명령 프롬프트(CMD) — A와 같은 설치를 CMD에서
방법 D. npm — Node.js 22 이상을 이미 쓰는 분

3. 방법 A: 파워셸 한 줄 설치

파워셸을 열고 아래 한 줄을 붙여 넣으면 설치가 끝나요.

  1. 시작 메뉴에서 PowerShell을 검색해 여세요.→ 입력 줄이 PS로 시작하면 파워셸이에요. 관리자로 열 필요는 없어요.
  2. 아래 한 줄을 붙여 넣고 Enter를 누르세요.
irm https://claude.ai/install.ps1 | iex

→ 설치 프로그램이 클로드 코드를 내려받아 설치해요.
→ 설치 폴더는 %USERPROFILE%\.local\bin이고, 이후 업데이트는 백그라운드에서 자동으로 돼요.

명령 프롬프트(CMD)에서 하고 싶다면 방법 C 명령을 쓰면 돼요. 한 줄이 길어서 폰 화면에서는 잘리니, 사이트판에서 복사 버튼으로 가져가세요.

⚠️ 주의이 명령은 내려받은 내용을 그대로 실행해요. 블로그·영상에서 본 설치 명령은 주소가 claude.ai인지 확인하고, 공식 문서의 명령을 복사하세요.

4. 방법 B: winget 설치

winget으로 프로그램을 관리하고 있다면 이 방법이 편해요. 제 머신도 이 방법으로 깔려 있어요. 단, winget 설치는 자동으로 업데이트되지 않아요. 가끔 둘째 줄을 직접 실행해야 해요.

winget install Anthropic.ClaudeCode
winget upgrade Anthropic.ClaudeCode

→ 첫 줄은 설치, 둘째 줄은 업데이트예요. 오늘(10월 7일) 확인해 보니 제 머신에 깔린 버전은 2.1.268인데, winget에 올라온 최신 버전은 2.1.286이었어요. winget은 업데이트를 직접 챙겨야 한다는 걸 그대로 보여 주는 숫자예요.

5. 방법 D: npm 설치

Node.js 22 이상을 이미 쓰는 개발자라면 npm으로도 깔 수 있어요. npm으로 깔아도 같은 클로드 코드가 설치돼요. Node.js가 없다면 이 방법을 고를 이유가 없어요.

npm install -g @anthropic-ai/claude-code

→ 업데이트할 때는 같은 명령 끝에 @latest를 붙여 실행해요.

6. 설치 확인하고 첫 로그인

설치가 끝나면 새 터미널 창에서 버전부터 확인하세요. 설치 전에 열어 둔 창은 새 경로(PATH)를 몰라서, 같은 창에서는 claude를 못 찾을 수 있어요.

  1. 터미널 창을 모두 닫고 새로 여세요.
  2. 아래 한 줄을 입력하세요.
claude --version

→ 2.1.268 (Claude Code)처럼 버전 숫자가 찍히면 설치 성공이에요. 제 머신에서 10월 7일에 찍힌 값이에요.

  1. cd 명령으로 작업할 폴더에 들어간 뒤 claude를 입력하세요.→ 브라우저가 열리고 클로드 계정 로그인 화면이 떠요.
  2. 클로드 계정으로 로그인하세요.→ 로그인이 끝나면 터미널에 대화 화면이 열려요. API 키를 따로 만들 필요는 없어요.

claude를 처음 실행하면 열리는 로그인 화면 — 위쪽에 클로드 코드 안내 줄이 보여요 (직접 캡처)

배터리를 끼우자 드릴이 돌아가는 장면 — 로그인까지 끝난 클로드 코드 (GPT 이미지 생성)

로그인이 됐다면 첫 요청을 한국어로 넣어 보세요. 제가 이 블로그 저장소에서 실제로 입력했던 요청이에요.

📋 그대로 복사해 쓰세요

이 저장소 구조를 파악하고 실행 계획 문서를 만들어줘

설치 상태가 궁금하면 claude doctor를 입력해 보세요. 세션을 열지 않고 설치 상태만 점검해 줘요. 제 머신에서는 설치 방식이 winget으로 나오고, 마지막 줄에 No installation issues found가 떠요.

7. VS Code에서 쓰려면

VS Code 1.94.0 이상이면 확장 탭에서 ‘Claude Code’를 검색해 설치하면 돼요. 로그인은 같은 클로드 계정으로 하고, 여기서도 API 키는 필요 없어요. 이 블로그 작업도 VS Code 확장에서 하고 있어요.

확장 안에는 클로드 코드가 따로 들어 있어요. 다만 VS Code 아래쪽 터미널에서 claude를 직접 치려면 위의 설치가 따로 필요해요.

막힐 때

claude를 인식할 수 없다고 나와요
원인: 설치 전에 열어 둔 터미널이거나, 설치 폴더가 PATH에 없어요.
해결: 터미널을 모두 닫고 새로 여세요. 그래도 안 되면 사용자 PATH에 %USERPROFILE%\.local\bin을 추가하세요. 붙여 넣을 두 줄은 사이트판에 있어요.

irm을 인식할 수 없다거나, &&가 올바른 구분 기호가 아니라고 나와요
원인: 셸을 잘못 고른 거예요. irm이 안 되면 명령 프롬프트(CMD)에, &&가 안 되면 파워셸에 있는 거예요.
해결: 방법 A는 파워셸에서, 방법 C는 명령 프롬프트에서 실행하세요. 입력 줄이 PS로 시작하면 파워셸이에요.

보안 연결(SSL/TLS) 오류가 나요
원인: 오래된 환경에서 TLS 1.2가 꺼져 있을 때 나요.
해결: 파워셸에서 TLS 1.2를 켜는 한 줄을 먼저 실행하고 설치 명령을 다시 넣으세요. 이 한 줄도 사이트판에 있어요.

💡 핵심설치가 안 된 것 같으면, 먼저 터미널을 새로 열어 보세요.

오류 메시지를 AI에게 물어볼 때는 이렇게 붙여 넣으면 돼요. [ ] 안을 바꿔 쓰세요.

윈도우 파워셸에서 클로드 코드를 설치하다가 아래 오류가 났어. 원인과 해결 순서를 알려줘: [오류 메시지 붙여 넣기]
✅ 한눈에 정리① 고민되면 파워셸 한 줄 — 자동 업데이트까지
② 무료 플랜으로는 못 써요 — 계정 먼저
③ 설치 뒤엔 새 터미널에서 claude --version
④ winget은 가끔 winget upgrade로 직접 업데이트

자주 묻는 질문

Q. 무료 계정으로도 쓸 수 있나요?

아니요. 공식 문서 기준으로 Pro·Max·Team·Enterprise 또는 Console 계정이 필요하고, 무료 플랜에는 클로드 코드가 들어 있지 않아요.

Q. API 키를 따로 발급받아야 하나요?

아니요. claude를 처음 실행하면 브라우저가 열리고, 클로드 계정으로 로그인하면 돼요.

Q. 업데이트는 어떻게 하나요?

파워셸·CMD 설치(방법 A·C)는 백그라운드에서 자동으로 돼요. winget은 winget upgrade Anthropic.ClaudeCode를, npm은 같은 설치 명령 끝에 @latest를 붙여 직접 실행해요.

Q. Git for Windows는 꼭 깔아야 하나요?

선택이에요. 없으면 클로드 코드가 셸 명령을 파워셸로 실행하고, 있으면 Git Bash로 Bash 도구를 써요.

방법 C. 명령 프롬프트(CMD)에서 설치

curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd

‘claude’를 인식할 수 없을 때 — 사용자 PATH에 설치 폴더 추가 (파워셸)

$currentPath = [Environment]::GetEnvironmentVariable('PATH', 'User')
[Environment]::SetEnvironmentVariable('PATH', "$currentPath;$env:USERPROFILE\.local\bin", 'User')

추가한 뒤 터미널을 완전히 닫고 새로 열어 claude --version으로 확인하세요.

보안 연결(SSL/TLS) 오류가 날 때 — TLS 1.2를 켜고 다시 설치 (파워셸)

[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12
irm https://claude.ai/install.ps1 | iex
