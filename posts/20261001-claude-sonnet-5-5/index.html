Claude Sonnet 5.5가 나왔다는 소식을 보면 이 질문부터 들어요. “그럼 이제 Opus는 안 써도 되나?” 가격·속도·공식 지표를 한자리에 놓고 보면 답이 보여요.

자동차 신형이 나왔는데 가격표가 작년과 똑같다고 해 볼게요. 그런데 보닛을 열어 보니 엔진은 윗급 모델에 들어가던 것과 거의 같은 물건이에요. 2026년 9월 28일 앤트로픽이 내놓은 Claude Sonnet 5.5가 그런 모양이에요.
Claude Sonnet 5.5는 Sonnet 5와 같은 값에 30% 이상 빨라지고, 공식 지표 8개가 모두 오른 중간급 모델이에요.

⚠️ 출처 안내성능·가격 수치는 2026년 9월 28일 앤트로픽 공식 발표와 공식 문서를 옮긴 거예요. 회사가 직접 잰 값이라 독립 검증 전이에요.

1. 무엇이 나왔나

Sonnet 5.5는 Claude 5.5 계열의 두 번째 모델이고, 윗급은 Opus 5.5예요.

API 이름은 claude-sonnet-5-5이고, Claude 앱과 API, AWS·구글 클라우드·마이크로소프트 애저에서 쓸 수 있어요. 가볍고 많이 쓰는 용도의 Haiku 5.5는 ‘앞으로 몇 주 안에’ 나온다고 예고했어요.

앤트로픽은 두 모델의 역할을 이렇게 나눴어요.
윗급 Opus 5.5 — 신중한 판단이 필요한 복잡한 일
이번 Sonnet 5.5 — 범위가 정해진 일상 업무, 버그 고치기, 깔끔한 문서·슬라이드·스프레드시트 만들기

공식 모델 비교표는 Sonnet 5.5를 ‘속도와 지능의 가장 좋은 조합’이라고 소개해요. 응답 속도 칸에는 Sonnet 5.5가 ‘빠름’, Opus 5.5가 ‘보통’으로 적혀 있어요.

2. 가격과 스펙

가격은 Sonnet 5와 같은 100만 토큰당 입력 2달러·출력 10달러예요. 공식 가격표와 모델 비교표의 값을 표로 옮겼어요.

항목Sonnet 5.5
입력 / 출력 (100만 토큰당)$2 / $10 (Opus 5.5는 $4 / $20)
캐시 읽기 / 5분 캐시 쓰기$0.20 / $2.50 (Opus 5.5는 $0.20 / $5)

Sonnet 5의 2달러·10달러는 원래 8월 말까지의 출시 기념 가격이었어요. 9월 1일부터 3달러·15달러로 오를 예정이었는데, 앤트로픽이 이 인상을 취소하고 정식 가격으로 바꿨어요. Sonnet 5.5도 Sonnet 5와 같은 값이에요.

3. 공식 지표 8개

공식 표의 지표 8개가 모두 올랐고, 터미널 코딩 지표는 10.3%에서 70.6%로 뛰었어요. 앤트로픽 발표 표에서 Sonnet 5, Sonnet 5.5, Opus 5.5 값을 옮겼어요.

표를 읽을 때 짚어 둘 점이 있어요.
측정 설정 — Opus 5.5의 Terminal-Bench는 생각 강도 Xhigh, Sonnet 5.5의 FrontierCode는 Max에서 잰 값이에요. Sonnet 5.5는 이 지표에서 Max가 오히려 Xhigh보다 낮았대요. 하위 에이전트로 검토를 쪼개 돌리다 시간 초과가 나거나 과제 범위 밖까지 고친 경우가 있었다고 해요.
실무 지표 2개 — 출시 전 버전으로 잰 값인데, 그 버전에 정해진 형식으로 답하는 기능을 약하게 만드는 버그가 있었고 지금은 고쳤대요. 회사는 실제보다 낮게 나왔을 거라고 봐요.

Sonnet 가운데 처음으로 화면만 보고 포켓몬 레드를 깼다는 문장도 발표문에 있어요.

4. Opus 5.5와 비교

토큰 단가는 Opus 5.5의 절반인데, 터미널 코딩은 앞서고 실무 지표는 2점 차예요. 나머지 지표는 Opus 5.5가 조금씩 높아요.

형과 거의 같은 키가 된 동생 — Opus 5.5와 Sonnet 5.5 (GPT 이미지 생성)

단가로만 계산하면 입력 100만·출력 20만 토큰짜리 일이 Opus 5.5는 8달러, Sonnet 5.5는 4달러예요. 실제로는 모델마다 같은 일에 쓰는 토큰 수가 달라서 단가 비교일 뿐이에요.

그런데 앤트로픽은 발표문에 이렇게 선을 그었어요. “벤치마크 점수는 능력의 한 면만 보여 줍니다. 오래 판단을 이어 가야 하는 복잡하고 열린 일에서는 Opus 5.5가 여전히 확실히 더 강합니다.” 범위를 지키며 정확히 고치는 FrontierCode에서 차이가 가장 큰 것도 같은 이야기로 읽혀요.

이런 일은 Sonnet 5.5 — 문서 정리, 슬라이드·표 만들기, 범위가 분명한 버그 고치기
이런 일은 Opus 5.5 — 오래 고민해야 하는 기획·분석, 여러 파일을 오래 손보는 큰 작업

5. 작업당 비용

토큰 단가는 Sonnet 5와 같지만, 같은 일을 더 적은 토큰으로 끝내서 작업 한 건당 비용이 최대 30% 적었대요(회사 시험).

택시 미터기 단가가 같아도 길을 잘 아는 기사는 덜 돌아가니 요금이 덜 나오죠. 앤트로픽이 비용 이야기를 꺼낸 방식이 이 ‘덜 돌아가기’예요. 미리 써 본 사람들은 Sonnet 5.5가 도구 호출을 한데 묶어 보내는 일이 많아서 단계가 줄었다고 했대요.

지표 하나씩 보면 차이가 더 큰 곳도 있어요. 발표문 그림 설명에 적힌 비교예요.

지표 · Sonnet 5.5 설정Sonnet 5와 비교한 작업당 비용
터미널 코딩 · Medium 설정Sonnet 5 최고점을 넘고 10분의 1 미만
Cursor 안 작업 · Low 설정Sonnet 5 최고점을 넘고 10분의 1 미만
실무 과제 · Medium 설정Sonnet 5 최고점을 넘고 약 9분의 1
코드 수정 · High 설정같은 High의 Sonnet 5보다 10점 높고 약 15분의 1

‘최대 30%’는 전반적인 수치이고, 표는 지표 하나에서 정해진 설정끼리 맞대 본 값이에요.

Opus 5.5와 견주면 회사 설명이 더 조심스러워요. 토큰 단가는 절반이지만(캐시 읽기만 둘 다 0.2달러), 회사 설명은 “낮은 설정에서 작업당 비용이 적고, 높은 설정에서는 비슷한 비용으로 비슷한 성능”이에요. Opus 5.5에 맞먹는 점수는 생각 강도를 끝까지 올렸을 때 나오고, 그때는 일 한 건 값도 비슷해진다는 뜻이에요. 시스템 카드에는 SWE-Bench Pro처럼 격차가 남은 지표(81.3% 대 89.9%)도 있어요.

💡 핵심반값 효과가 가장 큰 건 Low·Medium 설정으로 충분한 일이에요.

6. 안전 조치

성능이 오르면서 안전 조치도 윗급 수준으로 올렸어요.
사이버보안 — 해킹 쪽 능력이 Opus 5와 비슷해서, 위험도가 높은 사이버보안 작업은 눈에 보이게 Sonnet 5로 넘어가 처리돼요. 내 코드의 버그를 찾고 고치는 건 평소처럼 돼요.
생각 빼내기 방지 — 생각 과정을 빼내 다른 모델 학습에 쓰는 시도를 막는 분류기를 단 첫 Sonnet이에요.
생각 기록의 주인 — 생각 기록을 그 기록을 만든 계정에서 떼어 쓸 수 없게 했어요.
생명과학 — 안전 조치는 Sonnet 5와 같은 수준이래요.

7. 누구에게 무슨 뜻인가

쓰는 도구에 따라 이렇게 나눠 보면 돼요.
Claude 앱 사용자 — 기본 생각 강도가 Medium이에요. 문서 정리·슬라이드·일상 질문은 Sonnet 5.5, 오래 고민할 기획·분석은 Opus 5.5로 나눠 쓰면 돼요.
Claude Code 사용자 — 기본은 Medium이에요. 범위가 분명한 버그는 Sonnet 5.5, 여러 파일을 오래 손보는 작업은 Opus 5.5가 회사 설명과 맞아요.
API 사용자 — 모델 이름만 claude-sonnet-5-5로 바꾸면 되고 단가표는 Sonnet 5 그대로예요. 실제 청구액은 토큰이 줄어든 만큼 내려갈 수 있어요.

제 생각 — 모델 고르는 기준이 바뀌고 있어요. 이번 발표의 성능 그림은 가로축이 전부 ‘작업 한 건에 얼마’였어요. 앤트로픽 개발자 문서도 “돈은 끝낸 작업 단위로 내니, 완료한 작업당 비용으로 비교하라”고 하고, 가장 어려운 10%의 일로 비교하라고 덧붙여요.

그래서 저는 기준이 ‘가장 센 모델’에서 일 한 건을 끝내는 데 드는 값으로 옮겨 가고 있다고 봐요. 자주 하는 일과 가장 까다로운 일을 Sonnet 5.5(낮은 설정)와 Opus 5.5에 똑같이 맡겨 보고, 결과와 건당 비용을 나란히 적어 보는 게 회사 발표 숫자보다 정확해요.

② 지표 8개 모두 올라 Opus 5.5 바로 아래
③ 작업당 비용은 Sonnet 5보다 최대 30% 적게
④ 길게 판단할 일은 회사도 Opus 5.5 권장

윗급 모델 이야기는 Opus 5.5 출시 글에 있어요.
