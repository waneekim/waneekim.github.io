클로드 오토 모드 기본 적용, 매번 안 묻는 AI는 괜찮을까

클로드 오토 모드 — 매번 안 묻는 AI, 괜찮을까? (캐릭터는 AI 이미지 생성)

심부름을 잘하는 로봇이 있다고 해 볼게요. 그런데 이 로봇은 서랍 하나 열 때도, 종이 한 장 버릴 때도 “해도 돼요?” 하고 물어요. 처음엔 꼼꼼히 보다가, 스무 번쯤 넘어가면 우리는 보지도 않고 “응, 다 돼”라고 하게 되죠.

앤트로픽이 10월 22일, 클로드가 일할 때마다 묻던 허락을 자동 검사가 먼저 살펴보는 오토 모드(Auto mode)를 다음 주부터 대부분의 클로드 앱에서 기본으로 켠다고 알렸어요. 대상은 프로·맥스·팀 요금제에서 새로 여는 대화예요.

4컷 만화 — 매번 허락을 묻던 AI 일꾼 옆에, 위험한 일만 막아 주는 자동 검사(안전요원)가 생겼어요 (장면 그림 AI 이미지 생성, 말풍선 글자 직접 넣음)

1. 오토 모드가 뭐예요?

궁금이오토 모드면 AI가 전부 알아서 한다는 거예요? 조금 무서운데요.
AI 로봇전부는 아니에요. 제 옆에 안전요원이 한 명 붙는다고 생각하면 돼요. 제가 뭘 하려고 할 때마다 안전요원이 먼저 보고, 괜찮으면 통과, 위험하면 멈춤!

지금까지 클로드는 파일을 고치거나 명령을 실행하기 전에 사람에게 허락을 물었어요. 오토 모드에서는 그 질문을 자동 검사가 먼저 받아요.

이런 일이면오토 모드는
평범하고 안전한 일묻지 않고 바로 해요
위험해 보이는 일막고, 더 안전한 다른 길을 찾아요
다른 길도 막히면그때 사람에게 직접 물어요

앤트로픽은 클로드 코드(개발자용 클로드)를 설명하면서, 자동 검사가 특히 되돌리기 어려운 일, 크게 망가뜨리는 일, 내 작업 공간 밖으로 향하는 일을 막는 데 맞춰져 있다고 밝혔어요. 지난 글에서 다룬 클로드 듀엣도 같은 자동 검사가 행동을 승인한다고 소개했으니, 함께 보면 흐름이 잡혀요.

2. 왜 이제 안 묻게 바꿨어요?

궁금이그래도 사람이 직접 보는 게 더 안전하지 않아요?
AI 로봇저도 그럴 줄 알았는데요, 숫자를 보면 조금 달라요.

앤트로픽이 클로드 코드 사용자를 살펴보니, 사람들은 허락 요청 100번 중 97번을 그냥 허락했어요. 하루에 수십 번, 많으면 수백 번 물으니 읽지 않고 누르는 습관이 생긴 거예요. 4컷 만화 2번 칸 그대로죠.

그래서 실험을 했어요. 돈을 받고 참여한 테스터 1,053명이 코딩 일을 하는 중간에, 허락 요청 하나를 누가 봐도 위험한 명령으로 몰래 바꿔 넣었어요. 실제로 실행되지는 않게 만든 시험이에요.

위험한 명령을 끼워 넣은 실험 — 사람은 13.6%, 오토 모드는 89%를 막았어요 (앤트로픽 클로드 코드 실험 숫자로 직접 제작)

사람은 오래 일할수록 더 놓쳤어요. 앞서 허락을 50번 넘게 누른 뒤에는 위험한 명령을 약 5%만 막았어요. 자동 검사는 일이 길어져도 막는 비율이 그대로였다고 해요.

💡 한 줄로사람이 대충 누르는 허락보다, 지치지 않는 자동 검사가 위험한 일을 더 많이 걸렀다는 게 앤트로픽의 설명이에요.

3. 언제부터, 누구에게 켜져요?

누가언제
클로드 코드 (프로·맥스·팀)8월 14일부터 이미 기본
대부분의 클로드 앱 (프로·맥스·팀)10월 22일 공지 기준 다음 주부터, 새 대화에 기본
기업용 요금제관리자에게 이메일로 먼저 알린 뒤

앤트로픽은 ‘대부분의 클로드 앱’이 정확히 어느 앱인지는 공지에 적지 않았어요. 다음 주부터 클로드가 전보다 덜 묻는다면, 오토 모드가 켜진 거예요.

4. 그럼 완전히 안전해요?

궁금이그럼 이제 아무것도 안 봐도 돼요?
AI 로봇아니요! 안전요원도 가끔 놓쳐요. 그래서 중요한 일은 꼭 같이 봐 주세요.
⚠️ 알아 둘 점① 위 숫자는 모두 클로드 코드에서 잰 거예요. 앤트로픽도 공지에 '아래 숫자는 클로드 코드 기준'이라고 적었어요. 일반 클로드 앱에서 같은 결과가 나온다는 뜻은 아니에요.
② 실험은 앤트로픽이 직접 하거나 다른 회사에 맡겨서 했고, 숫자도 앤트로픽이 발표했어요.
③ 앤트로픽 스스로 자동 검사가 위험을 없애 주지는 못한다며, 실제 서비스 서버를 크게 바꾸는 일은 사람이 직접 확인하라고 권했어요.

5. 나는 뭘 하면 돼요?

  1. 돈·계정·중요한 파일이 걸린 일은 결과를 다시 보기결제, 메일 보내기, 파일 지우기처럼 되돌리기 어려운 일은 끝난 뒤 꼭 확인해요.
  2. 클로드가 멈추고 물으면 그때는 꼼꼼히 읽기이제 묻는 횟수가 줄어드니, 물어볼 때는 정말 중요한 순간일 가능성이 커요.
  3. 매번 묻는 방식이 편하면 바꾸기AI타임스 보도에 따르면 직접 승인하는 방식으로 바꿀 수 있어요. 클로드 코드는 Shift+Tab 키나 데스크톱 앱의 모드 메뉴에서 바꿔요(앤트로픽 공식 글).
💡 우리도 써 봤어요이 블로그도 글 작업에 클로드 코드 오토 모드를 써요. 바깥에 글을 올리는 일은 "진행해" 한마디로는 통과하지 못했고, 올릴 문장을 사람이 직접 확인한 뒤에야 넘어갔어요. 귀찮아도, 이런 순간에 멈춰 주는 게 안전요원의 몫이에요.
✅ 한눈에 정리· 오토 모드는 클로드가 묻던 허락을 자동 검사가 먼저 보는 방식이에요
· 클로드 코드에서 사람은 위험한 명령의 13.6%, 자동 검사는 89%를 막았어요
· 다음 주부터 프로·맥스·팀 요금제의 대부분 클로드 앱 새 대화에 기본으로 켜져요
· 숫자는 클로드 코드 기준이고, 중요한 일은 여전히 사람이 확인해야 해요

오늘의 큰 흐름: AI가 ‘묻고 기다리는 도우미’에서 ‘맡기면 혼자 오래 일하는 일꾼’으로 바뀌는 중이고, 그만큼 무엇을 막을지가 중요해졌어요.
