오픈AI 모델 구글 클라우드 입점, 기업 고객에게 달라지는 것

오픈AI 모델이 구글 클라우드로 — 기업은 쓰던 약정으로 결제 (캐릭터는 AI 이미지 생성)

동네에서 이름난 빵집이 오랫동안 한 백화점에만 매장을 내다가, 올해 들어 다른 백화점에도 하나씩 들어간다고 해 볼게요. 손님은 늘 가던 백화점에서, 이미 사 둔 그 백화점 상품권으로 같은 빵을 살 수 있게 돼요. 회사가 AI 모델을 고를 때도 비슷해요. 이미 쓰는 클라우드 안에서, 미리 약속해 둔 사용 금액으로 살 수 있느냐가 도입 속도를 크게 좌우해요.

오픈AI가 10월 21일(미국 현지) 구글 클라우드와 손잡고, 최신 모델을 구글 클라우드의 ‘모델 가든(Model Garden)’에 넣는다고 발표했어요. 마이크로소프트 애저와 아마존 AWS에 이어, 흔히 3대 클라우드로 불리는 세 곳 모두에 오픈AI 최신 모델이 들어가는 셈이에요. 다만 구글 쪽은 아직 일부 기업 고객만 쓰는 비공개 프리뷰예요.

빵 바구니를 들고 여러 가게 앞에 선 로봇 — 한 회사의 모델이 여러 클라우드에 들어가는 모습을 빗댄 그림 (AI 이미지 생성)

1. 무슨 일: 모델 가든에 오픈AI

오픈AI는 공식 블로그 글 ‘OpenAI models are coming to Google Cloud’에서 최신 모델과 코딩 에이전트 코덱스(Codex)의 작업 흐름을 구글 클라우드 모델 가든에 넣는다고 밝혔어요. 모델 가든은 구글 클라우드에서 여러 회사의 AI 모델을 골라 쓰는 곳이에요. 구글은 자사·외부·오픈 모델을 합쳐 200개가 넘는다고 적었어요. 두 회사 발표에서 확인한 내용을 표로 옮겼어요.

항목확인한 내용
발표10월 21일(미국 현지), 오픈AI·구글 클라우드 블로그 같은 날
들어가는 모델GPT-6 Astra, GPT-6.1 Sol, GPT-6 Luna(구글 발표)
지금 상태일부 기업 고객 대상 비공개 프리뷰
정식 출시‘앞으로 몇 주 안’ 계획, 날짜는 없음
결제구글 클라우드 마켓플레이스, 기존 약정에서 차감
곧 들어갈 곳구글 안티그래비티(코딩 도구), 제미나이 에이전트
마이크로소프트‘여전히 오픈AI의 주력 클라우드 파트너’(오픈AI)

구글은 같은 날 자기 블로그에서, 앞서가는 비공개 모델 세 가지를 모두 제공하는 대형 클라우드는 이제 구글뿐이라고 주장했어요. 모델 가든에는 이미 제미나이와 앤트로픽 클로드가 있었어요(아르스 테크니카). 제미나이 에이전트는 구글이 10월 8일 발표한 업무용 에이전트예요. 권한과 감사 기록 이야기는 10월 9일 글에 정리해 뒀어요.

2. 들어가는 모델 셋은 어떻게 다른가

구글이 밝힌 모델은 가장 센 GPT-6 Astra, 그보다 싼 GPT-6.1 Sol, 가볍고 빠른 GPT-6 Luna예요. 구글의 설명과 오픈AI API 표준 요금을 나란히 놓으면 이래요.

모델구글 설명
GPT-6 Astra코딩·컴퓨터 사용·전문 업무·과학 연구처럼 어려운 일
GPT-6.1 Sol아스트라에 가까운 지능을 더 낮은 비용으로
GPT-6 Luna많은 양의 일상 업무를 빠르고 싸게
모델오픈AI API 요금(100만 토큰당 입력 · 출력)
GPT-6 Astra10달러 · 50달러
GPT-6.1 Sol2달러 · 10달러
GPT-6 Luna0.10달러 · 0.50달러

요금은 오픈AI API 요금표(10월 22일 조회, 표준·짧은 문맥 기준)예요. 구글 클라우드에서 얼마에 파는지는 두 회사 모두 밝히지 않았어요. 구글은 계약을 따로 맺거나 구조를 바꾸지 않고도 성능·지연·비용에 맞춰 모델을 바꿔 쓸 수 있다고 설명했어요.

정원에서 화분을 돌보는 로봇 정원사 — 여러 회사 모델이 모인 모델 가든에 오픈AI 모델이 새로 들어가는 것을 빗댄 그림 (AI 이미지 생성)

세 모델은 9월에 차례로 나왔어요. 출시일과 코딩 평가에서 어떻게 달랐는지는 10월 21일 글에 정리해 뒀어요.

3. 기업이 얻는 것: 청구서와 약정

구글 클라우드 고객은 오픈AI 모델을 구글 클라우드 마켓플레이스에서 사고, 미리 약속해 둔 구글 클라우드 사용 금액(약정)에서 차감할 수 있어요. 구글 설명으로는 사용 요금이 구글 클라우드 청구서 한 장에 함께 나오고, 여러 모델 회사에 걸쳐 쓰는 할인 약정(Flexible Savings Plans)에도 잡혀요. 오픈AI와 따로 계약하지 않아도 된다는 뜻이에요.

보안·관리 조건은 구글이 이렇게 밝혔어요.

항목구글 설명
데이터입력·문맥·결과는 고객이 정한 범위 안에 두고, 기반 모델 학습에 쓰지 않음
실행 장소구글 클라우드 전용 인프라, 격리된 게이트웨이를 거침
관리인증된 신원, VPC 서비스 제어, 통합 감사 기록
아직 ‘곧’데이터 무보존(ZDR) 선택지, 기밀 컴퓨팅(Confidential Compute)

개발자 쪽 변화도 있어요. 구글은 프리뷰 고객이 API로 모델을 쓰고, 코덱스 CLI와 데스크톱 앱이 구글 쪽에서 추론을 돌리도록 연결할 수 있다고 적었어요. 구글 발표에는 문서 관리 회사 박스(Box)의 AI 제품 부사장 말도 실렸어요. 구글 클라우드의 보안·규정 준수 기능과 함께 오픈AI 모델을 고객에게 줄 수 있게 된다는 내용이에요.

💡 핵심오픈AI는 규제가 까다로운 업종일수록 민감한 데이터에 누가 접근하는지 통제해야 한다고 적었어요. 그런 회사에는 ‘어느 모델이 좋은가’만큼 ‘이미 승인받은 클라우드 안에서 살 수 있는가’가 중요해요.

4. 애저·AWS를 거쳐 구글까지

오픈AI 최신 모델이 마이크로소프트 밖 클라우드로 나간 건 올해 4월 두 회사가 계약을 고친 뒤부터예요. 오픈AI 발표로는 4월 27일 개정 계약에서 마이크로소프트는 주력 클라우드 파트너로 남고, 오픈AI 제품은 원칙적으로 애저에 먼저 나와요. 그러면서 오픈AI는 모든 제품을 어느 클라우드의 고객에게나 팔 수 있게 됐어요.

4월 마이크로소프트 계약 개정부터 10월 구글 클라우드까지 — 오픈AI 모델이 클라우드로 퍼진 순서 (직접 제작)

바로 다음 날인 4월 28일, 아마존 베드록(Amazon Bedrock)에 GPT-5.5와 코덱스, 관리형 에이전트가 제한 프리뷰로 들어갔어요. 6월 1일에는 AWS 정식 출시로 바뀌었어요. 6월 10일에는 오라클 클라우드가 뒤를 이었고, 8월 7일부터는 미국에서 오라클 마켓플레이스로 살 수 있게 됐어요.

마이크로소프트는 2019년 10억 달러를 투자하며 오픈AI의 독점 클라우드 제공자가 됐어요(오픈AI 2019년 발표). 지금은 독점이 아니지만, 오픈AI는 이번 구글 발표 끝에도 ‘마이크로소프트는 여전히 주력 클라우드 파트너’라고 한 줄 적었어요. 경쟁사도 같은 길에 있어요. 앤트로픽도 최신 모델 클로드 오퍼스 5.5를 자기 플랫폼과 AWS, 구글 클라우드, 마이크로소프트 파운드리에서 함께 팔고 있어요. 모델 회사는 고객이 있는 클라우드로 들어가고, 클라우드는 고를 수 있는 모델을 늘리는 흐름이에요.

5. 발표만으로 알 수 없는 것

이번 소식은 두 회사의 발표가 중심이라, 실제로 써 본 독립 평가는 아직 없어요. 지금은 일부 기업 고객만 쓰는 비공개 프리뷰이고, 정식 출시는 ‘몇 주 안’이라고만 했어요. 구글 클라우드에서의 요금과 쓸 수 있는 지역(리전)도 발표에 없어요. 한국 기업이 언제 쓸 수 있는지는 구글 클라우드 쪽에 따로 확인해야 해요.

보안 약속 가운데 일부도 아직 ‘곧’이에요. 데이터를 아예 남기지 않는 선택지(ZDR)와 기밀 컴퓨팅은 준비 중이라고 구글이 적었어요. 안티그래비티에 어떤 오픈AI 모델이 들어갈지도 구글이 밝히지 않았다고 아르스 테크니카는 짚었어요.

이 매체의 부제는 모델 이름을 ‘GPT 6.1 Astra’로 적었지만, 구글 발표의 이름은 GPT-6 Astra라 이 글은 구글 표기를 따랐어요.

‘3대 클라우드 모두’라는 말도 나눠 봐야 해요. 애저와 AWS는 정식 제공이지만, 구글은 아직 프리뷰예요.

⚠️ 주의같은 이름의 모델이라도 오픈AI에서 직접 쓸 때와 구글 클라우드에서 쓸 때 요금·기능·데이터 처리 조건이 같은지는 아직 공개되지 않았어요. 도입 전에는 계약서와 문서를 직접 확인하세요.
✅ 한눈에 정리① 오픈AI 모델이 구글 클라우드 모델 가든에 들어가요
② Astra·Sol·Luna, 지금은 비공개 프리뷰예요
③ 기존 구글 클라우드 약정으로 결제할 수 있어요
④ 애저·AWS에 이어 구글까지 왔어요(구글은 프리뷰)
⑤ 요금·지역·정식 출시일은 아직 공개되지 않았어요

오늘의 큰 흐름: 모델이 클라우드를 가리지 않아요. 오픈AI 모델이 구글 클라우드로 들어가면서, 고객은 쓰던 클라우드에서 모델을 고르게 됐어요.

자주 묻는 질문

Q. 지금 구글 클라우드에서 바로 쓸 수 있나요?

아직은 구글이 고른 일부 기업 고객만 비공개 프리뷰로 써요. 구글 클라우드의 관심 신청 양식으로 요청할 수 있고, 정식 출시는 몇 주 안으로 계획돼 있어요.

Q. 구글 클라우드에서 쓰면 요금은 오픈AI API와 같나요?

공개되지 않았어요. 오픈AI API 표준 요금은 100만 토큰당 GPT-6 Astra 입력 10달러·출력 50달러, GPT-6.1 Sol 2달러·10달러, GPT-6 Luna 0.10달러·0.50달러예요(10월 22일 조회).

Q. 마이크로소프트와 오픈AI 관계가 끝난 건가요?

아니에요. 오픈AI는 이번 발표에도 마이크로소프트가 주력 클라우드 파트너라고 적었어요. 4월 개정 계약으로 오픈AI 제품은 원칙적으로 애저에 먼저 나오고, 마이크로소프트는 2032년까지 오픈AI 기술 사용권을 갖되 독점은 아니게 됐어요.

Q. AWS에서는 언제부터 오픈AI 모델을 쓸 수 있었나요?

4월 28일 아마존 베드록 제한 프리뷰로 시작해 6월 1일 정식 출시됐어요. 오픈AI는 상용 지역과 미국 정부용 GovCloud 지역에서 쓸 수 있다고 밝혔어요.
