할머니가 쓰던 두꺼운 가죽 장부를 태블릿 가계부로 옮긴다고 해 볼게요. 옛 글씨를 읽을 줄 알아야 하고, 옮긴 뒤에도 숫자가 끝자리까지 같아야 해요. COBOL·포트란처럼 오래된 프로그래밍 언어로 짠 은행·공공 시스템을 고치거나 새 언어로 옮기는 일이 이와 비슷해요.

OpenAI가 10월 19일 이런 옛 언어 코딩 실력을 재는 평가 두 가지와 자기 모델 점수를 공개했어요. 새 모델 출시는 아니에요. 일부 기사는 ‘옛 언어용 코딩 모델 GPT-6 Astra 출시’로 전했지만, 아스트라는 9월 3일에 나온 OpenAI 최상위 모델이에요. 아스트라가 처음 나왔을 때 이야기는 9월 7일 글에 있어요.

1. 무슨 일: 새 모델이 아닌 평가 발표

OpenAI는 10월 19일 연구 글 ‘학습 자료가 적은 프로그래밍 언어에서의 코딩 발전’을 올렸어요. 글에 나온 내용을 표로 옮겼어요.

항목확인한 내용
날짜·형식10월 19일(미국) OpenAI 연구 글
새 평가MultiLangBench(SQLite 만들기, 20개 언어), COBOL 이전 평가
나온 모델GPT-6 Astra(9월 3일), GPT-6.1 Sol(9월 29일), GPT-6 Luna(9월 22일)
비교 기준직전 세대 GPT-5.6 Sol
함께 공개MultiLangBench 시험 세트·언어별 결과(GitHub, Apache 2.0)
써 보는 곳OpenAI API — 우리 팀 언어로 시험해 보라고 안내

옛 언어를 고른 까닭으로 OpenAI는 IBM 자료를 들어, COBOL이 온라인 뱅킹 시스템의 40% 이상, 대면 카드 결제의 80%, ATM 거래의 95%를 떠받친다고 적었어요. 포트란은 날씨 예보와 원자로 안전 분석에 쓰인다고 했어요. 이런 언어는 파이썬·자바스크립트보다 배울 코드와 문서가 적어서, 코딩 모델이 약하다는 고객 의견이 많았다고 해요.

2. 평가 ①: SQLite 만들기

MultiLangBench는 SQLite와 똑같이 움직이는 데이터베이스 엔진을 정해진 언어로 처음부터 만들게 하는 시험이에요. 만든 프로그램에 처음 데이터베이스 파일과 SQL 문을 넣으면 바뀐 파일이 나오고, 그 파일을 진짜 SQLite 3.40.1로 확인해 맞으면 통과예요.

GitHub 설명서를 보면 시험 문제는 SQLite 자체 시험 5만 1,000개 가운데 이 방식으로 바꿀 수 있었던 2만 4,000개에서 나왔어요. 기본 채점은 그중 272개만 써요. 시험 중에는 인터넷을 막고, 환경에서 SQLite 흔적을 지워야 해요. 정해진 언어가 아닌 언어로 짜면 0점이에요.

최고 추론 설정에서 아스트라와 GPT-5.6 Sol의 통과율을 언어별로 놓으면 이래요.

언어GPT-5.6 Sol → GPT-6 Astra
COBOL10.9% → 72.1%
포트란21.4% → 83.5%
OCaml25.6% → 85.8%
비주얼 베이식27.5% → 89.4%
20개 언어 평균26.8% → 87.4%

아스트라는 20개 언어 중 19개에서 83%를 넘었고, 가장 어려운 언어는 여전히 COBOL(72%)이었어요. 싼 모델 GPT-6 Luna는 평균 40.3%로, GPT-5.6 Sol보다 높으면서 샘플 하나당 예상 비용은 0.77달러로 78% 낮았다고 OpenAI는 적었어요.

추론 설정(reasoning effort)은 답하기 전에 모델이 얼마나 오래 생각할지 정하는 값이에요. 높일수록 점수가 오르지만 토큰과 비용도 늘어요.

3. 평가 ②: COBOL 다른 언어로 옮기기

두 번째 평가는 COBOL 프로그램을 C++·자바·코틀린·파이썬·러스트로 옮기면서 하는 일을 그대로 지키는지 봐요. 숨겨 둔 시험에서 출력이 바이트 하나까지 같아야 하고, 시험을 모두 통과해야만 성공으로 쳐요.

OpenAI가 든 예가 반올림이에요. COBOL의 고정소수점 계산은 따로 반올림하라고 하지 않으면 넘치는 소수 자리를 버려요. 새 코드가 이걸 반올림으로 바꾸면 오류 없이 돌아가도 금액 결과가 달라져요.

옛 블록 더미와 새 블록 더미가 똑같은지 돋보기로 맞춰 보는 로봇 — 옮긴 프로그램이 옛 결과를 그대로 내는지 보는 COBOL 이전 평가를 빗댄 그림 (AI 이미지 생성)

이 평가에서는 아스트라가 아니라 GPT-6.1 Sol이 주인공이었어요. 낮은 추론 설정에서 86.6%로, 같은 설정의 GPT-5.6 Sol(5.4%)보다 크게 높았고 API 비용은 61% 수준이었어요. 설정을 올리면 97.9%까지 나와, OpenAI는 이 시험이 거의 꽉 찼다고 적었어요.

같은 글의 그래프를 보면 아스트라는 96.8%, 9월에 나온 GPT-6 Sol은 최고 설정에서 95.8%였어요.

4. 아스트라와 솔, 점수와 비용 차이

두 시험 모두 GPT-6.1 Sol이 아스트라와 거의 같은 점수를 훨씬 싸게 냈어요. OpenAI 글 본문에는 없고, 페이지에 실린 그래프 값을 옮겨 정리한 거예요.

OpenAI 옛 언어 코딩 평가 두 가지의 모델별 점수와 비용 — SQLite 만들기와 COBOL 옮기기 (직접 제작)

SQLite 만들기에서 6.1 Sol 최고 설정은 87.0%로 아스트라(87.4%)와 0.4%포인트 차이였고, 샘플당 예상 비용은 7.53달러 대 32.18달러로 4분의 1 안팎이었어요. COBOL 옮기기에서도 6.1 Sol은 97.9%를 0.70달러에, 아스트라는 96.8%를 3.26달러에 냈어요.

최고 설정의 아스트라는 COBOL로 SQLite를 만드는 샘플 하나에 54.72달러가 들었어요. 점수를 끝까지 끌어올리면 비용이 크게 뛴다는 뜻이에요.

10월 21일 OpenAI API 요금표(100만 토큰당 입력·출력)도 함께 보면 이래요.

모델입력 · 출력
GPT-6 Astra10달러 · 50달러
GPT-6.1 Sol2달러 · 10달러
GPT-6 Sol2달러 · 10달러
GPT-6 Luna0.10달러 · 0.50달러
GPT-5.6 Sol (이전)4달러 · 20달러

토큰 단가는 아스트라가 6.1 Sol의 5배예요. 실제 비용 차이가 그보다 작은 건 모델마다 같은 일에 쓰는 토큰 수가 달라서예요. 6.1 Sol의 값과 성능은 10월 1일 글에 정리해 뒀어요.

5. 검증과 한계: 회사가 만든 시험

두 시험 모두 OpenAI가 만들고 OpenAI가 잰 점수예요. 10월 21일까지 다른 기관이 같은 시험으로 잰 결과는 찾지 못했어요. MultiLangBench는 문제와 채점 방법이 공개돼 누구나 다시 재 볼 수 있어요. 반면 COBOL 이전 평가는 숨긴 시험을 쓰고, 문제를 공개한다는 안내가 없어요.

시험 범위도 봐야 해요. SQLite는 설명서가 잘 갖춰진 프로그램이고, 실제 회사 시스템은 문서가 빠져 있거나 업무 규칙이 코드에만 남은 경우가 많아요. OpenAI도 실제 운영 소프트웨어에 쓰려면 전문가 검토와 그 시스템의 업무 규칙·의존성에 맞춘 시험이 여전히 필요하다고 적었어요.

‘5.4%에서 86.6%’는 가장 낮은 설정끼리 비교한 숫자예요. 같은 그래프에서 GPT-5.6 Sol도 최고 설정에서는 65.2%였어요.

보도도 엇갈려요. Thurrott는 ‘새 코딩 모델 출시’로 쓰고 COBOL 이전 결과를 아스트라 몫(86.8%)으로 적었어요. The Decoder는 비교 기준을 같은 그래프의 GPT-5.6 Terra(37.9%)로 잡았어요. 이 글은 10월 21일 OpenAI 원문 기준이에요.

💡 핵심회사가 만든 시험의 점수예요. 우리 코드로 재 보기 전까지는 ‘옛 언어 작업이 해 볼 만해졌다’는 신호로만 보세요.

6. 써 보기 전에 볼 것

옛 시스템에 AI를 붙여 보려면 정답지부터 만드는 게 순서예요. 볼 곳은 네 가지예요.
① 우리 언어 점수 — MultiLangBench 언어별 결과에서 우리 팀 언어부터 보세요
② 싼 설정부터 — 6.1 Sol 낮은 설정으로 작은 프로그램 하나를 옮겨 보고, 모자랄 때 설정과 모델을 올리세요
③ 정답지 — 옛 시스템의 실제 출력을 모아 바이트 단위로 비교하는 시험을 먼저 만드세요
④ 사람 검토 — 반올림·빈 레코드 처리 같은 업무 규칙은 담당자가 확인하세요

정답지 없이 옮긴 코드는 돌아가도 맞는지 알 수 없어요. OpenAI 평가도 같은 방식으로 채점했어요.

⚠️ 주의금융·공공 시스템 코드는 회사 자산이에요. 외부 AI API에 넣기 전에 회사 보안 규정과 계약부터 확인하세요.

회사 정보를 AI에 넣을 때 지킬 점은 9월 7일 글에 정리해 뒀어요.

오늘의 큰 흐름: OpenAI가 채팅 밖으로 영역을 넓히고 있어요. 옛 코드 현대화처럼 기업이 오래 미뤄 온 일을 겨누는데, 남은 질문은 회사 밖 시험에서도 같은 점수가 나오느냐예요.

자주 묻는 질문

Q. GPT-6 아스트라는 이번에 새로 나온 모델인가요?

아니요. 9월 3일 공개된 OpenAI 최상위 모델이에요. 10월 19일 글은 이미 나온 모델들의 옛 언어 실력을 새 평가로 잰 결과예요.

Q. COBOL 코드를 AI가 알아서 다 옮겨 주나요?

OpenAI 시험에서는 97.9%까지 나왔지만 회사가 만든 시험이에요. OpenAI도 실제 운영 코드에는 전문가 검토와 업무 규칙에 맞춘 시험이 필요하다고 적었어요.

Q. 아스트라와 6.1 Sol 중 무엇을 쓰면 되나요?

이 두 시험에서는 6.1 Sol이 아스트라와 비슷한 점수를 4분의 1 안팎의 비용에 냈어요. 우리 코드 몇 개로 둘 다 재 보고 고르는 게 안전해요.

Q. 한국 금융권 시스템에도 통할까요?

한국 시스템을 따로 잰 자료는 찾지 못했어요. 회사마다 업무 규칙과 시스템 환경이 달라서, 작은 프로그램으로 직접 시험해 보는 게 먼저예요.
