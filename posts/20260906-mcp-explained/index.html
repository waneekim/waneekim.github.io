MCP 뜻, AI에게 손발을 달아 주는 표준과 MCP 서버 정리

MCP 뜻과 MCP 서버 — AI에게 손발을 달아 주는 표준 (캐릭터는 GPT 이미지 생성)

AI 관련 글을 읽다 보면 MCP라는 세 글자가 자꾸 나와요. “MCP 서버를 연결하세요”라는 문장에서 이런 생각이 들죠. “그래서 MCP가 뭔데?” 개발자 용어 같아서 넘기기 쉽지만, 개념은 놀랄 만큼 단순해요.

충전 케이블을 떠올려 보세요. 기기마다 단자 모양이 다르면 케이블을 따로 챙겨야 하지만, USB-C처럼 단자를 하나로 맞추면 케이블 하나로 여러 기기를 꽂을 수 있어요. MCP는 AI와 도구 사이의 단자를 하나로 맞춘 약속이에요. MCP 공식 문서도 MCP를 ‘AI 앱을 위한 USB-C 포트’라고 소개해요.
MCP(Model Context Protocol)는 AI 앱이 바깥의 도구·데이터에 연결되는 방법을 하나로 정한 공개 표준이에요.

케이블 하나로 메일·일정·문서를 잇는 장면 — MCP를 USB-C에 빗댄 그림 (GPT 이미지 생성)

② 호스트·서버 구조와 용어 6개

1. 뜻: AI와 도구 사이의 공용 규격

MCP는 AI가 내 메일·파일·업무 도구를 직접 다루게 해 주는 연결 규격이에요. 이름을 풀면 Model Context Protocol, 우리말로 ‘모델 컨텍스트 프로토콜’이에요. AI 모델에 필요한 맥락(context)과 도구를 건네는 규약(protocol)이라는 뜻이에요.

원래 AI 챗봇은 지식은 많은데 손발이 없는 존재였어요. 메일을 읽어 달라고 해도 내 메일함에 들어갈 수 없고, 파일을 정리해 달라고 해도 내 폴더를 열 수 없었어요.

클로드를 만든 앤트로픽(Anthropic)이 2024년 11월 25일 오픈소스로 공개했어요.

2. 왜 나왔나: 어댑터 지옥 문제

MCP 전에는 AI 서비스와 도구를 잇는 연동을 하나하나 따로 만들어야 했어요. AI 서비스가 3개, 연결할 도구가 5개면 3×5 = 15개 연동을 전부 따로 개발하는 식이에요. 해외여행 갈 때 나라마다 다른 콘센트 어댑터를 챙기는 상황과 같아요.

앤트로픽 발표문도 ‘새 데이터 소스마다 따로 구현해야 해서, 연결된 시스템을 넓히기 어렵다’는 문제를 짚었어요.

MCP 이전과 이후 — AI 앱 3개와 도구 5개를 잇는 연결 수 비교 (직접 제작)

MCP는 이걸 규격 하나로 정리했어요. 도구 쪽은 MCP 서버를 한 번만 만들고, AI 앱 쪽은 MCP를 한 번만 지원하면 돼요. 그러면 15개가 3 + 5 = 8개로 줄어요.

💡 핵심새 도구가 나와도 MCP 서버 하나만 더하면, MCP를 지원하는 AI 앱 어디서나 쓸 수 있어요.

3. 구조: 호스트와 서버 두 쪽

구조는 두 쪽만 기억하면 돼요. AI가 들어 있는 앱(호스트)과 도구를 내주는 쪽(서버)이에요. MCP 호스트는 클로드 데스크톱, 클로드 코드 같은 AI 앱이에요. MCP 서버는 Gmail 서버, 노션 서버, 회사 DB 서버처럼 도구마다 하나씩 있어요.

호스트가 서버에 꽂히면, AI는 그 서버가 내주는 기능을 자기 손발처럼 쓸 수 있어요. 공식 문서를 읽다 보면 나오는 용어 여섯 개를 표로 정리했어요.

용어뜻
호스트 (host)AI가 들어 있는 앱 — 클로드 데스크톱, 클로드 코드
클라이언트 (client)호스트 안에서 서버 하나와의 연결을 맡는 부품
서버 (server)도구·데이터를 내주는 프로그램 — Gmail, 노션
도구 (tools)AI가 실행하는 기능 — 메일 검색, DB 조회
리소스 (resources)AI가 읽는 자료 — 파일 내용, DB 기록
프롬프트 (prompts)미리 만들어 둔 요청 틀

클라이언트는 호스트가 서버마다 하나씩 만드는 연결 담당이라, 쓰는 사람이 따로 챙길 일은 없어요. 호스트는 AI 앱, 서버는 도구 쪽이라는 것만 기억하면 충분해요.

4. 연결하면 실제로 달라지는 것

MCP 서버를 연결해 두면, 내 메일·문서·일정을 다루는 일을 AI에게 말로 시킬 수 있어요. 저는 클로드에 Gmail·노션·구글 캘린더를 커넥터로 연결해 두고 써요. 클로드에서는 claude.ai에 추가한 MCP 서버를 커넥터(connector)라고 불러요.

연결해 두면 이런 요청이 실제로 돼요. 먼저 Gmail을 연결했다면 이렇게요.

📋 그대로 복사해 쓰세요

지난주 온 세금계산서 메일 찾아서 요약해줘

노션을 연결했다면 이렇게요.

이 회의록을 노션 페이지로 정리해줘

구글 캘린더를 연결했다면 이렇게요.

다음 주 일정 보고 비는 시간에 미팅 잡아줘

연결된 MCP 서버는 직접 확인할 수 있어요.

  1. 클로드 웹이나 데스크톱에서 Customize > Connectors 메뉴를 여세요(영어 화면 기준).→ 연결할 수 있는 커넥터를 둘러보고 추가할 수 있어요.
  2. 클로드 코드를 쓴다면 터미널에 아래 한 줄을 입력하세요.
claude mcp list

→ 연결된 MCP 서버가 한 줄씩 떠요. 이 머신(클로드 코드 2.1.268)에서는 claude.ai Gmail, claude.ai Notion, claude.ai Google Calendar가 Connected로 보여요.
→ 이름 앞의 claude.ai는 claude.ai에서 연결한 커넥터를 클로드 코드가 그대로 가져왔다는 표시예요.

5. 한 회사의 기능이 아닌 이유

MCP는 앤트로픽이 만들었지만, 지금은 여러 회사가 함께 쓰는 공개 표준이에요. 그래서 도구를 만드는 회사들이 ‘우리 서비스 MCP 서버’를 내놓고, 쓸 수 있는 도구가 계속 늘어나요.

OpenAI 개발자 문서도 MCP를 ‘AI 모델을 확장하는 업계 표준이 되어 가는 공개 프로토콜’이라고 소개해요.

2025년 12월 9일에는 앤트로픽이 MCP를 리눅스 재단(Linux Foundation) 산하의 Agentic AI Foundation에 기부했어요. 이 재단은 앤트로픽·Block·OpenAI가 함께 세웠어요. 같은 발표에 따르면 공개된 MCP 서버는 1만 개가 넘어요.

MCP를 쓰는 곳을 공식 문서와 발표문 기준으로 정리했어요.

쓰는 곳MCP를 쓰는 방식
클로드 (웹·데스크톱·코드)커넥터로 연결
챗GPT · 코덱스원격 MCP 서버 연결 (OpenAI 문서)
VS 코드 · 커서개발 도구에 MCP 서버 연결
제미나이 · 코파일럿MCP 채택 (앤트로픽 2025년 12월 발표)

6. 연결 전에 알아 둘 주의점

MCP는 AI에게 실제 권한을 주는 기술이라, 아무 서버나 연결하면 안 돼요. 연결한 서버는 내 데이터에 접근할 수 있어요. MCP 사양도 도구를 ‘임의의 코드 실행’으로 보고 조심해서 다루라고 적어 두었어요.

OpenAI와 클로드 코드 공식 문서도 믿을 수 있는 서버만 연결하라고 해요. 글 속에 숨긴 지시로 AI를 조종하는 공격(프롬프트 인젝션)이 있어서예요.

낯선 플러그를 꽂기 전에 돋보기로 살펴보는 장면 — MCP 서버도 연결 전에 확인 (GPT 이미지 생성)

민감한 데이터를 다루는 연결은 신중하게 정하고, 쓰지 않는 커넥터는 연결을 끊어 두세요.

⚠️ 주의출처를 모르는 MCP 서버는 연결하지 마세요. 도구를 만든 회사가 직접 운영하는 공식 서버부터 쓰세요.

헷갈리기 쉬운 것

MCP는 AI 이름이 아니에요 클로드나 ChatGPT 같은 AI가 아니라 AI 앱과 도구를 잇는 규격이에요. 공식 문서도 AI 앱이 모델을 어떻게 쓰는지는 MCP가 정하지 않는다고 적어요.

MCP 서버가 꼭 내 컴퓨터에서 도는 건 아니에요 같은 컴퓨터에서 도는 로컬 서버도, 서비스 회사가 인터넷에서 운영하는 원격 서버도 있어요. 제 클로드 코드 목록의 claude.ai 커넥터들은 모두 https 주소로 연결된 원격 서버예요.

MCP가 보안을 대신 지켜 주지는 않아요 MCP 사양은 사용자 동의와 통제를 원칙으로 두면서도, 프로토콜만으로는 강제할 수 없다고 밝혀요. 지키는 건 앱 설정과, 무엇을 연결할지 고르는 사람의 몫이에요.

✅ 한눈에 정리① MCP는 AI 앱과 도구를 잇는 공개 표준
② 도구는 서버를, AI 앱은 지원을 한 번만
③ 구조는 호스트(AI 앱)와 서버(도구) 두 쪽
④ 출처를 아는 공식 서버만 연결

자주 묻는 질문

Q. MCP를 쓰려면 코딩을 알아야 하나요?

아니요. 4번처럼 커넥터 메뉴에서 골라 연결하면 돼요. 서버를 새로 만드는 건 개발자의 일이에요.

Q. ChatGPT에서도 MCP를 쓸 수 있나요?

네. OpenAI 문서에 따르면 원격 MCP 서버를 ChatGPT와 Codex, API에서 쓸 수 있어요.

Q. MCP 서버는 누가 만드나요?

도구를 만든 회사가 공식 서버를 내기도 하고, 개인이 만든 서버도 있어요. 앤트로픽은 처음 공개할 때 Google Drive, Slack, GitHub 서버를 함께 내놓았어요.

Q. AI가 연결된 도구로 마음대로 일을 벌이지는 않나요?

MCP 사양은 도구를 쓰기 전에 사용자 동의를 받으라고 정해 두었고, 실제로 얼마나 묻는지는 앱 설정에 따라 달라요. 저는 클로드 코드를 자동 모드로 쓰고, 밖으로 내보내는 일은 규칙을 정해 두고 맡겨요.

다음 글에서는 클로드 코드에 MCP 서버를 직접 연결하는 방법을 다뤄요. 연결 방식 세 가지와 연결 뒤 확인하는 법까지요.
