클로드 코드에 MCP 연결하기, 세 가지 방법과 연결 확인까지

클로드 코드에 MCP 연결하기 — 세 가지 방법과 연결 확인까지 (캐릭터는 GPT 이미지 생성)

MCP가 뭔지 알고 나면 다음 질문이 생겨요. “그래서 클로드 코드에는 어디에 뭘 입력해서 연결하지?” 설정 파일과 명령어 이야기가 한꺼번에 나와서, 시작도 하기 전에 막히기 쉬워요.

MCP 연결은 멀티탭에 플러그를 꽂는 일과 비슷해요. 메일·일정·노트 같은 도구가 플러그이고, 클로드 코드가 멀티탭이에요. 꽂는 방법이 세 가지 있을 뿐이에요. 웹에서 고르는 커넥터, 명령 한 줄로 꽂는 claude mcp add, 팀이 같이 쓰는 .mcp.json 파일이에요.
처음이라면 claude.ai 커넥터 하나로 시작하면 돼요. 명령어는 몰라도 돼요.

멀티탭에 메일·일정·노트 플러그를 꽂는 장면 — MCP 서버 연결을 빗댄 그림 (GPT 이미지 생성)

준비물: claude.ai 계정으로 로그인한 클로드 코드
2026년 10월 기준 · Windows 11 · 2.1.268

1. 연결 방법 세 가지

클로드 코드에 MCP 서버를 붙이는 길은 세 가지예요. 무엇을 연결하는지와 누가 같이 쓰는지로 고르면 돼요.

클로드 코드에 MCP를 연결하는 세 가지 방법 — 커넥터, claude mcp add, .mcp.json (직접 제작)

세 방법을 언제 쓰는지 표로 정리했어요.

방법이럴 때 써요
claude.ai 커넥터목록에 있는 서비스(Gmail·캘린더 등) — 처음이라면 이것
claude mcp add목록에 없는 서버를 내 컴퓨터에 등록할 때
.mcp.json저장소에 넣어 팀원 모두 같은 서버를 쓸 때

제 연결은 대부분 첫 번째 방법이에요.

2. 커넥터로 첫 연결하기

claude.ai에서 연결한 커넥터는 같은 계정으로 로그인한 클로드 코드에 저절로 들어와요. claude.ai에 추가한 MCP 서버를 커넥터(connector)라고 불러요. 서버 주소나 설정 파일을 만질 일이 없어요.

  1. 웹이나 데스크톱 클로드에서 Customize > Connectors를 여세요(영어 화면 기준).→ 연결할 수 있는 커넥터 목록이 보여요.
  2. 연결할 서비스를 고르고, 그 서비스의 로그인(인증) 안내를 따라가세요.→ 클로드가 그 계정에 접근할 수 있게 돼요.
  3. 클로드 코드를 켜고 /mcp를 입력하세요.→ 방금 연결한 커넥터가 이름 앞에 claude.ai가 붙은 채로 보여요.

저는 Gmail·노션·구글 캘린더를 이렇게 연결해 두고 써요. 연결해 두면 터미널에서 이런 요청이 돼요.

📋 그대로 복사해 쓰세요

지난주 온 메일 찾아서 요약해줘

오늘 온 메일만 추리고 싶으면 이렇게요.

오늘 온 메일 중 중요한 것만 골라 요약해줘

커넥터 하나로 써 보고, 익숙해지면 하나씩 늘리세요.

💡 핵심첫 연결은 커넥터로 하세요. 명령어는 목록에 없는 서버가 필요할 때 배워도 늦지 않아요.

3. 연결됐는지 확인하기

연결 확인은 터미널의 claude mcp list나, 클로드 코드 안의 /mcp 하나면 돼요.

  1. 터미널에서 아래 한 줄을 입력하세요.
claude mcp list

→ 연결된 MCP 서버가 한 줄씩 상태와 함께 떠요. 이 머신(2.1.268)에서는 claude.ai Gmail, claude.ai Notion, claude.ai Google Calendar가 ✔ Connected로 보여요.
→ 클로드 코드 안에서는 /mcp를 입력하세요. 서버마다 상태가 보이고, 로그인이 필요한 원격 서버는 여기서 인증하고, 안 쓰는 서버는 지우지 않고 끌 수 있어요.

상태 표시는 세 가지예요.
✔ Connected — 연결됨, 바로 쓸 수 있어요
! Needs authentication — 로그인(인증)이 필요해요
✘ Failed to connect — 연결 실패, 주소나 실행 명령을 확인하세요

초록 불이 켜진 연결을 가리키며 확인하는 장면 — /mcp 상태 표시를 빗댄 그림 (GPT 이미지 생성)

4. 목록에 없는 서버는 명령으로

커넥터 목록에 없는 서버는 claude mcp add 명령 한 줄로 등록해요. 서버가 인터넷 주소로 제공되면(원격) 첫 줄처럼, 내 컴퓨터에서 실행하는 서버면(로컬) 둘째 줄처럼 써요.

claude mcp add -t http <name> <url>
claude mcp add <name> -- <command>

→ -t는 --transport를 줄인 옵션이에요. 적지 않으면 로컬(stdio) 서버로 등록돼요.
→ -- 뒤에 적은 것은 서버를 실행하는 명령으로 그대로 넘어가요.

<name>은 내가 붙이는 이름이고, 영문·숫자·하이픈·밑줄만 쓸 수 있어요. <url>과 <command>는 서버를 내놓은 곳이 알려 줘요. 등록한 서버를 지울 때는 claude mcp remove 뒤에 이름을 붙여요. 옵션은 버전마다 바뀔 수 있어서 claude mcp add --help가 늘 기준이에요. 이 글의 옵션은 2.1.268의 도움말과 대조했어요.

5. 범위 고르기와 .mcp.json

claude mcp add로 등록한 서버는 기본으로 지금 프로젝트에서 나만 써요. 범위(scope)를 바꾸면 쓰는 곳이 달라져요. 범위는 세 가지이고, 명령에 -s 옵션(--scope)을 붙여 골라요.

범위어디서 · 누가 써요
local (기본)지금 프로젝트에서 나만
project지금 프로젝트에서 팀 모두 — .mcp.json에 저장
user내 모든 프로젝트에서 나만

project 범위로 등록한 서버는 프로젝트 맨 위 폴더의 .mcp.json 파일에 적혀요. 이 파일을 저장소에 함께 올리면 팀원이 같은 서버 목록을 받아요. 혼자 쓰면 local, 팀이 같이 쓰면 project로 고르면 돼요.

보안 때문에, 클로드 코드는 .mcp.json에 적힌 서버를 쓰기 전에 승인을 물어요. 승인 전 서버는 claude mcp get에서 ⏸ Pending approval로 보이고 연결되지 않아요.

6. 연결 전에 지킬 것

MCP 서버는 AI에게 실제 권한을 주는 연결이라, 믿을 수 있는 서버만 연결하세요. 공식 문서는 연결하기 전에 서버를 믿을 수 있는지 확인하라고 적어요. 바깥 내용을 가져오는 서버는 글 속에 숨긴 지시로 AI를 조종하는 공격(프롬프트 인젝션)에 노출될 수 있어서예요.

수동(Manual) 모드에서는 MCP 도구를 쓰기 전에도 승인을 물어요. 무엇을 하려는지 읽고 승인하세요. 저는 클로드 코드를 자동 모드로 쓰고, 밖으로 내보내는 일은 규칙을 정해 두고 맡겨요.

쓰지 않는 서버는 /mcp에서 꺼 두세요. 클로드 도움말도 쓰지 않는 서비스는 연결을 끊어 두라고 해요.

⚠️ 주의출처를 모르는 MCP 서버는 연결하지 마세요. 저장소의 .mcp.json에 낯선 서버가 있으면 승인하기 전에 확인하세요.

막힐 때

목록에 ! Needs authentication으로 떠요
원인: 로그인(인증)이 필요한 원격 서버인데 아직 인증하지 않았어요.
해결: 클로드 코드에서 /mcp를 열고 그 서버를 골라 인증하세요.

등록한 서버가 다른 폴더에서는 안 보여요
원인: 기본 범위(local)는 등록한 프로젝트에서만 보여요.
해결: 모든 프로젝트에서 쓰려면 -s user를 붙여 다시 등록하세요.

.mcp.json의 서버가 연결되지 않아요
원인: 아직 승인하지 않았어요. 프로젝트 범위 서버는 승인 전에는 연결하지 않아요.
해결: 클로드 코드를 켜면 뜨는 승인 창에서 승인하세요. 상태는 claude mcp get 뒤에 서버 이름을 붙여 볼 수 있어요.

✅ 한눈에 정리① 처음엔 claude.ai 커넥터로 연결
② 목록에 없는 서버는 claude mcp add
③ 팀이 같이 쓰면 project 범위(.mcp.json)
④ 확인은 claude mcp list와 /mcp

자주 묻는 질문

Q. 코딩을 몰라도 연결할 수 있나요?

네. 커넥터는 웹에서 고르고 로그인하면 끝이에요. 명령어는 목록에 없는 서버를 붙일 때만 필요해요.

Q. claude.ai 커넥터를 클로드 코드에서만 끌 수 있나요?

네. 공식 문서에 따르면 설정에서 disableClaudeAiConnectors를 true로 두면 클로드 코드가 claude.ai 커넥터를 쓰지 않아요. 하나만 막으려면 deniedMcpServers에 이름을 넣어요.

Q. 서버를 많이 연결하면 대화가 무거워지나요?

공식 문서에 따르면 MCP 도구 설명은 기본으로 미뤄 두고, 실제로 쓸 때까지 도구 이름과 서버 안내만 맥락에 들어가요. 그래도 안 쓰는 서버는 /mcp에서 꺼 두는 게 좋아요.

Q. 더 이상 안 쓰는 커넥터는 어떻게 하나요?

claude.ai의 Customize > Connectors에서 연결을 끊으세요. 클로드 코드에서 잠깐만 안 쓰려면 /mcp에서 끄면 돼요.

어떤 서버부터 연결할지는 MCP 서버 추천 글에 정리했어요. 매일 쓰는 서버와 연결 전 확인할 것까지요.
