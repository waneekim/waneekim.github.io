MCP 서버 추천, 실제로 연결해 쓰는 6개와 연결 전 확인할 것

MCP 서버 추천 — 실제로 연결해 쓰는 6개 (캐릭터는 GPT 이미지 생성)

MCP가 뭔지 알고 나면 다음 질문은 하나예요. “그래서 뭘 연결하지?” 검색하면 서버 목록은 잔뜩 나오는데, 무엇부터 붙여야 하는지는 잘 알려 주지 않아요.

MCP 서버를 연결하는 일은 도우미에게 집 열쇠를 맡기는 일과 비슷해요. 누가 만든 열쇠인지 보고, 어느 방 열쇠인지 확인하고, 안 쓰는 열쇠는 돌려받아요.
MCP 서버는 많이 붙이는 것보다, 믿을 수 있는 것부터 하나씩 붙이는 게 핵심이에요.

도우미 로봇에게 메일·일정·문서 열쇠를 건네는 장면 — MCP 서버 연결을 열쇠 맡기기에 빗댄 그림 (GPT 이미지 생성)

🎯 이 글에서 얻는 것대상: MCP 뜻을 알고 연결해 보려는 분
① 연결 전에 확인할 3가지
② 실제로 연결해 쓰는 커넥터 6개와 요청 예시
③ 처음 붙일 조합과 연결·확인하는 법
준비물: 클로드 계정 · 쓰고 있는 서비스 계정
2026년 10월 기준 · 클로드 코드 2.1.268

1. 연결 전에 확인할 3가지

연결은 AI에게 그 서비스의 데이터를 읽고 바꿀 권한을 주는 일이라, 붙이기 전에 세 가지를 봐요. 클로드 도움말도 연결하면 내 계정 권한 안에서 데이터에 접근하고, 바꿀 수도 있다고 적어 두었어요.

MCP 서버 연결 전 확인할 3가지 — 공식 제공처, 요구하는 권한, 꼭 필요한지 (직접 제작)

① 공식 제공처인가 — 그 서비스를 만든 회사가 직접 운영하는 서버인지 봐요.
② 권한이 보이는가 — 읽기·쓰기·삭제 중 무엇을 달라고 하는지 연결 화면에서 확인해요.
③ 꼭 필요한가 — 쓸 일 없는 연결은 그 자체가 위험이라 붙이지 않아요.

이 세 가지는 클로드 공식 도움말의 안내와도 같아요. 믿을 수 있고 필요한 서비스만 연결하고, 연결할 때 요청하는 권한을 살피고, 안 쓰는 서비스는 연결을 끊으라고 해요.

2. 추천 6개 한눈에 보기

제가 클로드에 연결해 두고 쓰는 커넥터는 아래 여섯 개예요. 전부 원래 쓰던 서비스예요. 클로드에서는 claude.ai에 추가한 MCP 서버를 커넥터(connector)라고 불러요.

커넥터이런 일을 시켜요
Gmail (지메일)메일 찾기·요약, 메일 보내기
구글 캘린더일정 보기·만들기, 빈 시간 찾기
노션회의록 정리, 페이지 만들기, DB 조회
구글 드라이브파일 찾기, 내용 읽기
슬랙채널 요약, 메시지 검색·보내기
피그마디자인 읽기, 문서용 도식 만들기

여섯 개 모두 그 서비스를 만든 회사의 주소로 연결돼요. 제 클로드 코드 연결 목록을 보면 Gmail·캘린더·드라이브는 googleapis.com, 노션은 mcp.notion.com, 슬랙은 mcp.slack.com, 피그마는 mcp.figma.com이에요. 새 도구를 배우는 게 아니라 쓰던 도구에 손발을 다는 것에 가까워요.

3. 메일·캘린더·문서부터

처음 세 개를 고른다면 메일, 캘린더, 문서(노션이나 드라이브)예요. 매일 손이 가는 일이라 바로 차이가 나요. Gmail을 연결하면 메일함을 뒤지는 일을 말로 시킬 수 있어요. 저는 폰으로 자료를 옮길 때도 AI에게 제 메일로 보내 달라고 시켜요.

📋 그대로 복사해 쓰세요

지난주 온 세금계산서 메일 찾아서 요약해줘

구글 캘린더를 연결했다면 이렇게요.

다음 주 일정 보고 비는 시간에 30분 미팅 잡아줘

드라이브를 연결했다면 “그 보고서 어디 있더라”를 이렇게 물어요.

드라이브에서 지난달 주간 보고 파일을 찾아서 핵심만 3줄로 알려줘

노션은 회의록 정리와 페이지 만들기에 써요. 개인 위키를 노션에 두고 있다면, AI가 그 위키를 읽고 쓰게 되는 차이가 커요.

4. 팀이라면 슬랙, 도식은 피그마

팀에서 일한다면 슬랙을 더하세요. 회의 전에 채널 논의를 요약시키는 데 쓸모가 커요. 슬랙을 연결했다면 이렇게 시켜요.

이 채널 이번 주 논의를 정해진 것과 남은 질문으로 나눠서 요약해줘

피그마 커넥터는 디자인 파일을 읽고 다이어그램을 만들어 줘요. 디자이너가 아니어도 문서에 넣을 도식을 만들 때 써요.
슬랙과 피그마는 메일·캘린더·문서가 손에 익은 뒤에 붙여도 늦지 않아요.

5. 개발자라면 GitHub·파일·브라우저

코딩을 한다면 저장소·파일·브라우저를 다루는 서버가 많이 쓰여요. 이 절은 제가 직접 연결해 쓴 게 아니라 각 공식 저장소를 읽고 정리한 거예요.

GitHub MCP 서버 — GitHub가 직접 내는 서버예요. 저장소 코드 읽기, 이슈·PR 관리, 워크플로 확인을 말로 시킬 수 있어요.
Playwright MCP 서버 — 마이크로소프트가 내는 브라우저 자동화 서버예요. AI가 웹 페이지를 열고 눌러 볼 수 있어요.
Filesystem 서버 — MCP 공식 저장소에 있는 참고용 서버예요. 정해 둔 폴더의 파일을 읽고 써요.

클로드 코드 같은 코딩 에이전트에 붙이면 이슈 확인, 코드 수정, PR 만들기가 한 흐름으로 이어져요. 다만 MCP 공식 저장소는 참고용 서버가 교육용 예시이고 그대로 실제 운영에 쓰라고 만든 게 아니라고 적어 두었어요. 예전에 있던 PostgreSQL 참고 서버도 지금은 보관(archived) 목록으로 옮겨졌어요.

6. 연결하고 확인하는 법

커넥터는 클로드 설정에서 고르고, 그 서비스에 로그인해 접근을 허락하면 연결돼요.

  1. 클로드 웹이나 데스크톱에서 Customize > Connectors를 여세요(영어 화면 기준).→ 커넥터 설정 화면이 열려요.
  2. Connectors 옆의 + 버튼을 누르세요.→ 연결할 수 있는 커넥터가 분류별로 떠요.
  3. 연결할 서비스를 눌러 설명과 할 수 있는 일을 읽어 보세요.→ 1번의 ①과 ②를 여기서 확인해요.
  4. Connect를 누르고 그 서비스의 로그인 안내를 따라가세요.→ 계정 접근을 허락하면 연결이 끝나요.
  5. 클로드 코드를 쓴다면 터미널에 아래 한 줄을 입력하세요.
claude mcp list

→ 연결된 서버가 한 줄씩 떠요. 이 머신(클로드 코드 2.1.268)에서는 위 여섯 개가 모두 Connected로 보여요.
→ claude.ai 계정으로 로그인한 클로드 코드라면, claude.ai에서 연결한 커넥터가 따로 추가하지 않아도 따라와요.

처음 붙일 조합은 하는 일에 따라 고르세요.
직장인 기본 — Gmail + 캘린더 + 노션 또는 드라이브
팀 리더 — 위 조합 + 슬랙
개발자 — GitHub + 파일시스템 + 쓰는 DB의 공식 서버

한 번에 다 붙이지 말고, 하나 연결해서 일주일 써 보고 다음을 붙이세요. 연결이 늘수록 편해지지만 관리할 권한도 함께 늘어요.

안 쓰는 열쇠를 돌려받아 열쇠함에 넣는 장면 — 쓰지 않는 커넥터는 연결 끊기 (GPT 이미지 생성)

쓰지 않게 된 커넥터는 같은 Customize > Connectors 화면에서 연결을 끊을 수 있어요.

⚠️ 주의회사 메일·사내 문서 계정은 연결하기 전에 회사 보안 규칙부터 확인하세요.

막힐 때

회사 계정에서 커넥터를 추가할 수 없어요
원인: 팀·엔터프라이즈 요금제는 관리자가 먼저 커넥터를 켜 줘야 해요.
해결: 관리자에게 요청하세요. 켜진 뒤에도 각자 자기 계정으로 로그인은 따로 해야 해요.

클로드 코드 목록에 커넥터가 안 떠요
원인: 커넥터는 claude.ai 계정으로 로그인한 클로드 코드에만 자동으로 따라와요.
해결: claude.ai 계정으로 로그인했는지 확인하고, 커넥터는 claude.ai의 Customize > Connectors에서 추가하세요.

목록에 Needs authentication이라고 떠요
원인: 커넥터는 추가했지만 그 서비스 로그인(인증)이 끝나지 않은 상태예요.
해결: Customize > Connectors에서 그 커넥터의 연결을 끊었다가 다시 연결하세요.

자주 묻는 질문

Q. 무료 요금제에서도 연결할 수 있나요?

클로드 도움말에 따르면 웹 커넥터는 모든 사용자가 쓸 수 있어요. 주소를 직접 넣는 사용자 지정 커넥터는 무료 요금제에서 1개까지예요.

Q. MCP 서버와 커넥터는 다른 건가요?

같은 거예요. 클로드는 claude.ai에 추가한 MCP 서버를 커넥터라고 불러요.

Q. 연결하면 AI가 내 계정으로 무엇이든 할 수 있나요?

클로드는 그 서비스에서 내 계정이 가진 권한을 그대로 이어받아요. 그래서 연결할 때 요청하는 권한을 살피고, 필요 없는 커넥터는 끊어 두는 게 좋아요.

Q. 목록에 없는 도구는 어떻게 연결하나요?

MCP 서버 주소를 직접 넣는 사용자 지정 커넥터로 붙일 수 있어요. 다만 이런 서버는 앤트로픽이 검증하지 않은 것이라, 믿을 수 있는 곳에서 낸 서버인지 먼저 확인하세요.
